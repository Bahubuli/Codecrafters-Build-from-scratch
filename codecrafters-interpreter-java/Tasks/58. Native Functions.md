# Stage 58: Native functions

## In one line
Implementing function call expressions (`callee(args...)`) and defining global native callable functions (`clock()`).

## The problem it solved
Programs need primitives provided directly by the host runtime environment (I/O, system clock, math libraries) that cannot be expressed purely in language syntax. We need a general mechanism for calling functions and binding native host capabilities into the global environment.

## Concepts (the transferable part)
- **The `LoxCallable` Interface**:
  ```java
  public interface LoxCallable {
      int arity();
      Object call(Interpreter interpreter, List<Object> arguments);
  }
  ```
  Both native functions and user-defined Lox functions implement this abstraction.
- **Call Expression Grammar and Parsing**:
  Calls bind tighter than unary/binary operations, parsed directly above `primary()`:
  ```
  unary  → ( "!" | "-" ) unary | call ;
  call   → primary ( "(" arguments? ")" )* ;
  ```
  The loop allows chained calls like `fn(1)(2)`.
  When a left parenthesis is encountered, `finishCall` collects comma-separated argument expressions up to the closing parenthesis (with a maximum argument limit of 255).
- **Global Environment and Native Function Registration**:
  The interpreter maintains a `globals` root environment where native builtins are bound at initialization:
  ```java
  globals.define("clock", new LoxCallable() {
      @Override
      public int arity() { return 0; }

      @Override
      public Object call(Interpreter interpreter, List<Object> arguments) {
          return (double) System.currentTimeMillis() / 1000.0;
      }

      @Override
      public String toString() { return "<native fn>"; }
  });
  ```
- **Call Evaluation**:
  1. Evaluate `callee` expression.
  2. Evaluate each argument expression in left-to-right order.
  3. Validate that `callee` is an instance of `LoxCallable`.
  4. Verify that argument count matches `function.arity()`.
  5. Invoke `function.call(this, arguments)`.

## What breaks it (failure modes)
- Calling a non-callable object (e.g. `123()`), which must raise a runtime error `"Can only call functions and classes."`.
- Arity mismatch between passed arguments and expected parameters, which must raise `"Expected X arguments but got Y."`.
- Evaluating arguments in reverse or non-deterministic order.

## Tradeoffs
- Modeling native functions as `LoxCallable` objects inside the normal environment avoids special AST nodes or grammar extensions for every builtin function.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input: `print clock();`
- Stdout: `1731411035`
- Exit code: `0`

## Java specifics — lookup, don't memorize
- `System.currentTimeMillis() / 1000.0` converts milliseconds since epoch to fractional seconds in double precision.
