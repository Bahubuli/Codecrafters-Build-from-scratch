# Stage 55: While statements

## In one line
Loop construct that repeatedly evaluates condition expression and executes body statement while truthy.

## Self-test (cover the answers below and answer these first)
- Why does `while` parse the body as a single `statement()` instead of requiring a `block()`?
- How is the loop condition re-evaluated in the interpreter visitor?
- If the initial condition evaluates to falsey, how many times does the body execute?

## The problem it solved
Programs require repeating actions until a dynamically changing termination condition is met (e.g., accumulation, state mutation, sequence generation like Fibonacci).

## Concepts (the transferable part)
- **Loop AST Representation**:
  ```java
  public static class While extends Stmt {
      public final Expr condition;
      public final Stmt body;
      ...
  }
  ```
- **Grammar Rule**:
  ```
  statement      → exprStmt
                 | ifStmt
                 | printStmt
                 | whileStmt
                 | block ;

  whileStmt      → "while" "(" expression ")" statement ;
  ```
  Because the body is a `statement()`, a single statement (`while (foo < 3) print foo = foo + 1;`) or a block statement (`while (foo < 3) { ... }`) works transparently.
- **Direct Java While Mapping**:
  ```java
  @Override
  public Void visitWhileStmt(Stmt.While stmt) {
      while (isTruthy(evaluate(stmt.condition))) {
          execute(stmt.body);
      }
      return null;
  }
  ```
  The condition is re-evaluated on each iteration against the current runtime environment, reflecting any mutations performed in the loop body.

## What breaks it (failure modes)
- Evaluating `condition` only once prior to the loop, causing an infinite loop or terminating prematurely.
- Restricting the body to `block()` only, which causes parse errors on single-statement while loops.

## Tradeoffs
- A while loop is the fundamental primitive; subsequent loop constructs (like `for` loops) can be desugared directly into `while` loops without new bytecode or interpreter execution paths.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input:
  ```lox
  var quz = 0;
  while (quz < 3) {
    print quz;
    quz = quz + 1;
  }
  ```
- Stdout:
  ```

  1
  2
  ```
- Exit code: `0`

## Java specifics — lookup, don't memorize
- `while (isTruthy(evaluate(stmt.condition)))` leverages Java's native `while` control loop to manage interpreter instruction flow.
