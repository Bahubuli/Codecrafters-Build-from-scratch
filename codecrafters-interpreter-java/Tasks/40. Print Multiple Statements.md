# Stage 40: Print: Multiple statements

## In one line
Extending program execution to sequentially evaluate and print multiple statements across multiple lines or within the same line.

## The problem it solved
Real-world programs consist of multiple statements executed in sequence. The interpreter must parse consecutive statements until EOF, regardless of whether they are separated by newlines, indentation, or simply semicolons on a single line.

## Concepts (the transferable part)
- **Program Grammar**:
  $$\text{program} \to \text{statement}^* \ \text{EOF}$$
- **Looping AST Parsing (`Parser.java`)**:
  ```java
  public List<Stmt> parseStatements() {
      List<Stmt> statements = new ArrayList<>();
      while (!isAtEnd()) {
          Stmt stmt = declaration();
          if (stmt != null) {
              statements.add(stmt);
          }
      }
      return statements;
  }
  ```
- **Sequential Statement Dispatch (`Interpreter.java`)**:
  ```java
  public void interpret(List<Stmt> statements) {
      try {
          for (Stmt statement : statements) {
              execute(statement);
          }
      } catch (RuntimeError error) {
          System.err.println(error.getMessage() + "\n[line " + error.token.line + "]");
          hasRuntimeError = true;
      }
  }
  ```
- **Newline Agnosticism**:
  Because Lox treats whitespace and newlines as delimiters rather than statement terminators, semicolons provide the syntactic boundaries separating statements.

## What breaks it (failure modes)
- Stopping after parsing or executing the first statement.
- Failing to handle multiline string literals embedded within a statement.
- Crashing when statements are placed back-to-back on a single line (e.g. `print 1; print 2;`).

## Tradeoffs
- Explicit semicolons eliminate ambiguity around newline insertion (unlike JavaScript's automatic semicolon insertion or Python's indentation rules), making statement boundaries deterministic.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input:
  ```lox
  print "hello"; print true;
  print 42;
  ```
- Stdout:
  ```
  hello
  true
  42
  ```
- Exit code: `0`
