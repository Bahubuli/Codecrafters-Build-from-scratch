# Stage 44: Variables: Initialize variables

## In one line
Defaulting variable declarations without an explicit initializer expression (`var a;`) to `nil` (`null`).

## Self-test (cover the answers below and answer these first)
- What is the initializer expression of `var a;` in the AST?
- What value is stored in `Environment` when a variable has no initializer?
- Why is `values.containsKey(...)` essential when checking if a variable defined as `nil` exists?

## The problem it solved
In Lox, variables can be declared without an initial value (`var x;`). In such cases, the variable must be initialized to `nil` rather than left undefined or causing runtime errors upon access.

## Concepts (the transferable part)
- **Optional Initializer in AST (`Stmt.Var`)**:
  `Stmt.Var` holds a nullable `Expr initializer`. When the parser does not see an `=` token, `initializer` is set to `null`.
- **Interpreting Uninitialized Variables (`Interpreter.java`)**:
  ```java
  @Override
  public Void visitVarStmt(Stmt.Var stmt) {
      Object value = null;
      if (stmt.initializer != null) {
          value = evaluate(stmt.initializer);
      }

      environment.define(stmt.name.lexeme, value);
      return null;
  }
  ```
- **Distinguishing Between Undefined vs Defined with `nil`**:
  `Environment` must use `values.containsKey(name.lexeme)` instead of checking `values.get(name.lexeme) != null`. If it checked for non-null, accessing an uninitialized variable would mistakenly be treated as undefined.

## What breaks it (failure modes)
- Leaving the variable undefined in `Environment` so that accessing it raises `Undefined variable` error.
- Checking `values.get(name) != null` to check existence instead of `containsKey`.
- Printing `null` instead of `nil` when stringifying uninitialized variables.

## Tradeoffs
- Defaulting to `nil` vs requiring explicit initialization: Defaulting to `nil` provides flexibility in scripting languages, but can allow uninitialized read bugs to propagate silently until a runtime operator error occurs.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input:
  ```lox
  var a;
  print a;
  ```
- Stdout: `nil`
- Exit code: `0`

## Java specifics — lookup, don't memorize
- In Java, `Map.put(key, null)` inserts a key mapped to `null`. `Map.containsKey(key)` returns `true`, distinguishing it from an absent key.
