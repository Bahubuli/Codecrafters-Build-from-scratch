# Stage 51: Else-if statements

## In one line
Chaining conditional branching through recursive statement nesting where an `else` branch contains another `Stmt.If` statement.

## Self-test (cover the answers below and answer these first)
- Does the Lox grammar need a dedicated `else if` keyword or AST node? Why or why not?
- How is an `else if (...)` chain represented structurally in the AST?
- What guarantees that only the first matching condition in an `if ... else if ... else` chain executes?

## The problem it solved
Multi-way branching requires evaluating a sequence of conditions until one is truthy, executing only its corresponding branch. Instead of inventing a distinct syntax or AST node for `else if`, recursive grammar allows the `else` clause to parse any `statement()`, which may itself be an `ifStatement()`.

## Concepts (the transferable part)
- **Syntactic Composition**:
  ```
  ifStmt → "if" "(" expression ")" statement
           ( "else" statement )? ;
  ```
  Because `statement` can be an `ifStmt`, chaining:
  ```lox
  if (c1) s1;
  else if (c2) s2;
  else s3;
  ```
  naturally parses into:
  `Stmt.If(c1, s1, Stmt.If(c2, s2, s3))`.
- **Short-circuit Execution**:
  ```java
  @Override
  public Void visitIfStmt(Stmt.If stmt) {
      if (isTruthy(evaluate(stmt.condition))) {
          execute(stmt.thenBranch);
      } else if (stmt.elseBranch != null) {
          execute(stmt.elseBranch);
      }
      return null;
  }
  ```
  When `c1` is truthy, `s1` is executed and `stmt.elseBranch` (which holds the entire rest of the chain) is skipped completely.

## What breaks it (failure modes)
- Trying to tokenize `else if` as a single composite token instead of two separate tokens.
- Creating a separate list of conditions in `Stmt.If`, which unnecessarily complicates tree walkers and code generators when recursive nesting already represents it faithfully.

## Tradeoffs
- Nested AST structure means deep `else if` chains create deep trees rather than a flat switch/case table, but keeps the grammar small, elegant, and minimal.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input:
  ```lox
  var age = 88;
  var stage = "unknown";
  if (age < 18) { stage = "child"; }
  else if (age >= 18) { stage = "adult"; }
  else if (age >= 65) { stage = "senior"; }
  print stage;
  ```
- Stdout:
  ```
  adult
  ```
- Exit code: `0`

## Java specifics — lookup, don't memorize
- AST nesting in Java relies on Polymorphic Dispatch:
  `stmt.elseBranch.accept(this)` invokes `visitIfStmt` recursively for nested `If` statements without special casing.
