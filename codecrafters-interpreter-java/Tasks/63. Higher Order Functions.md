# Stage 63: Higher order functions

## In one line
Supporting first-class functions passed as arguments, returned from functions, and invoked curried or chained by capturing the lexical enclosing environment.

## The problem it solved
Higher-order functions require functions to be treated as ordinary values: they can be stored in variables, passed into other functions as arguments, returned from functions, and invoked directly from expressions (chained calls).

## Concepts (the transferable part)
- **First-Class Functions**:
  In Java, `LoxFunction` is a Java object implementing `LoxCallable`. Since any `Object` can be bound to an identifier, stored in an `Environment`, or passed as an argument to another function call, functions are first-class citizens.
- **Chained Call Parsing**:
  In `Parser.call()`:
  ```java
  private Expr call() {
      Expr expr = primary();

      while (true) {
          if (match(TokenType.LEFT_PAREN)) {
              expr = finishCall(expr);
          } else {
              break;
          }
      }

      return expr;
  }
  ```
  The while loop wraps any call result in subsequent `Expr.Call` nodes when followed by `(`, allowing expressions like `returnArg(func)(arg)`.
- **Lexical Closures**:
  When a function is declared inside another function, its `LoxFunction` instance captures the active local `Environment` as its `closure`. When returned and called later, its activation record's enclosing pointer points to that captured `closure`, preserving lexical variables.

## What breaks it (failure modes)
- Only allowing identifiers as call targets (`foo()` instead of `(expr)()`).
- Binding function declarations only to the global environment instead of the current local environment.
- Mutating environments globally rather than scoping them per activation record.

## Tradeoffs
- Tree-walk interpreters naturally preserve closures by retaining references to parent `Environment` objects on the Java heap, relying on Java's garbage collector to reclaim unreachable environments.

## CLI / Protocol format
- Command: `./your_program.sh run <file.lox>`
- Input:
  ```lox
  fun makeGreeter() {
    fun greet(name) {
      print "Hello " + name;
    }
    return greet;
  }
  var sayHello = makeGreeter();
  sayHello("Bob");
  ```
- Stdout:
  ```
  Hello Bob
  ```
- Exit code: `0`
