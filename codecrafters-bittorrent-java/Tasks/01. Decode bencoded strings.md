# Stage 01: Decode bencoded strings

## In one line
Decoded length-prefixed BitTorrent strings formatted as `<length>:<string>` into JSON representations.

## Self-test (cover the answers below and answer these first)
- How does Bencode represent strings and determine string boundaries without escaping?
- What happens if the string contains colons or binary data?
- Why does Bencode use length prefixes instead of null-terminators or quote escapes?

## The problem it solved
Systems exchanging arbitrary binary and textual data across untrusted networks need unambiguous framing without expensive escaping. Bencode solves string serialization by prefixing the content with its exact byte length followed by a colon delimiter (`<length>:<content>`).

## Concepts (the transferable part)
- **Length-Prefixed Framing (Pascal strings / Bencode)**: Rather than scanning for delimiter markers or escaping reserved characters, prefixing payloads with length provides O(1) boundary determination and byte-exact safety for arbitrary binary payloads.
- **Wire Deserialization**: Scanning for the delimiter separating metadata (byte count) from payload and slicing exactly the specified count of bytes.

## What breaks it (failure modes)
- Negative or non-numeric length prefix — crashes if not validated before parsing.
- Truncated payload where available bytes are fewer than indicated length — causes out-of-bounds errors.
- Colons inside the payload itself — must ensure only the first delimiter after digits is treated as the boundary.

## Tradeoffs
- Length prefix vs delimiter escaping — Length prefixes require knowing the size in advance (buffering required during serialization), but make parsing O(1) in boundary scanning and safe for arbitrary binary.

## Wire format / protocol
`4:spam` -> `"spam"`  
`10:hellohello` -> `"hellohello"`  
`<ASCII integer length>:<raw bytes>`

## Java specifics - lookup, don't memorize
- `Character.isDigit(char)` — checks whether a character is an ASCII digit.
- `String.indexOf(':')` — finds the index of the first occurrence of delimiter.
- `Integer.parseInt(String)` — parses string representations of base-10 integers.
- `Gson.toJson(Object)` — converts Java objects into JSON strings.
