# Stage 5: Read data from a single column

## In one line
Parse `CREATE TABLE` DDL to map column names to physical record positions, locate the table's root page B-tree leaf cells, and unpack the SQLite Record Format to extract column values.

## Self-test (cover the answers below and answer these first)
- Why is the column definition order from the `CREATE TABLE` statement required to decode a row's column values?
- How does SQLite represent an `INTEGER PRIMARY KEY` column inside the record payload versus the leaf cell header?
- What are the three components of a table B-tree leaf cell, and how does the record header demarcate itself from the record body?
- How are variable-length strings and blobs encoded in SQLite's serial type system?
- What happens if the column requested is `INTEGER PRIMARY KEY` and the record's serial type is `0` (NULL)?

## The problem it solved
In Stage 4, we only read table metadata and leaf cell counts from page headers without inspecting row payloads. To execute queries like `SELECT name FROM apples`, we must now decode the table's schema to determine column offsets, navigate the leaf page cell pointer array, and unpack each row's serialized record header and body.

## Concepts (the transferable part)
- **Schema as Record Map** — SQLite record payloads do not store column names or types; they only store an ordered sequence of typed values. The `CREATE TABLE` DDL in `sqlite_schema` defines the canonical 0-based column order required to interpret record payloads.
- **B-Tree Leaf Table Cell Anatomy** — Each cell in a table B-tree leaf page (`0x0D`) contains a payload size (varint), an integer rowid (varint), and the payload bytes conforming to the SQLite Record Format.
- **SQLite Record Format** — A self-describing payload consisting of a header (total header byte count as a varint, followed by a varint serial type per column) and a body containing contiguous raw bytes for each non-zero-sized column value.
- **INTEGER PRIMARY KEY Rowid Alias** — An `INTEGER PRIMARY KEY` column serves as an alias for the 64-bit signed `rowid`. SQLite avoids redundant storage by encoding its serial type in the record header as 0 (NULL), meaning its value must be retrieved from the cell's `rowid`.
- **Text & Blob Serial Type Mapping** — Serial types $\ge 12$ represent blobs (if even: $(N - 12) / 2$ bytes) or UTF-8 strings (if odd: $(N - 13) / 2$ bytes).

## What breaks it (failure modes)
- **Assuming Column Names Exist in Data Payload** — Record bodies contain only raw values, not column names. Attempting to parse rows without first parsing the schema's column order will fail.
- **Ignoring INTEGER PRIMARY KEY Alias** — Selecting an `INTEGER PRIMARY KEY` column whose serial type is 0 will yield `null` unless explicitly resolved to the cell's `rowid`.
- **Buffer Misalignment From Variable Serial Types** — Each column before the target column must advance the buffer position by its exact serial type byte width (`getSerialTypeSize`); miscalculating any prior column width corrupts subsequent column offsets.
- **Table Constraints Misidentified as Columns** — Table DDL often includes constraints (`PRIMARY KEY (...)`, `CONSTRAINT`, `FOREIGN KEY`, `CHECK`, `UNIQUE`). Treating constraints as column definitions desynchronizes the column index from the record payload.
- **Quoted or Bracketed Identifiers** — SQL identifiers can be enclosed in double quotes, backticks, single quotes, or brackets (`"name"`, `[name]`). Failing to strip delimiters prevents matching requested column names.

## Tradeoffs
- **Scanning/Skipping Columns in-situ vs Pre-parsing all Row Values** — Skipping earlier columns by bumping buffer position executes faster with less memory allocation per row than unpacking all columns into an array or object map.
- **Regex Tokenizer vs Full SQL DDL Parser** — Splitting top-level parentheses and comma-separated tokens handles standard SQLite `CREATE TABLE` statements cleanly without the complexity of an entire SQL compiler frontend.

## Storage / Protocol format

### Table B-Tree Leaf Cell Format (`0x0D`)
| Field | Type | Description |
|---|---|---|
| `payload_size` | Varint | Total payload bytes (overflow page indicator if payload exceeds usable space) |
| `rowid` | Varint | 64-bit signed integer row identifier |
| `payload` | Bytes | Serialized record (Header + Body) |

### SQLite Record Format
```
+-------------------------------------------------------------------------+
|                              Record Header                              |
| [header_size : varint] [serial_type_0] [serial_type_1] ... [serial_type_N] |
+-------------------------------------------------------------------------+
|                               Record Body                               |
| [value_0 : bytes] [value_1 : bytes] ... [value_N : bytes]               |
+-------------------------------------------------------------------------+
```

### Serial Type Encodings
| Serial Type | Content Size | Meaning |
|---|---|---|
| `0` | 0 bytes | NULL value (or `rowid` alias if column is `INTEGER PRIMARY KEY`) |
| `1` | 1 byte | 8-bit signed two's complement integer |
| `2` | 2 bytes | 16-bit big-endian signed integer |
| `3` | 3 bytes | 24-bit big-endian signed integer |
| `4` | 4 bytes | 32-bit big-endian signed integer |
| `5` | 6 bytes | 48-bit big-endian signed integer |
| `6` | 8 bytes | 64-bit big-endian signed integer |
| `7` | 8 bytes | 64-bit IEEE 754 floating point number |
| `8` | 0 bytes | Integer constant `0` |
| `9` | 0 bytes | Integer constant `1` |
| `10, 11` | 0 bytes | Internal reserved |
| $N \ge 12$ (even) | $(N - 12) / 2$ bytes | BLOB |
| $N \ge 13$ (odd) | $(N - 13) / 2$ bytes | String in database text encoding (UTF-8) |

## Java specifics — lookup, don't memorize
- `ByteBuffer.position(int newPosition)` — Sets the cursor offset in the buffer for subsequent reads.
- `Short.toUnsignedInt(short s)` — Converts signed 16-bit short to unsigned 32-bit integer (`0` to `65535`).
- `String.substring(int begin, int end)` — Returns a sub-sequence of characters from `begin` (inclusive) to `end` (exclusive).
- `StandardCharsets.UTF_8` — Charset constant for decoding byte arrays into UTF-8 strings.
- `Pattern.compile(String regex, int flags)` — Compiles regex with flags such as `Pattern.CASE_INSENSITIVE` or `(?is)`.
