# Stage 8: Create a list

---

## What You Have to Do

Add support for creating and appending to lists using the `RPUSH` command:

```
RPUSH <key> <element> [<element> ...]
```

1. **`RPUSH <key> <element>`**
   Appends one or more elements to the right (tail) of the list stored at `<key>`.
   If `<key>` does not exist, an empty list is created before performing the append operation.
   
   Example:
   ```
   $ redis-cli RPUSH list_key "foo"
   (integer) 1

   $ redis-cli RPUSH list_key "bar"
   (integer) 2
   ```

2. **RESP Wire Protocol Reply**:
   - The reply is the **length of the list** after the push operation.
   - Encoded as a **RESP Integer**:
     ```
     :<length>\r\n
     ```
     For length 1: `:1\r\n`
     For length 2: `:2\r\n`

---

## Thought Process

**The gap after stage 7:** Up until now, our Redis implementation only handled single-value scalar strings (`SET`, `GET`). Real-world Redis is a multi-model data structure server supporting lists, sets, hashes, sorted sets, and streams.

**List Semantics in Redis:**
- Redis lists are ordered collections of strings.
- `RPUSH` inserts elements at the tail (right end) of the list.
- If the target key does not exist, it is initialized as an empty list and the element is appended.
- Pushing $M$ elements returns the new total length of the list.

**Concurrency & Storage Design:**
- Multiple client threads can push to different keys concurrently, or even push to the *same* key concurrently.
- We maintain a dedicated thread-safe list store:
  ```java
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();
  ```
- To safely retrieve or create the list without race conditions, we use `listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()))`.
- When appending elements and querying the size, we synchronize on the list instance (`synchronized (list)`) to ensure atomic batch appending and size calculation across concurrent client threads.

## The Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## New Concepts in This Stage

**[CONCEPT] RESP Integer Type (`:`)**  
RESP integers represent 64-bit signed numbers. They start with a colon prefix `:` and terminate with CRLF `\r\n`:
- Format: `:<number>\r\n`
- Examples: `:0\r\n`, `:1\r\n`, `:-42\r\n`
- Redis uses RESP integers for counts, sizes, boolean responses (0 or 1), and error status codes in integer form.

**[CONCEPT] List Data Structure in Key-Value Stores**  
Unlike scalar key-value mappings where `store[k] = v`, collections in Redis associate a single key with an ordered sequence or set. `RPUSH` appends to the tail, preserving the order of insertion.

**[CONCEPT] Atomic Key Initialization (`computeIfAbsent`)**  
In concurrent systems, checking `if (!map.containsKey(key)) map.put(key, new List())` suffers from a classic *check-then-act* race condition: two threads could observe absence simultaneously and overwrite each other's lists. `Map.computeIfAbsent` performs this atomically.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `listStore.computeIfAbsent(key, k -> ...)` — atomically computes and inserts the value if key is absent.
- `Collections.synchronizedList(new ArrayList<>())` — wraps an `ArrayList` in a thread-safe wrapper.
- `synchronized (list) { ... }` — synchronizes operations on the list monitor so multi-element appends and size checks remain atomic.

---

## Failure Modes

- **Returning Simple String or Bulk String instead of Integer**: Sending `+1\r\n` or `$1\r\n1\r\n` will cause the Redis client or tester to fail type validation. The response must start with `:`.
- **Race conditions on list creation**: Using non-atomic `get` then `put` can lose items if two clients simultaneously push to a new key.
- **Off-by-one argument bounds**: `RPUSH <key> <elem1> <elem2> ...` has key at `parts[1]` and elements starting at index `parts[2]`.
- **Argument count validation**: Calling `RPUSH` with missing key or element must return an error rather than throwing an `ArrayIndexOutOfBoundsException`.

## Tradeoffs — List Representations

| Approach | Appending (RPUSH) | Random Access (LRANGE) | Memory Overhead |
|---|---|---|---|
| **`ArrayList`** | $O(1)$ amortized | $O(1)$ | Low, contiguous backing array |
| **`LinkedList`** | $O(1)$ | $O(N)$ traversal | Higher (node pointer overhead) |
| **Redis `quicklist` (C implementation)** | $O(1)$ | $O(N)$ across nodes, $O(1)$ within ziplist | Highly optimized cache-friendly chunking |

*For in-memory Java prototyping:* `ArrayList` protected by synchronization provides optimal cache locality and instant $O(1)$ indexed reads for subsequent stages like `LRANGE`.

## How It Flows

```
Client -> *3\r\n$5\r\nRPUSH\r\n$8\r\nlist_key\r\n$7\r\nelement\r\n

Server reads:
  n = 3
  parts = ["RPUSH", "list_key", "element"]

Server processing:
  key = "list_key"
  list = listStore.computeIfAbsent("list_key", ...)
  synchronized(list):
    list.add("element")
    newLength = 1

Server replies:
  :1\r\n
```
