# Stage 1: Bind to a Port

---

## What You Have to Do

Start a TCP server that listens on port 6379 and accepts one incoming connection from a client. No data exchange yet — just prove the server is alive and reachable.

---

## Thought Process

**What even IS a server?**  
A server is a program that waits for other programs (clients) to connect to it.

**What is a port?**  
Your machine has one IP address but can run many programs at once. Ports are numbered "doors" (0–65535) — they let the OS route incoming traffic to the right program. Redis always uses **6379** by convention.

**What could go wrong at startup?**  
Another process might already own port 6379 → `Address already in use`. That's why we set `SO_REUSEADDR = true` — it lets us reclaim the port quickly after a restart without waiting for the OS's ~60-second TIME_WAIT.

---

## The Solution

```java
import java.io.IOException;
import java.net.ServerSocket;
import java.net.Socket;

public class Main {
  public static void main(String[] args) {

    ServerSocket serverSocket = null;
    Socket clientSocket = null;
    int port = 6379;

    try {
      serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);
      clientSocket = serverSocket.accept();

    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());

    } finally {
      try {
        if (clientSocket != null) {
          clientSocket.close();
        }
      } catch (IOException e) {
        System.out.println("IOException: " + e.getMessage());
      }
    }
  }
}
```

---

## New Concepts in This Stage

**[CONCEPT] Two kinds of sockets**  
There are two distinct objects here that Java names similarly:
- **Listening socket** (`ServerSocket`) — bound to a port, only purpose is to wait for connections. Lives for the server's entire lifetime.
- **Connected socket** (`Socket`) — one active connection to one client. You get a new one each time `accept()` returns.

This distinction exists at the OS level in every language. The OS manages both; Java just wraps them.

**[CONCEPT] `accept()` — blocking handoff**  
`accept()` pauses your thread until a client completes the TCP handshake. Only then does it return — handing you the connected socket for that client. This is *blocking I/O*: your thread does nothing useful while waiting. You'll encounter non-blocking alternatives later; blocking is the simplest starting model.

**[CONCEPT] Port reuse / TIME_WAIT**  
When a process exits, the OS holds its port in TIME_WAIT for ~60 seconds to catch stray late-arriving packets. `SO_REUSEADDR` bypasses this for development convenience. In production you'd let it expire normally.

**[SYNTAX] Variables declared before `try`**  
Java scoping: a variable declared inside `try` is invisible to `finally`. Since `finally` needs to call `clientSocket.close()`, the variable must be declared in the outer scope. Not a systems concept — just a Java rule.

**[SYNTAX] `try / catch / finally`**  
Java's error-handling structure. `finally` always runs regardless of success or failure — the right place to release resources like sockets. You'll write this shape constantly.

---

## Failure Modes

- **Port already in use** — `new ServerSocket(port)` throws immediately. `setReuseAddress(true)` prevents this on fast restarts; it doesn't help if another unrelated process owns the port.
- **`accept()` never returns** — if no client connects, your program sits here forever. For a server that's correct behavior. In a client it would be a bug.
- **`clientSocket` still null when `finally` runs** — if `accept()` throws before assigning `clientSocket`, the variable is still null. The `if (clientSocket != null)` guard prevents a NullPointerException.

---

## Key Concepts Summary

| Term | What it means |
|------|---------------|
| **Port** | A numbered door (0–65535). Programs claim ports to receive traffic. |
| **TCP** | Reliable, ordered byte-stream protocol. Data arrives in order, nothing lost. |
| **ServerSocket** | Listening socket — binds to a port and waits for connections |
| **Socket** | Connected socket — represents one active client connection |
| **`accept()`** | Blocks until a client connects; returns the connected Socket |
| **SO_REUSEADDR** | Bypasses TIME_WAIT so you can restart quickly during development |
| **Blocking I/O** | A call that pauses your thread until the operation completes |
