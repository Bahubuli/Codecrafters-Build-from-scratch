# Stage 13: Prepend elements

---

## Problem Solved

In previous stages, we implemented `RPUSH` to append elements to the tail of a list and `LRANGE` to inspect slices from arbitrary positive or negative indices. However, a complete list primitive requires bidirectional insertion. In Redis, lists are dual-ended: clients can push to either the head (`LPUSH`) or the tail (`RPUSH`), allowing Redis lists to function interchangeably as Stacks (LIFO), Queues (FIFO), or double-ended queues (Deques).

This stage implements the `LPUSH` command:
1. **Head Prepending**: `LPUSH <key> <element1> [element2 ...]` inserts elements at index 0 (the head) of the list.
2. **Left-to-Right Batch Prepending Order**:
   - Redis evaluates multiple arguments sequentially: for `LPUSH key "a" "b" "c"`, `"a"` is pushed at index 0 (`["a"]`), then `"b"` is pushed at index 0 (`["b", "a"]`), and finally `"c"` is pushed at index 0 (`["c", "b", "a"]`).
   - Consequently, the arguments appear in reverse order when inspected from head to tail via `LRANGE`.
3. **Implicit Creation**: If `<key>` does not exist in the store, a new empty list is instantiated before prepending elements.
4. **RESP Integer Return**: Returns the total length of the list immediately after all elements are prepended: `:<newLength>\r\n`.

---

## Thought Process & Mathematical Derivation

**1. Left-to-Right Prepend Semantics:**
Suppose the list initially contains $K$ elements: $[x_1, x_2, \dots, x_K]$.
When executing `LPUSH key e_1 e_2 ... e_m`:
- Iteration $i = 1$: Insert $e_1$ at index $0 \implies [e_1, x_1, x_2, \dots, x_K]$.
- Iteration $i = 2$: Insert $e_2$ at index $0 \implies [e_2, e_1, x_1, x_2, \dots, x_K]$.
- $\dots$
- Iteration $i = m$: Insert $e_m$ at index $0 \implies [e_m, \dots, e_2, e_1, x_1, x_2, \dots, x_K]$.

The new length is:
$$\text{newLength} = K + m$$

And the head of the list is $e_m$, the last argument specified in the command.

**2. Contrast with RPUSH:**
- `RPUSH key "a" "b" "c"` on empty list $\implies ["a", "b", "c"]$.
- `LPUSH key "a" "b" "c"` on empty list $\implies ["c", "b", "a"]$.
- Mixing them (`RPUSH key "x"`, then `LPUSH key "y"`) $\implies ["y", "x"]$.

**3. Concurrency & Atomicity:**
Batch prepends must be atomic. If two clients simultaneously execute `LPUSH` or `RPUSH` on the same key, interleaving element insertions would corrupt the expected ordering and result in inconsistent intermediate states. By synchronizing on the list instance (`synchronized (list)`), all elements in the command are prepended atomically before any concurrent `LRANGE` or `RPUSH` can observe the list.

## Full Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'lpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(0, parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      int size = list.size();
                      if (size == 0) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        if (start < 0) start += size;
                        if (stop < 0) stop += size;
                        if (start < 0) start = 0;
                        if (stop < 0) stop = 0;

                        if (start >= size || start > stop) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          int stopIdx = Math.min(stop, size - 1);
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## Concepts

**[CONCEPT] Double-Ended Queue (Deque) Duality in Redis Lists**  
In systems engineering, Redis lists represent abstract sequences where both ends are accessible in $O(1)$ time in C Redis (using `quicklist`—a doubly linked list of ziplists/listpacks).
- `LPUSH` / `LPOP`: Push and pop from the head.
- `RPUSH` / `RPOP`: Push and pop from the tail.
- By pairing `LPUSH` with `RPOP` (or `RPUSH` with `LPOP`), clients build standard FIFO message queues.
- By pairing `LPUSH` with `LPOP` (or `RPUSH` with `RPOP`), clients build LIFO stacks.

**[CONCEPT] Left-to-Right Batch Prepend Semantics**  
When multiple values are pushed via `LPUSH key v1 v2 v3`, Redis processes arguments left-to-right. Each value is prepended to the head, displacing previously prepended values to the right. Therefore, the rightmost argument in the command (`v3`) becomes the new head of the list at index 0.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `list.add(0, element)`: Inserts `element` at index 0, shifting any existing elements to higher indices.
- `listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()))`: Thread-safe creation of the synchronized collection if absent from the concurrent hash table.

## Failure Modes

- **Reverse Argument Prepending**:
  - *Bug*: Looping backwards over `parts` (e.g. `for (int i = parts.length - 1; i >= 2; i--) list.add(0, parts[i])`).
  - *Symptom*: Arguments would end up in forward order (`["a", "b", "c"]`), violating Redis specification where `LPUSH key a b c` yields `["c", "b", "a"]`.
- **Pre-allocating or Appending Instead of Prepending**:
  - *Bug*: Calling `list.add(parts[i])` instead of `list.add(0, parts[i])`.
  - *Symptom*: Becomes identical to `RPUSH`, causing `LRANGE` validation to fail.
- **Race Condition on Batch Prepend**:
  - *Bug*: Failing to wrap the insertion loop in `synchronized (list)`.
  - *Symptom*: A concurrent `LRANGE` or `RPUSH` on another worker thread could read partially pushed lists or interleave elements unpredictably.
- **Insufficient Argument Validation**:
  - *Bug*: Executing `LPUSH` when `parts.length < 3` (e.g., `LPUSH mylist` with no elements).
  - *Symptom*: `IndexOutOfBoundsException` or creating an empty list without error response. Must return `-ERR wrong number of arguments for 'lpush' command\r\n`.

## Tradeoffs

| Approach | Advantages | Disadvantages |
|---|---|---|
| **`ArrayList.add(0, elem)`** | Simple implementation reusing standard `List<String>`; works seamlessly with `subList` for `LRANGE`. | $O(N)$ shift per insertion because internal array must copy elements rightward via `System.arraycopy`. For huge lists, head prepends are slow. |
| **`ArrayDeque<String>` / `LinkedList<String>`** | $O(1)$ head prepends and tail appends. Matches Redis dual-ended queue performance characteristics. | Slicing by index for `LRANGE` requires $O(N)$ traversal (`LinkedList`) or converting to random-access structure (`ArrayDeque`). |
| **Reverse and Bulk `addAll(0, ...)`** | Single array resize and memory shift instead of $M$ individual shifts for $M$ arguments. | Minor allocation overhead for temporary reversed collection; same asymptotic complexity. |

## How It Flows

```
1. Client pushes multiple items using LPUSH:
Client -> LPUSH fruits "apple" "banana" "cherry"

Server Processing:
  Step 1: list.add(0, "apple")   -> ["apple"]
  Step 2: list.add(0, "banana")  -> ["banana", "apple"]
  Step 3: list.add(0, "cherry")  -> ["cherry", "banana", "apple"]
  newLength = 3

Server -> :3\r\n

2. Client inspects full list:
Client -> LRANGE fruits 0 -1

Server Processing:
  size = 3
  start = 0, stop = 2
  slice = ["cherry", "banana", "apple"]

Server -> *3\r\n$6\r\ncherry\r\n$6\r\nbanana\r\n$5\r\napple\r\n

3. Subsequent LPUSH on existing list:
Client -> LPUSH fruits "date"
Server Processing:
  Step 1: list.add(0, "date")    -> ["date", "cherry", "banana", "apple"]
  newLength = 4
Server -> :4\r\n
```

## Rebuild Checklist

- [ ] Match command case-insensitively: `command.equalsIgnoreCase("LPUSH")`.
- [ ] Validate argument count: verify `parts.length >= 3`, returning `-ERR wrong number of arguments for 'lpush' command\r\n` if not.
- [ ] Fetch or initialize list using `listStore.computeIfAbsent(...)`.
- [ ] Acquire `synchronized (list)` lock.
- [ ] Iterate forward through arguments: `for (int i = 2; i < parts.length; i++) { list.add(0, parts[i]); }`.
- [ ] Read `list.size()` inside the synchronized block.
- [ ] Format and write RESP integer: `":" + newLength + "\r\n"`.
- [ ] Flush socket output stream.
