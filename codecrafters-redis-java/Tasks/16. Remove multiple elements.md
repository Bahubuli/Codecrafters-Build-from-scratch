# Stage 16: Remove multiple elements

---

## Problem Solved

In Stage 15, we introduced the `LPOP <key>` command to dequeue a single element from the head of a Redis list. However, high-throughput consumer systems (such as worker pools and stream processors) frequently need to drain or batch-process work items to amortize network round-trips and lock contention. Issuing $K$ individual `LPOP` commands incurs $K$ client-server round-trip times (RTT).

This stage implements the multi-element variant of `LPOP`:
1. **Optional Count Argument**: `LPOP <key> [count]` allows callers to dequeue up to `count` elements in a single atomic invocation.
2. **Backwards Compatibility**: When no count is supplied (`parts.length == 2`), `LPOP` continues to pop 1 element and returns a RESP Bulk String `$<len>\r\n<element>\r\n` (or `$-1\r\n` if missing or empty).
3. **Array Reply for Multi-Pop**: When count is provided (`parts.length >= 3`), `LPOP` returns a RESP Array `*<N>\r\n...` containing bulk strings of the popped elements.
4. **Boundary & Clamp Semantics**: If `count` exceeds the list's current length ($|L_k| < \text{count}$), Redis pops all available elements and returns an array of length $|L_k|$.
5. **Key Cleanup**: When the list is completely drained, the key is removed from the global store (`listStore.remove(key)`).
6. **Missing Key Semantics**: If the key does not exist or is empty when count is provided, Redis returns a Null Array (`*-1\r\n`).

---

## Thought Process & Mathematical Derivation

**1. Batch Dequeuing & Amortized Cost:**
Batching transforms an $O(K \cdot \text{RTT})$ sequential network operation into a single round-trip:
$$\text{Latency} = 1 \times \text{RTT} + O(K)$$
Instead of acquiring the list monitor lock $K$ times and emitting $K$ separate frame packets, the server locks once, pops $K$ elements atomically, and flushes one aggregated RESP array.

**2. State Transition & Clamping:**
Given a list $L_k = [x_0, x_1, \dots, x_{M-1}]$ and a requested count $C \ge 0$:
$$\text{Elements to remove: } K = \min(C, |L_k|) = \min(C, M)$$
The popped sublist is:
$$R = [x_0, x_1, \dots, x_{K-1}]$$
The updated list state becomes:
$$L'_k = [x_K, x_{K+1}, \dots, x_{M-1}]$$
If $K = M$, the remaining length $|L'_k| = 0$, triggering keyspace reclamation:
$$\text{listStore.remove}(k)$$

**3. Type Polymorphism in Return Format:**
Notice a subtle Redis protocol design decision:
- `LPOP key`: Returns a Bulk String (or Null Bulk String `$-1\r\n`).
- `LPOP key count`: Returns an Array of Bulk Strings (or Null Array `*-1\r\n`).
Even if `count == 1`, passing the count argument switches the return wire type to a single-element array (`*1\r\n$...\r\n`).

## Full Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'lpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(0, parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LLEN")) {
                if (parts.length < 2) {
                  out.write("-ERR wrong number of arguments for 'llen' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.get(key);
                  int length = 0;
                  if (list != null) {
                    synchronized (list) {
                      length = list.size();
                    }
                  }
                  String response = ":" + length + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPOP")) {
                if (parts.length < 2) {
                  out.write("-ERR wrong number of arguments for 'lpop' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else if (parts.length == 2) {
                  String key = parts[1];
                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    String removedElement = null;
                    synchronized (list) {
                      if (!list.isEmpty()) {
                        removedElement = list.remove(0);
                        if (list.isEmpty()) {
                          listStore.remove(key);
                        }
                      }
                    }
                    if (removedElement == null) {
                      out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      byte[] bytes = removedElement.getBytes(StandardCharsets.UTF_8);
                      String response = "$" + bytes.length + "\r\n" + removedElement + "\r\n";
                      out.write(response.getBytes(StandardCharsets.UTF_8));
                    }
                  }
                } else {
                  String key = parts[1];
                  try {
                    int count = Integer.parseInt(parts[2]);
                    if (count < 0) {
                      out.write("-ERR value is out of range, must be positive\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      List<String> list = listStore.get(key);
                      if (list == null) {
                        out.write("*-1\r\n".getBytes(StandardCharsets.UTF_8));
                      } else {
                        List<String> removedElements = new ArrayList<>();
                        synchronized (list) {
                          int toRemove = Math.min(count, list.size());
                          for (int i = 0; i < toRemove; i++) {
                            removedElements.add(list.remove(0));
                          }
                          if (list.isEmpty()) {
                            listStore.remove(key);
                          }
                        }
                        if (removedElements.isEmpty() && count > 0) {
                          out.write("*-1\r\n".getBytes(StandardCharsets.UTF_8));
                        } else {
                          StringBuilder sb = new StringBuilder();
                          sb.append("*").append(removedElements.size()).append("\r\n");
                          for (String elem : removedElements) {
                            byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                            sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                          }
                          out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                        }
                      }
                    }
                  } catch (NumberFormatException e) {
                    out.write("-ERR value is not an integer or out of range\r\n".getBytes(StandardCharsets.UTF_8));
                  }
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      int size = list.size();
                      if (size == 0) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        if (start < 0) start += size;
                        if (stop < 0) stop += size;
                        if (start < 0) start = 0;
                        if (stop < 0) stop = 0;

                        if (start >= size || start > stop) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          int stopIdx = Math.min(stop, size - 1);
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## Concepts

**[CONCEPT] Batched Consumer Drain Pattern**  
In distributed messaging and queue topologies, consumers drain messages in batches rather than singly. This reduces per-message TCP packet framing and kernel syscall overhead. Atomically popping $K$ elements ensures that no competing consumer worker can interleave and steal partial chunks of the batch.

**[CONCEPT] Protocol Type Specialization by Arity**  
Redis commands often alter their return wire type based on the presence of optional modifiers:
- Calling `LPOP key` produces a scalar RESP bulk string.
- Calling `LPOP key count` produces a collection RESP array.
This distinction enables strongly typed Redis client libraries to deserialize responses into exact target language types (`String` vs `List<String>`).

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `Math.min(count, list.size())`: Clamps the drain count to the actual available number of items without throwing `IndexOutOfBoundsException`.
- `Integer.parseInt(parts[2])`: Parses the ASCII representation of the count argument, throwing `NumberFormatException` if malformed.

---

## What Breaks It (Failure Modes)

- **Looping Beyond Available Size Without Clamping**:
  - *Hazard*: Running `for (int i = 0; i < count; i++) list.remove(0)` without guarding `i < toRemove` or `!list.isEmpty()`.
  - *Failure*: Throws `IndexOutOfBoundsException` when `count > list.size()`.
- **Returning Bulk String When Count Is Passed**:
  - *Hazard*: If `count == 1`, returning `$len\r\nval\r\n` instead of `*1\r\n$len\r\nval\r\n`.
  - *Failure*: Clients expect a RESP Array whenever the count parameter is explicitly provided.
- **Leaking Empty List Keys After Batch Drain**:
  - *Hazard*: Failing to check `if (list.isEmpty()) listStore.remove(key)` after draining.
  - *Failure*: Drained keys remain in the map with empty list instances, causing `EXISTS` to return true and consuming memory indefinitely.
- **Negative Count Values**:
  - *Hazard*: Passing a negative count like `LPOP key -5`.
  - *Failure*: In Redis, negative count values must return `-ERR value is out of range, must be positive\r\n`.

---

## Tradeoffs

| Approach | Advantages | Disadvantages |
|---|---|---|
| **$K$ successive `list.remove(0)` calls** | Minimal code change, reuses existing `ArrayList` operations. | Each removal incurs $O(N)$ shift of remaining elements, total $O(K \cdot N)$. |
| **`subList` removal / bulk drain** | Faster bulk shift if backed by specialized chunked deque. | In `ArrayList`, still shifts tail elements, with slightly less overhead. |
| **Doubly-linked List / ArrayDeque head advance** | $O(K)$ pointer adjustments or ring buffer head increment without shifting elements. | Slower random access for `LRANGE` queries. |

---

## Wire Format / Protocol

| Command / State | Wire Input | Wire Output |
|---|---|---|
| Single pop (no count) | `*2\r\n$4\r\nLPOP\r\n$3\r\nkey\r\n` | `$<len>\r\n<element>\r\n` |
| Multi pop ($K$ elements) | `*3\r\n$4\r\nLPOP\r\n$3\r\nkey\r\n$1\r\n2\r\n` | `*2\r\n$...\r\n...` |
| Count > list length ($M$ elements) | `*3\r\n$4\r\nLPOP\r\n$3\r\nkey\r\n$2\r\n10\r\n` | `*M\r\n$...\r\n...` |
| Non-existent key with count | `*3\r\n$4\r\nLPOP\r\n$7\r\nmissing\r\n$1\r\n2\r\n` | `*-1\r\n` (Null Array) |
| Non-existent key without count | `*2\r\n$4\r\nLPOP\r\n$7\r\nmissing\r\n` | `$-1\r\n` (Null Bulk String) |

## How It Flows

```
1. Multi-element Pop:
Client -> LPOP mylist 2
Server:
  list = listStore.get("mylist")
  synchronized (list):
    toRemove = min(2, 3) = 2
    removedElements = [list.remove(0), list.remove(0)] -> ["one", "two"]
    list.isEmpty() == false
Server -> *2\r\n$3\r\none\r\n$3\r\ntwo\r\n

2. Pop with Count Exceeding Size:
Client -> LPOP mylist 5 (list has only 1 element)
Server:
  list = listStore.get("mylist")
  synchronized (list):
    toRemove = min(5, 1) = 1
    removedElements = [list.remove(0)] -> ["last"]
    list.isEmpty() == true -> listStore.remove("mylist")
Server -> *1\r\n$4\r\nlast\r\n

3. Pop Non-Existent Key with Count:
Client -> LPOP nonexistent 3
Server:
  list = listStore.get("nonexistent") -> null
Server -> *-1\r\n
```

## Rebuild Checklist

- [ ] Check argument count (`parts.length < 2`), return error if invalid.
- [ ] If `parts.length == 2` (single element pop):
  - [ ] If list is null or empty, return `$-1\r\n`.
  - [ ] Under lock, pop `list.remove(0)`, cleanup key if empty, return bulk string `$<len>\r\n<element>\r\n`.
- [ ] If `parts.length >= 3` (multi-element pop):
  - [ ] Parse `count = Integer.parseInt(parts[2])`. Return error if invalid format or negative.
  - [ ] If list is null, return `*-1\r\n`.
  - [ ] Under lock:
    - [ ] Calculate `toRemove = Math.min(count, list.size())`.
    - [ ] Pop `toRemove` elements into a temporary list using `list.remove(0)`.
    - [ ] If list is now empty, delete key from `listStore`.
  - [ ] If drained elements is empty and `count > 0`, return `*-1\r\n`.
  - [ ] Otherwise, format and return RESP Array `*<size>\r\n` with bulk strings.
- [ ] Flush output stream.
