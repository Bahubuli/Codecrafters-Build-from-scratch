# Stage 11: List elements (positive indexes)

---

## What You Have to Do

In this stage, you add support for querying elements of a list using the `LRANGE` command:

```
LRANGE <key> <start> <stop>
```

1. **Command Semantics**:
   - `LRANGE` retrieves a range of elements from the list stored at `<key>`.
   - The indexes `start` and `stop` are **0-based** and **inclusive**:
     - `0` is the first element of the list, `1` is the second, etc.
     - Both the element at `start` and the element at `stop` are included in the result.
   - For this stage, only non-negative indexes are tested.

2. **Boundary & Edge-Case Rules**:
   - If `<key>` does not exist in `listStore`: return an empty RESP array `*0\r\n`.
   - If `start >= list.size()` or `start > stop`: return an empty RESP array `*0\r\n`.
   - If `stop >= list.size()`: clamp `stop` to the last valid index (`list.size() - 1`).
   - If after clamping `start > stopIdx`: return `*0\r\n`.

3. **RESP Wire Protocol Reply**:
   - The result is serialized as a **RESP Array** of bulk strings:
     ```
     *<count>\r\n
     $<len1>\r\n<elem1>\r\n
     $<len2>\r\n<elem2>\r\n
     ...
     ```
   - For an empty range or missing list:
     ```
     *0\r\n
     ```
   - Example (`LRANGE list_key 0 2` with elements `["a", "b", "c"]`):
     ```
     *3\r\n$1\r\na\r\n$1\r\nb\r\n$1\r\nc\r\n
     ```

---

## Thought Process

**1. Inclusive vs Exclusive Slicing:**
- Most programming language slicing APIs (including Java's `list.subList(fromIndex, toIndex)` and Python's `list[start:stop]`) use a **half-open interval** `[fromIndex, toIndex)` where the end index is exclusive.
- Redis's `LRANGE`, however, specifies a **closed interval** `[start, stop]` where both boundaries are inclusive.
- To bridge this impedance mismatch when mapping to Java's `subList`, we clamp `stopIdx = Math.min(stop, list.size() - 1)` and query `list.subList(start, stopIdx + 1)`.

**2. Out-of-Bounds Clamping:**
- Redis is famously forgiving with ranges: out-of-range indexes do not produce an error; they clamp gracefully.
- If `stop` exceeds `list.size() - 1`, Redis simply reads up to the end of the list.
- If `start` is beyond the end of the list (`start >= list.size()`) or start exceeds stop (`start > stop`), the resulting range is empty, requiring a `*0\r\n` reply.

**3. Thread Safety & Lock Scope (Snapshotting):**
- In our multi-threaded server model, a client thread could issue `RPUSH key ...` while another client thread issues `LRANGE key ...`.
- If a thread calls `list.subList(start, end)` and iterates over it while another thread is mutating `list`, Java will throw a `ConcurrentModificationException`.
- Furthermore, we must not hold the synchronization lock on `list` while writing over TCP (`out.write`), as network latency or slow clients would cause head-of-line blocking for all other threads attempting to access that list.
- *Solution:* Under `synchronized (list)`, safely clamp indices and extract a snapshot copy (`new ArrayList<>(list.subList(...))`). Release the lock immediately, then serialize and flush the snapshot to the client socket.

## The Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      if (start >= list.size() || start > stop) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        int stopIdx = Math.min(stop, list.size() - 1);
                        if (start > stopIdx) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## New Concepts in This Stage

**[CONCEPT] Inclusive Index Ranges in Range Queries**  
Unlike standard programming language sub-string and sub-array APIs where upper bounds are exclusive `[start, end)`, Redis conventions use inclusive ranges `[start, stop]`. System designers must explicitly map between external protocol conventions and internal language collection APIs.

**[CONCEPT] RESP Array Framing (`*<count>\r\n`)**  
A RESP Array begins with an asterisk `*`, followed by the decimal number of elements and `\r\n`. Each contained item is itself a full RESP type (in `LRANGE`, each element is encoded as a bulk string `$<length>\r\n<data>\r\n`). An empty array is framed as `*0\r\n`. Note that `*0\r\n` (empty array) is distinct from `*-1\r\n` (null array).

**[CONCEPT] Reader Synchronization and Snapshot Isolation**  
When concurrent threads read and mutate shared collections, holding a lock for the entirety of network transmission causes severe lock contention. Instead, copy the required slice (`new ArrayList<>(list.subList(...))`) inside the synchronized critical section, and release the lock prior to encoding and sending bytes over the socket.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `list.subList(fromIndex, toIndex)`: Returns a view of the portion of this list between `fromIndex` (inclusive) and `toIndex` (exclusive).
- `Math.min(a, b)`: Clamps an index to prevent out-of-bounds reads when `stop >= list.size()`.
- `new ArrayList<>(subList)`: Copies elements into an independent collection, detaching from the underlying list view and allowing concurrent modifications to proceed without throwing `ConcurrentModificationException`.

---

## Failure Modes

- **Missing null check on non-existent keys**: Attempting to synchronize or call `.size()` on a `null` list throws `NullPointerException`. Non-existent keys must immediately return `*0\r\n`.
- **Off-by-one error with `subList`**: Passing `stop` instead of `stopIdx + 1` into `list.subList()` drops the last element due to Java's half-open interval semantics.
- **Unclamped `stop` throwing `IndexOutOfBoundsException`**: If `stop >= list.size()` and is passed directly to `subList`, Java throws an exception. `stop` must be clamped to `list.size() - 1`.
- **`ConcurrentModificationException` during serialization**: If elements are iterated directly from `list` or a live `subList` view while another thread pushes to the list, the iterator fails fast. Snapshotting inside `synchronized (list)` avoids this.
- **Returning Null Array `*-1\r\n` instead of Empty Array `*0\r\n`**: Missing keys in `LRANGE` return an empty array `*0\r\n`, not a null array `*-1\r\n`.

---

## Tradeoffs — Snapshot Copy vs Locked Streaming

| Metric | Snapshot Copy (`new ArrayList<>(subList)`) | Locked Streaming (`synchronized` during I/O) |
|---|---|---|
| **Lock Holding Time** | $O(K)$ in-memory copy (microseconds) | Variable: bound by network latency and TCP buffer availability (milliseconds) |
| **Throughput under Concurrency** | High: writer threads unblocked almost immediately | Low: writer threads blocked while slow readers flush over TCP |
| **Memory Allocation** | Allocates temporary list of size $K$ | Zero additional heap allocation |
| **Suitability** | Best for Redis range commands where slices are moderate | Only viable in single-threaded event loops (native Redis) |

## How It Flows

```
1. Client populates a list:
Client -> *7\r\n$5\r\nRPUSH\r\n$8\r\nlist_key\r\n$1\r\na\r\n$1\r\nb\r\n$1\r\nc\r\n$1\r\nd\r\n$1\r\ne\r\n
Server -> :5\r\n

2. Client queries first two elements:
Client -> *4\r\n$6\r\nLRANGE\r\n$8\r\nlist_key\r\n$1\r\n0\r\n$1\r\n1\r\n

Server reads:
  command = "LRANGE", key = "list_key", start = 0, stop = 1
Server processing:
  list found with size = 5
  synchronized (list):
    stopIdx = min(1, 4) = 1
    slice = ["a", "b"]
Server replies:
  *2\r\n$1\r\na\r\n$1\r\nb\r\n

3. Client queries range beyond list bounds:
Client -> *4\r\n$6\r\nLRANGE\r\n$8\r\nlist_key\r\n$1\r\n2\r\n$2\r\n10\r\n

Server reads:
  command = "LRANGE", key = "list_key", start = 2, stop = 10
Server processing:
  stopIdx = min(10, 4) = 4
  slice = ["c", "d", "e"]
Server replies:
  *3\r\n$1\r\nc\r\n$1\r\nd\r\n$1\r\ne\r\n

4. Client queries non-existent key or invalid range:
Client -> *4\r\n$6\r\nLRANGE\r\n$7\r\nmissing\r\n$1\r\n0\r\n$1\r\n2\r\n
Server replies:
  *0\r\n
```

## Rebuild Checklist

- [ ] Check if `key` exists in `listStore`; if not, write `*0\r\n`.
- [ ] Parse `start` and `stop` as integers from `parts[2]` and `parts[3]`.
- [ ] Synchronize on the target `list` and check if `start >= list.size()` or `start > stop`.
- [ ] Clamp `stopIdx = Math.min(stop, list.size() - 1)`.
- [ ] If `start > stopIdx`, treat as empty range (`*0\r\n`).
- [ ] Extract snapshot `new ArrayList<>(list.subList(start, stopIdx + 1))` inside the lock.
- [ ] Outside the lock, construct RESP array header `*<size>\r\n` followed by bulk string encoding `$<len>\r\n<data>\r\n` for each element.
- [ ] Flush output stream.
