# Stage 12: List elements (negative indexes)

---

## Problem Solved

In the previous stage, `LRANGE <key> <start> <stop>` only accommodated positive, 0-based inclusive index ranges. However, in real-world access patterns, querying from the tail of a sequence is common—such as retrieving the latest $N$ items (`LRANGE key -N -1`), inspecting the very last element (`LRANGE key -1 -1`), or dropping trailing elements (`LRANGE key 0 -3`).

This stage extends `LRANGE` with Redis's negative index normalization semantics:
1. **Negative Offsets**: A negative integer represents an offset from the end of the list:
   - `-1` is the last element (`size - 1`).
   - `-2` is the second-to-last element (`size - 2`).
   - In general: `index = index + size`.
2. **Underflow Clamping**: If a negative index underflows beyond the beginning of the list (e.g., `-6` on a list of length 5), it clamps to `0` (the start of the list).
3. **Empty / Inverted Range Boundaries**:
   - If after normalization `start >= size` or `start > stop`, the result is an empty RESP array `*0\r\n`.
   - `stop` is clamped to the list boundary: `stopIdx = Math.min(stop, size - 1)`.
   - If `start > stopIdx`, return `*0\r\n`.
4. **Thread-Safe Slicing**: Under `synchronized (list)`, snapshot the slice `new ArrayList<>(list.subList(start, stopIdx + 1))` and stream the RESP array outside the lock.

---

## Thought Process & Mathematical Derivation

**1. Index Normalization Function:**
Let $N = \text{list.size()}$.
For any index $k \in \mathbb{Z}$:
- If $k < 0$, offset from the end: $k' = k + N$.
- If $k' < 0$ (underflow where $|k| > N$), clamp to start: $k'' = \max(0, k') = 0$.
- If $k \ge 0$, then $k'' = k$.

In imperative Java:
```java
if (start < 0) start += size;
if (stop < 0) stop += size;
if (start < 0) start = 0;
if (stop < 0) stop = 0;
```

**2. Range Validity & Clamping:**
- If $N == 0$, the list is empty $\rightarrow$ return empty RESP array `*0\r\n`.
- If $\text{start} \ge N$, the start position is past the end $\rightarrow$ return `*0\r\n`.
- If $\text{start} > \text{stop}$, the interval is inverted $\rightarrow$ return `*0\r\n`.
- For upper-bound overshoot, clamp $\text{stopIdx} = \min(\text{stop}, N - 1)$.
- If $\text{start} > \text{stopIdx}$, return `*0\r\n`.

**3. Half-Open vs. Closed Interval Mapping:**
Redis intervals are inclusive $[start, stopIdx]$. Java's `List.subList(from, to)` expects a half-open interval $[from, to)$.
Therefore, the subList upper bound is $\text{stopIdx} + 1$.

**4. Concurrency & Isolation:**
`size`, normalization, and slicing must all occur within `synchronized (list)`. If `size` were read outside the lock while another connection pushes elements, the list could grow or shrink, causing `IndexOutOfBoundsException` or inconsistent slice windows.

## Full Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      int size = list.size();
                      if (size == 0) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        if (start < 0) start += size;
                        if (stop < 0) stop += size;
                        if (start < 0) start = 0;
                        if (stop < 0) stop = 0;

                        if (start >= size || start > stop) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          int stopIdx = Math.min(stop, size - 1);
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## Concepts

**[CONCEPT] Negative Index Normalization (Offsetting & Clamping)**  
In array-based abstractions, negative indexing represents backward indexing from the end of the collection ($k + N$). When negative offsets exceed collection length ($|k| > N$), Redis treats the index as clamping to the beginning of the sequence ($0$), rather than throwing an indexing error. This symmetric boundary handling makes Redis commands resilient across dynamically sized lists.

**[CONCEPT] Atomicity of Collection Inspection and Slicing**  
Reading `list.size()`, applying index normalization math, and producing `list.subList()` must be executed atomically inside `synchronized (list)`. If `list.size()` were sampled before acquiring the lock, a concurrent writer could alter the collection size before `subList` is called, leading to `IndexOutOfBoundsException` or invalid slices.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `Math.min(stop, size - 1)`: Bounds the inclusive end-point so `subList(start, stopIdx + 1)` never exceeds `size`.
- `Collections.emptyList()`: An immutable zero-allocation list instance used when queries resolve to empty ranges.

---

## Failure Modes

- **Normalization Order Bug (`start += size` vs underflow check)**: If `start = -10` on a list of size 5, `start += size` yields `-5`. If the underflow check `if (start < 0) start = 0;` is omitted, passing `-5` into `subList` throws `IndexOutOfBoundsException`.
- **Applying normalization to an empty list (`size == 0`)**: If `size == 0`, `start = -1` becomes `start = -1 + 0 = -1`, then clamps to `0`. Then `start >= size` (`0 >= 0`) triggers, returning empty. However, checking `size == 0` early prevents unnecessary index arithmetic.
- **Inverted range resulting in negative length**: For queries like `LRANGE key 3 1` or `LRANGE key 2 -10` (where normalized stop is 0 and start is 2), `start > stop`. Attempting `list.subList(2, 0 + 1)` throws `IllegalArgumentException: fromIndex(2) > toIndex(1)`. The guard `if (start > stop)` guarantees this never happens.
- **Holding lock during TCP output write**: Serializing and flushing RESP strings over `out.write()` while holding `synchronized (list)` blocks all concurrent readers and writers on that key if the network or client socket blocks.

---

## Tradeoffs

| Approach | Advantages | Disadvantages |
|---|---|---|
| **In-place index normalization** | Minimal overhead, zero memory allocation, exact match with Redis reference implementation | Must carefully guard boundary edge cases (`start > stop`, `start >= size`) |
| **Java Stream / Filter API** | Declarative pipeline syntax | Substantial heap allocation and boxing overhead for simple range lookups |
| **Pre-copying entire list** | Eliminates fine-grained index lock duration | $O(N)$ memory and time overhead even when requesting a small slice |

## How It Flows

```
1. Client populates 5 items:
Client -> RPUSH list_key "a" "b" "c" "d" "e"
Server -> :5

2. Query last 2 elements:
Client -> LRANGE list_key -2 -1
Server processing:
  size = 5
  start = -2 + 5 = 3
  stop = -1 + 5 = 4
  stopIdx = min(4, 4) = 4
  slice = subList(3, 5) -> ["d", "e"]
Server -> *2\r\n$1\r\nd\r\n$1\r\ne\r\n

3. Query all items except last 2:
Client -> LRANGE list_key 0 -3
Server processing:
  size = 5
  start = 0
  stop = -3 + 5 = 2
  stopIdx = min(2, 4) = 2
  slice = subList(0, 3) -> ["a", "b", "c"]
Server -> *3\r\n$1\r\na\r\n$1\r\nb\r\n$1\r\nc\r\n

4. Out-of-bounds negative index:
Client -> LRANGE list_key -10 1
Server processing:
  size = 5
  start = -10 + 5 = -5 -> clamps to 0
  stop = 1
  stopIdx = min(1, 4) = 1
  slice = subList(0, 2) -> ["a", "b"]
Server -> *2\r\n$1\r\na\r\n$1\r\nb\r\n
```

## Rebuild Checklist

- [ ] Check if `list` is null; return `*0\r\n` immediately if absent.
- [ ] In `synchronized (list)`, check if `size == 0`; return empty list if so.
- [ ] Apply negative offset logic: `if (start < 0) start += size; if (stop < 0) stop += size;`.
- [ ] Apply underflow clamping: `if (start < 0) start = 0; if (stop < 0) stop = 0;`.
- [ ] Check range validity: `if (start >= size || start > stop)` return empty list.
- [ ] Clamp upper bound: `int stopIdx = Math.min(stop, size - 1);`.
- [ ] Snapshot the slice: `new ArrayList<>(list.subList(start, stopIdx + 1));`.
- [ ] Release lock and encode RESP array `*<count>\r\n$<len>\r\n<data>\r\n...`.
