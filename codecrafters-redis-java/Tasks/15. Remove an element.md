# Stage 15: Remove an element

---

## Problem Solved

In previous stages, we implemented `RPUSH` and `LPUSH` to insert elements at the tail or head of a list, `LRANGE` to inspect slices, and `LLEN` to query element count. However, a data structure that only supports ingestion and inspection is not yet a functional queue or stack. Clients need to consume elements from the list.

This stage implements the `LPOP` command:
1. **Head Element Removal**: `LPOP <key>` removes and returns the first element (index 0) of the list stored at `<key>`.
2. **Missing or Empty Key Semantics**: If `<key>` does not exist in the store, or if the list contains no elements, Redis returns a Null Bulk String (`$-1\r\n`).
3. **Keyspace Reclamation**: When an `LPOP` operation empties a list, Redis removes the key from the global keyspace. Subsequent queries on that key behave as if it does not exist.
4. **RESP Bulk String Response**: The popped element is returned as a standard RESP bulk string: `$<len>\r\n<element>\r\n`.

---

## Thought Process & Mathematical Derivation

**1. Queue and Stack Dualities:**
With `LPOP`, Redis lists can be utilized as fundamental computing primitives:
- **FIFO Queue**: Producer uses `RPUSH` (enqueue at tail), consumer uses `LPOP` (dequeue at head).
  $$\text{RPUSH}(k, e) \implies L_k \gets L_k \mathbin{\Vert} [e]$$
  $$\text{LPOP}(k) \implies \text{head} = L_k[0], \; L_k \gets L_k[1 \dots |L_k|-1]$$
- **LIFO Stack**: Producer uses `LPUSH` (push onto head), consumer uses `LPOP` (pop from head).
  $$\text{LPUSH}(k, e) \implies L_k \gets [e] \mathbin{\Vert} L_k$$
  $$\text{LPOP}(k) \implies \text{head} = L_k[0], \; L_k \gets L_k[1 \dots |L_k|-1]$$

**2. Key Deletion on Empty Container:**
In Redis design philosophy, empty container types do not linger as empty shells in the keyspace:
$$\text{State Transition: } |L_k| = 1 \xrightarrow{\text{LPOP}(k)} |L_k| = 0 \implies \text{listStore.remove}(k)$$
This prevents memory leaks where thousands of abandoned empty list keys consume metadata overhead.

**3. Concurrency & Atomicity:**
When multiple clients compete to consume from the same queue:
- If two threads issue `LPOP` simultaneously when $|L_k| = 1$, exactly one client must receive the element, and the other must receive `$-1\r\n` (nil).
- Inspecting size, removing index 0, and deleting the empty key must occur atomically under the list's monitor lock (`synchronized (list)`).

## Full Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'lpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(0, parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LLEN")) {
                if (parts.length < 2) {
                  out.write("-ERR wrong number of arguments for 'llen' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.get(key);
                  int length = 0;
                  if (list != null) {
                    synchronized (list) {
                      length = list.size();
                    }
                  }
                  String response = ":" + length + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPOP")) {
                if (parts.length < 2) {
                  out.write("-ERR wrong number of arguments for 'lpop' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    String removedElement = null;
                    synchronized (list) {
                      if (!list.isEmpty()) {
                        removedElement = list.remove(0);
                        if (list.isEmpty()) {
                          listStore.remove(key);
                        }
                      }
                    }
                    if (removedElement == null) {
                      out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      byte[] bytes = removedElement.getBytes(StandardCharsets.UTF_8);
                      String response = "$" + bytes.length + "\r\n" + removedElement + "\r\n";
                      out.write(response.getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      int size = list.size();
                      if (size == 0) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        if (start < 0) start += size;
                        if (stop < 0) stop += size;
                        if (start < 0) start = 0;
                        if (stop < 0) stop = 0;

                        if (start >= size || start > stop) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          int stopIdx = Math.min(stop, size - 1);
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## Concepts

**[CONCEPT] Atomic Dequeue and Elimination of Empty Containers**  
In Redis, collections are self-cleaning: when the last item is removed, the container key is deleted from the database. This guarantees that:
1. Memory is freed immediately.
2. Checking existence via `EXISTS key` accurately reports `0`.
3. Commands like `TYPE` or `GET` on a previously depleted list return `none` or `nil` rather than a dangling empty list object.

**[CONCEPT] Linear Array Shift vs Linked List Node Unlinking**  
- In an `ArrayList`, calling `remove(0)` copies all remaining $N-1$ elements one slot to the left using `System.arraycopy()`, taking $O(N)$ time.
- In a doubly linked list or Redis `quicklist`, popping the head updates pointer references (`head = head.next; head.prev = null;`) in $O(1)$ time.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `list.remove(0)`: Removes and returns the element at index 0 of a `List`.
- `listStore.remove(key)`: Deletes the key-value mapping from the `ConcurrentHashMap`.

---

## What Breaks It (Failure Modes)

- **Unsynchronized `remove(0)` on Concurrent Pops**:
  - *Hazard*: Two threads execute `list.remove(0)` simultaneously without holding `synchronized (list)`.
  - *Failure*: Both threads can read the same element, or throw `IndexOutOfBoundsException` when the second thread tries to remove from an already emptied list.
- **Returning Integer or Empty String on Missing Key**:
  - *Hazard*: Returning `:0\r\n` or `$0\r\n\r\n` when `list == null` or list is empty.
  - *Failure*: Clients expect a RESP Null Bulk String (`$-1\r\n`) representing Redis `nil`.
- **Dangling Empty Lists in Store**:
  - *Hazard*: Failing to invoke `listStore.remove(key)` when `list.isEmpty()`.
  - *Failure*: While queries still return 0 / null bulk string, unused memory builds up in `listStore` for every popped queue.

---

## Tradeoffs

| Approach | Advantages | Disadvantages |
|---|---|---|
| **`ArrayList` with `remove(0)`** | Low memory overhead, contiguous cache-friendly storage, minimal object allocation. | Head removal requires $O(N)$ memory copying of remaining elements. |
| **`LinkedList` / `ArrayDeque`** | $O(1)$ head removal and insertion without array copies. | Random indexed access (`LRANGE`) degrades from $O(1)$ to $O(N)$ pointer traversal, and higher per-node memory overhead. |
| **Redis `quicklist` (Dual-ended list of ziplists)** | $O(1)$ push/pop at both ends with high CPU cache locality and compressed memory footprint. | High implementation complexity; requires managing chunk boundaries and re-balancing. |

---

## Wire Format / Protocol

| Command / State | Wire Input | Wire Output |
|---|---|---|
| Element popped | `*2\r\n$4\r\nLPOP\r\n$3\r\nkey\r\n` | `$<len>\r\n<element>\r\n` (e.g. `$3\r\none\r\n`) |
| Key does not exist | `*2\r\n$4\r\nLPOP\r\n$7\r\nmissing\r\n` | `$-1\r\n` (Null Bulk String) |
| List exists but empty | `*2\r\n$4\r\nLPOP\r\n$5\r\nempty\r\n` | `$-1\r\n` (Null Bulk String) |
| Missing argument | `*1\r\n$4\r\nLPOP\r\n` | `-ERR wrong number of arguments for 'lpop' command\r\n` |

## How It Flows

```
1. Normal Pop:
Client -> LPOP mylist
Server:
  list = listStore.get("mylist")
  synchronized (list):
    element = list.remove(0) -> "one"
    list.isEmpty() == false
Server -> $3\r\none\r\n

2. Final Element Pop (Key Cleanup):
Client -> LPOP mylist
Server:
  list = listStore.get("mylist")
  synchronized (list):
    element = list.remove(0) -> "last_item"
    list.isEmpty() == true -> listStore.remove("mylist")
Server -> $9\r\nlast_item\r\n

3. Missing Key Pop:
Client -> LPOP nonexistent
Server:
  list = listStore.get("nonexistent") -> null
Server -> $-1\r\n
```

## Rebuild Checklist

- [ ] Handle `command.equalsIgnoreCase("LPOP")`.
- [ ] Check argument count (`parts.length < 2`), return `-ERR wrong number of arguments for 'lpop' command\r\n` if violated.
- [ ] Fetch list from `listStore.get(key)`.
- [ ] If `list == null`, immediately write `$-1\r\n`.
- [ ] In `synchronized (list)` block:
  - Check `if (!list.isEmpty())`.
  - Remove head: `String removedElement = list.remove(0)`.
  - If `list.isEmpty()`, clean up keyspace: `listStore.remove(key)`.
- [ ] If `removedElement == null`, write `$-1\r\n`.
- [ ] Otherwise, write RESP bulk string `$<len>\r\n<element>\r\n`.
- [ ] Flush output stream.
