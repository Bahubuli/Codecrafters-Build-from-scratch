# Stage 14: Query list length

---

## Problem Solved

In previous stages, we implemented `RPUSH` and `LPUSH` to insert elements at either end of a list, and `LRANGE` to inspect slices. However, when clients use Redis lists as queues, stacks, or job buffers, they frequently need to inspect the number of pending elements without the overhead of transferring payload data across the network.

This stage implements the `LLEN` command:
1. **Length Querying**: `LLEN <key>` returns the number of elements currently stored in the list.
2. **Missing Key Semantics**: If `<key>` does not exist in the store (or the list has been removed or is null), Redis treats it as an empty list and returns `:0\r\n`.
3. **RESP Integer Response**: The output is formatted as a RESP integer: `:<length>\r\n`.
4. **$O(1)$ Efficiency**: The query is an instantaneous check of the container size rather than an iterative traversal.

---

## Thought Process & Mathematical Derivation

**1. Time Complexity: $O(1)$ vs $O(N)$:**
If a client had to execute `LRANGE key 0 -1` simply to count elements, the server would:
- Serialize all $N$ elements into RESP Bulk Strings.
- Transmit $O(\sum_{i=1}^N \text{len}(e_i))$ bytes across TCP sockets.
- Incur deserialization overhead on the client.

With `LLEN key`:
- The server reads the internal size counter in $O(1)$ time.
- Transmits only a few bytes (e.g., `:4\r\n`).
- Network bandwidth and serialization CPU cycles are completely saved.

**2. Non-Existent Key Handling:**
In Redis key-value semantics:
- Missing scalar keys queried via `GET` yield a Null Bulk String (`$-1\r\n`).
- Missing collection keys queried for their length/cardinality (`LLEN`, `SCARD`, `HLEN`, `ZCARD`) yield `0` (`:0\r\n`).
Hence:
$$\text{LLEN}(k) = \begin{cases} |L_k| & \text{if } k \in \text{listStore} \\ 0 & \text{otherwise} \end{cases}$$

**3. Thread Safety & Memory Visibility:**
Because Redis commands run concurrently across threads in our Java implementation:
- A worker thread executing `RPUSH` or `LPUSH` mutates the underlying `ArrayList` structure.
- Calling `list.size()` while another thread is expanding or shifting `ArrayList` element arrays without synchronization can read dirty memory or experience race conditions.
- Acquiring `synchronized (list)` ensures mutual exclusion and a memory barrier, guaranteeing that any writes completed by push operations are visible to `LLEN`.

## Full Solution

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStream;
import java.io.InputStreamReader;
import java.io.OutputStream;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class Main {
  private static class Entry {
    final String value;
    final Long expiresAt;

    Entry(String value, Long expiresAt) {
      this.value = value;
      this.expiresAt = expiresAt;
    }

    boolean isExpired() {
      return expiresAt != null && System.currentTimeMillis() > expiresAt;
    }
  }

  private static final Map<String, Entry> store = new ConcurrentHashMap<>();
  private static final Map<String, List<String>> listStore = new ConcurrentHashMap<>();

  public static void main(String[] args) {
    System.out.println("Logs from your program will appear here!");

    int port = 6379;

    try {
      ServerSocket serverSocket = new ServerSocket(port);
      serverSocket.setReuseAddress(true);

      while (true) {
        Socket clientSocket = serverSocket.accept();

        new Thread(() -> {
          try {
            OutputStream out = clientSocket.getOutputStream();
            InputStream in = clientSocket.getInputStream();
            BufferedReader reader = new BufferedReader(new InputStreamReader(in));

            while (true) {
              String line = reader.readLine();
              if (line == null) break; // client disconnected

              int n = Integer.parseInt(line.substring(1));

              String[] parts = new String[n];
              for (int i = 0; i < n; i++) {
                reader.readLine();            // Skip "$<len>"
                parts[i] = reader.readLine(); // Payload
              }

              String command = parts[0];

              if (command.equalsIgnoreCase("PING")) {
                out.write("+PONG\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("ECHO")) {
                String arg = parts[1];
                byte[] bytes = arg.getBytes(StandardCharsets.UTF_8);
                String response = "$" + bytes.length + "\r\n" + arg + "\r\n";
                out.write(response.getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("SET")) {
                String key = parts[1];
                String value = parts[2];
                Long expiresAt = null;

                if (parts.length >= 5) {
                  if (parts[3].equalsIgnoreCase("PX")) {
                    long pxMillis = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + pxMillis;
                  } else if (parts[3].equalsIgnoreCase("EX")) {
                    long exSeconds = Long.parseLong(parts[4]);
                    expiresAt = System.currentTimeMillis() + (exSeconds * 1000);
                  }
                }

                store.put(key, new Entry(value, expiresAt));
                out.write("+OK\r\n".getBytes(StandardCharsets.UTF_8));
              } else if (command.equalsIgnoreCase("GET")) {
                String key = parts[1];
                Entry entry = store.get(key);

                if (entry != null && !entry.isExpired()) {
                  byte[] bytes = entry.value.getBytes(StandardCharsets.UTF_8);
                  String response = "$" + bytes.length + "\r\n" + entry.value + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                } else {
                  if (entry != null && entry.isExpired()) {
                    store.remove(key);
                  }
                  out.write("$-1\r\n".getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("RPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'rpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LPUSH")) {
                if (parts.length < 3) {
                  out.write("-ERR wrong number of arguments for 'lpush' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.computeIfAbsent(key, k -> Collections.synchronizedList(new ArrayList<>()));
                  int newLength;
                  synchronized (list) {
                    for (int i = 2; i < parts.length; i++) {
                      list.add(0, parts[i]);
                    }
                    newLength = list.size();
                  }
                  String response = ":" + newLength + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LLEN")) {
                if (parts.length < 2) {
                  out.write("-ERR wrong number of arguments for 'llen' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  List<String> list = listStore.get(key);
                  int length = 0;
                  if (list != null) {
                    synchronized (list) {
                      length = list.size();
                    }
                  }
                  String response = ":" + length + "\r\n";
                  out.write(response.getBytes(StandardCharsets.UTF_8));
                }
              } else if (command.equalsIgnoreCase("LRANGE")) {
                if (parts.length < 4) {
                  out.write("-ERR wrong number of arguments for 'lrange' command\r\n".getBytes(StandardCharsets.UTF_8));
                } else {
                  String key = parts[1];
                  int start = Integer.parseInt(parts[2]);
                  int stop = Integer.parseInt(parts[3]);

                  List<String> list = listStore.get(key);
                  if (list == null) {
                    out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                  } else {
                    List<String> elementsToReturn;
                    synchronized (list) {
                      int size = list.size();
                      if (size == 0) {
                        elementsToReturn = Collections.emptyList();
                      } else {
                        if (start < 0) start += size;
                        if (stop < 0) stop += size;
                        if (start < 0) start = 0;
                        if (stop < 0) stop = 0;

                        if (start >= size || start > stop) {
                          elementsToReturn = Collections.emptyList();
                        } else {
                          int stopIdx = Math.min(stop, size - 1);
                          elementsToReturn = new ArrayList<>(list.subList(start, stopIdx + 1));
                        }
                      }
                    }

                    if (elementsToReturn.isEmpty()) {
                      out.write("*0\r\n".getBytes(StandardCharsets.UTF_8));
                    } else {
                      StringBuilder sb = new StringBuilder();
                      sb.append("*").append(elementsToReturn.size()).append("\r\n");
                      for (String elem : elementsToReturn) {
                        byte[] elemBytes = elem.getBytes(StandardCharsets.UTF_8);
                        sb.append("$").append(elemBytes.length).append("\r\n").append(elem).append("\r\n");
                      }
                      out.write(sb.toString().getBytes(StandardCharsets.UTF_8));
                    }
                  }
                }
              }
              out.flush();
            }
          } catch (IOException e) {
            System.out.println("IOException: " + e.getMessage());
          }
        }).start();
      }
    } catch (IOException e) {
      System.out.println("IOException: " + e.getMessage());
    }
  }
}
```

## Concepts

**[CONCEPT] Key Existence Semantics Across Redis Data Structures**  
In Redis, collection types (Lists, Sets, Sorted Sets, Hashes) treat non-existent keys identically to empty collections when inspected with non-mutating query commands:
- `LLEN missing_key` $\to 0$ (not `nil` or error)
- `SCARD missing_key` $\to 0$
- `HLEN missing_key` $\to 0$
- `LRANGE missing_key 0 -1` $\to$ empty array `*0\r\n`

Conversely, scalar inspection commands (like `GET missing_key`) return null (`$-1\r\n`).

**[CONCEPT] Memory Visibility in Concurrent Data Access**  
In multi-threaded architectures, reading a variable updated by another thread without synchronization can observe stale cache values due to CPU register caching and compiler instruction reordering. In Java, entering a `synchronized (list)` block establishes a happens-before relationship: changes made inside any prior `synchronized (list)` block on another thread are guaranteed visible upon monitor acquisition.

**[SYNTAX] Java specifics — lookup, don't memorize**  
- `listStore.get(key)`: Returns `null` if the key is absent from the `ConcurrentHashMap`.
- `synchronized (list) { length = list.size(); }`: Locks on the monitor of the `List` instance to read the current element count atomically.

---

## Failure Modes

- **Returning Null Bulk String on Missing Key**:
  - *Bug*: Writing `$-1\r\n` when `listStore.get(key) == null`.
  - *Symptom*: CodeCrafters tests expect `:0\r\n` for non-existent lists; client receives a string null instead of integer zero.
- **Unsynchronized Size Reading**:
  - *Bug*: Directly reading `list.size()` without `synchronized (list)`.
  - *Symptom*: Under heavy concurrent push/pop traffic, can read intermediate states or violate JVM memory visibility guarantees.
- **Missing Argument Validation**:
  - *Bug*: Executing `parts[1]` when `parts.length < 2`.
  - *Symptom*: `ArrayIndexOutOfBoundsException` terminating the connection thread when an empty `LLEN` command is sent.
- **Negative or Formatted Integer Mismatch**:
  - *Bug*: Formatting length as bulk string (e.g. `$1\r\n4\r\n`) instead of RESP integer (`:4\r\n`).
  - *Symptom*: Protocol parser rejection on Redis clients.

---

## Tradeoffs

| Approach | Advantages | Disadvantages |
|---|---|---|
| **Lock-based `synchronized (list)` Size Read** | Guaranteed consistency; zero additional state to synchronize or drift out of sync with the underlying list. | Readers momentarily contend for the monitor if a massive bulk push is currently writing to the list. |
| **Separate `AtomicInteger` Counter per Key** | Lock-free, non-blocking length queries via `counter.get()`. | Overhead of maintaining two concurrent data structures per key; risk of count and list contents diverging during exception handling. |
| **`ConcurrentLinkedDeque.size()`** | Entirely concurrent collection without custom synchronizations. | `size()` in `ConcurrentLinkedDeque` is an $O(N)$ linear traversal, violating Redis's $O(1)$ guarantee. |

## How It Flows

```
1. Existing list check:
Client -> LLEN queue
Server:
  list = listStore.get("queue")
  list != null
  synchronized (list) -> length = 4
Server -> :4\r\n

2. Non-existent list check:
Client -> LLEN nonexistent_key
Server:
  list = listStore.get("nonexistent_key")
  list == null -> length = 0
Server -> :0\r\n

3. Incorrect arguments:
Client -> LLEN
Server -> -ERR wrong number of arguments for 'llen' command\r\n
```
