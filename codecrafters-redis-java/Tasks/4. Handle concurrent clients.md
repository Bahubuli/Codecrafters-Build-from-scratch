## What You Have to Do

The tester opens **two connections at the same time** and sends `PING` on each:

```
$ redis-cli PING   # connection A
$ redis-cli PING   # connection B   (concurrent with A)
```

It expects **two** separate `+PONG\r\n` responses. You may still ignore the payload and hardcode the reply — this stage is purely about serving more than one client at once.

CodeCrafters hints: use **threads**, or — adventurous path — a single-threaded **event loop**, which is what real Redis does.
