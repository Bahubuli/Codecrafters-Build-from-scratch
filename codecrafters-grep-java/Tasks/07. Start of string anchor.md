# Stage 07: Start of string anchor

## In one line
The `^` anchor binds regex matching strictly to index 0 of the input line, asserting position without consuming input characters.

## Self-test (cover the answers below and answer these first)
- What distinguishes an anchor from a character class or literal token in terms of tape consumption?
- How does the meaning of `^` at index 0 of a pattern differ from `^` inside `[^...]`?
- What changes in the outer search loop when `anchorStart` is true?

## The problem it solved
By default, regex searches search for matching substrings at any position in the target text. When a match must strictly be a prefix (e.g. log line prefix `^ERROR`), unanchored regexes produce false positives on substrings. The `^` anchor constrains matching to string start.

## Concepts (the transferable part)
- **Zero-Width Assertions** — Anchors assert topological properties about cursor position (e.g. $index = 0$) rather than consuming a character codepoint.
- **Search Loop Specialization** — An unanchored search runs $\forall start \in [0, |text|]$, whereas a start-anchored search executes only at $start = 0$.
- **Grammar Disambiguation** — Context determines whether `^` is an anchor (token position 0 in pattern) or negation (first char inside brackets).

## What breaks it (failure modes)
- Conflating `^` anchor with negation inside `[^abc]`.
- Allowing start offset iteration when `^` is present (matching `app.log` against `^log`).
- Empty pattern after stripping `^` (e.g. `^` alone matches any string at index 0).

## Tradeoffs
- Parsing `^` as an engine configuration flag vs a first-class `AnchorToken`: Flagging `anchorStart` at pattern level directly specializes the outer search loop without needing pseudo-tokens in the recursion tape.

## CLI / Protocol format
- Command: `./your_program.sh -E "^log"`
- Stdin: Input line to evaluate.
- Exit code: `0` if line starts with the pattern, `1` otherwise.

## Java specifics — lookup, don't memorize
- `String.startsWith("^")` — Checks for leading anchor symbol.
- `String.substring(1)` — Slices pattern string after consuming leading anchor.
