# Stage 05: Negative character groups

## In one line
Negative character groups `[^...]` match any character that is absent from the bracketed character set, realizing set complementation in regular expression grammars.

## Self-test (cover the answers below and answer these first)
- What is the semantic difference between `[^abc]` and `[abc]`?
- What does the caret `^` signify when placed as the first character inside brackets vs at the beginning of a pattern?
- Why must a match scan through input characters and check if *any* single character satisfies the negated predicate?

## The problem it solved
Before this stage, filtering out specific delimiters, unwanted punctuation, or forbidden characters required complex exclusion logic. Negative character groups `[^...]` provide a concise declarative syntax for set complementation.

## Concepts (the transferable part)
- **Set Complement / Negation** — If universe $U$ is all valid characters and $S$ is the bracketed set, `[^S]` matches character $c$ iff $c \in U \setminus S$.
- **Context-Sensitive Metacharacters** — The caret `^` acts as set negation when directly following `[`, whereas outside brackets it acts as a line-start anchor.
- **Predicate Inversion** — Implementing negative character groups simply requires inverting the positive group predicate: `!chars.contains(c)`.

## What breaks it (failure modes)
- Caret placement — A caret not at index 0 inside brackets (`[a^b]`) is treated as a literal `^`, not a negation operator.
- All characters present in excluded set — If the input string only consists of characters inside the set (e.g. `cab` against `[^abc]`), no character satisfies the condition and the match must fail.

## Tradeoffs
- Reusing `Set<Character>` with inverted boolean return vs dedicated bitset inversion: Reusing the same underlying data structure with inverted predicate logic minimizes code duplication and avoids edge cases with large character sets.

## CLI / Protocol format
- Command: `./your_program.sh -E "[^abc]"`
- Stdin: Input line to evaluate.
- Exit code: `0` if any character outside the group is found in the input, `1` if all characters belong to the group.

## Java specifics — lookup, don't memorize
- Negation operator (`!`) — Inverts boolean return values.
- `String.startsWith("[^")` — Prefix check for detecting negated group tokens.
