# Stage 22: Implement the auto color option

## In one line
Detecting stdout TTY capabilities (`System.console() != null`) when `--color=auto` is requested, automatically enabling ANSI formatting in interactive terminals and suppressing it in pipes and file redirects.

## The problem it solved
Users running grep in an interactive shell benefit from visual colored highlights. However, when piping output (`grep --color=auto ... | wc -l` or `> output.txt`), raw ANSI sequences (`\033[01;31m`) corrupt downstream data streams and non-TTY display buffers. Supporting `--color=auto` provides dynamic TTY detection to highlight only when attached directly to an interactive terminal device.

## Concepts (the transferable part)
- **TTY Detection (`isatty`)** — POSIX utilities inspect stdout's file descriptor (`fileno 1`) using `isatty()`. In Java, `System.console() != null` determines whether the JVM process is attached to an interactive terminal console.
- **Tri-State Output Modes** — Modeling presentation flags with explicit enum states (`ALWAYS`, `NEVER`, `AUTO`):
  $$\text{shouldColor} = (\text{mode} = \text{ALWAYS}) \lor (\text{mode} = \text{AUTO} \land \text{isTTY})$$
- **Stream Transparency** — Automated fallback ensures binary clean text streams across all UNIX composition pipelines without requiring callers to manually adjust CLI flags.

## What breaks it (failure modes)
- Hardcoding `true` for auto mode — Emits ANSI escape codes into pipes, failing automated pipe testers (`| hexdump -C`).
- Hardcoding `false` for auto mode — Fails interactive terminal tests where human users expect highlighted matches.
- Failing to handle option argument formats — Only recognizing `--color=auto` but failing on `--color auto`.

## Tradeoffs
- `System.console() != null` vs JNI `isatty(1)` — `System.console()` is standard, zero-dependency Java standard library. When stdout is redirected to a pipe or file, `System.console()` evaluates to `null`.

## CLI / Protocol format
- Command: `./your_program.sh --color=auto -E "<pattern>"`
- Terminal (TTY): Emits matching line with matches wrapped in `\033[01;31m`...`\033[m`.
- Pipe / Redirect (Non-TTY): Emits pure text matching lines with no escape codes.
- Exit code: `0` on match, `1` on no match.

## Java specifics — lookup, don't memorize
- `System.console()` — Returns the unique `Console` object associated with the current Java virtual machine, or `null` if no console device is available (such as redirected stdout/stdin).
