# Stage 21: Disable highlighting

## In one line
Disabling ANSI escape formatting when `--color=never` is requested, outputting matching lines in clean plain text.

## Self-test (cover the answers below and answer these first)
- Why do pipelines and redirected file outputs in POSIX utilities require `--color=never` or automatic TTY detection?
- How does `--color=never` interact with the matching predicate and exit status codes?
- What happens to downstream command parsing (like `cut`, `awk`, or JSON parsers) if escape sequences are inadvertently included in stdout?

## The problem it solved
ANSI escape sequences (`\033[01;31m`...`\033[m`) are visual enhancements designed solely for human terminal viewers. When grep output is redirected to files, scripts, or other CLI filters, embedded escape sequences corrupt data streams. Supporting `--color=never` allows callers to guarantee pure, unadorned text output while retaining grep's matching and exit-code semantics.

## Concepts (the transferable part)
- **Presentation Layer Decoupling** — Separating the data filtering core from the output presentation layer. The match determination logic is invariant regardless of whether output is raw, formatted, or suppressed.
- **Terminal Control Escape Sequence Suppression** — Disabling SGR sequences preserves byte-for-byte stream integrity for downstream pipelines (`grep | awk | sed`).
- **Idempotent CLI Option Defaults** — When color is explicitly disabled (`--color=never`), the engine defaults to transparent record passthrough (`System.out.println(line)`).

## What breaks it (failure modes)
- Escape sequence leakage — If any ANSI bytes escape into the output under `--color=never`, pipeline parsers fail or emit corrupted text.
- Suppressing output altogether — Mistaking "disable color" for "suppress output" (which is `-q` / `--quiet`, not `--color=never`).
- Inverted exit codes — Exiting with non-zero on valid matches simply because color formatting was skipped.

## Tradeoffs
- Parsing explicit enum states (`ColorMode.ALWAYS`, `NEVER`, `AUTO`) vs boolean flag: An explicit tri-state cleanly models POSIX specifications while keeping the branching logic in the presentation pipeline minimal.

## CLI / Protocol format
- Command: `./your_program.sh --color=never -E "<pattern>"`
- Stdin: Plain text stream.
- Stdout: Clean plain text of matching lines without any `\033` escape bytes.
- Exit code:
  - `0` if at least one line matched.
  - `1` if zero lines matched.

## Java specifics — lookup, don't memorize
- `String.startsWith("--color=")` — Checks option prefix.
- `String.substring(int)` — Extracts option value after the `=` sign.
- `System.out.println(line)` — Emits the exact, unformatted string.
