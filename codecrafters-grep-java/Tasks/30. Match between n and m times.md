# Stage 30: Match between n and m times

## In one line
Implementing bounded-interval repetition `{n,m}` with inclusive minimum and maximum limits (`min = n`, `max = m`), greedy evaluation, and backtracking across the valid repetition window.

- Why does `ca{2,4}t` fail on `caaaaat` when five `a`s precede the trailing `t`?

## The problem it solved
Many practical patterns require strict upper and lower bounds—such as validating postal codes (e.g. 5 to 9 digits), username lengths (e.g. 3 to 16 characters), or hex color codes (e.g. 3 or 6 hex digits). Unbounded quantifiers allow malformed payloads to match, while nested single repetitions require combinatorial branches. The `{n,m}` syntax provides exact interval bounds.

## Concepts (the transferable part)
- **Range-Bounded Quantifier**: Explicitly specifies inclusive minimum $n$ and maximum $m$.
- **Bounded Greedy Backtracking**:
  1. Parse `{n,m}` by extracting comma-separated integers within curly braces.
  2. Consume matching tokens up to $\min(\text{available}, m)$.
  3. Validate $\text{count} \ge n$. If $\text{count} < n$, the branch immediately fails.
  4. Iterate match candidate lengths from $\text{count}$ down to $n$, evaluating downstream nodes until a valid terminal path is established.

## What breaks it (failure modes)
- Permitting consumption past $m$ (e.g. consuming 5 characters for `{2,4}`).
- Accepting fewer than $n$ characters.
- Inverting the bounds (handling $n > m$ without proper validation).
- Truncating multi-digit ranges like `{10,20}`.

## Tradeoffs
- Static bounds vs Dynamic repetition expansion — Backtracking dynamically between $[n, m]$ avoids bloating the AST with unrolled token sequences.

## CLI / Protocol format
- Command: `./your_program.sh -E "<pattern_with_{n,m}>"`
- Output:
  - Prints matched line(s) to stdout.
  - Exits with `0` on match, `1` on mismatch.

## Java specifics — lookup, don't memorize
- `parts = content.split(",", -1)` — splits bounds string into lower and upper parts.
- `Integer.parseInt(parts[0].trim())` and `Integer.parseInt(parts[1].trim())` — parses $n$ and $m$.
- `Quantifier.range(min, max)` — builds interval-bounded quantifier object.
