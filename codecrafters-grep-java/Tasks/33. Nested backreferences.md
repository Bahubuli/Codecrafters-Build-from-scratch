# Stage 33: Nested backreferences

## In one line
Propagating inner capturing group state out of nested sub-AST branches via a composite `MatchResult(endPos, capturedGroups)` container so both nested and enclosing group bindings remain accessible downstream.

## Self-test (cover the answers below and answer these first)
- In the pattern `('(cat) and \2') is the same as \1`, which group number corresponds to `(cat)` and which to the outer group?
- Why does returning only `int endPos` from branch matching fail when an inner group needs to be referenced outside its enclosing parent?
- When groups are nested, what is the exact numbering rule for assigning capture IDs?

## The problem it solved
Hierarchical syntax (such as quotation wrapping, parenthetical expressions, or XML tags) contains sub-components where inner entities must match internal backreferences, while the outer composite entity must simultaneously be captured as a whole. If capture maps are scoped strictly locally within branch recursion and discarded upon exit, outer nodes lose visibility into inner captures.

## Concepts (the transferable part)
- **1-Based Pre-order Group Indexing**: Group IDs are assigned strictly in increasing order ($1, 2, \dots$) as opening parentheses `(` are encountered left-to-right in the pattern string, regardless of nesting depth.
- **MatchResult Encapsulation**: Rather than passing scalar endpoint integers, branch matchers return `MatchResult` tuples holding both the endpoint offset and the cumulative `capturedGroups` map produced along that specific branch.
- **Layered Capture Merging**:
  1. Outer group invokes branch matcher with existing `capturedGroups`.
  2. Inner group adds capture `put(innerId, innerSubstr)` to its branch result.
  3. When inner branch completes, outer group copies the accumulated inner captures, adds `put(outerId, outerSubstr)`, and forwards the unified table to downstream matchers.

## What breaks it (failure modes)
- Discarding inner capture entries upon outer group completion.
- Numbering groups based on closing parenthesis order instead of opening parenthesis order.
- Shallow-sharing capture maps across alternative branches, allowing one failed branch's captures to bleed into another.

## Tradeoffs
- Returning `List<MatchResult>` vs Mutable Backtracking Undo Stack — Creating immutable result tuples cleanly supports branching and backtracking without requiring explicit undo stacks.

## CLI / Protocol format
- Command: `./your_program.sh -E "('(cat) and \2') is the same as \1"`
- Output:
  - Prints matched line(s) to stdout.
  - Exits with `0` on match, `1` on mismatch.

## Java specifics — lookup, don't memorize
- `static class MatchResult { final int endPos; final Map<Integer, String> capturedGroups; ... }` — composite return record.
- `Map<Integer, String> newCaptured = new HashMap<>(mr.capturedGroups)` — preserves nested group bindings.
