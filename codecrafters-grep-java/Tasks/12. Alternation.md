# Stage 12: Alternation

## In one line
Alternation evaluates subpattern branches `(pattern1|pattern2)` by trying each option in left-to-right order and continuing matching if any branch succeeds.

## Self-test (cover the answers below and answer these first)
- How does the `|` pipe operator create branching paths in the regex evaluation graph?
- Why must the subpattern inside parentheses be parsed into isolated alternative token sequences?
- When multiple branches match, why does deterministic leftmost alternation take precedence?

## The problem it solved
Regexes previously only matched fixed token sequences. Recognizing multiple distinct lexical variants (such as `(cat|dog)`, `(red|blue|green)`, or `I like (cats|dogs)`) required running multiple regexes. Alternation introduces disjunction directly into the syntax.

## Concepts (the transferable part)
- **Disjunction / Branching Operator** — The `|` operator specifies logical OR across subpatterns.
- **Hierarchical Group Parsing** — Parentheses `(...)` bound the scope of alternation, preventing `cat|dog` from affecting outer prefix/suffix tokens.
- **Backtracking Branch Explorer** — For each alternative branch $b \in \text{alternatives}$, the engine evaluates whether $b$ matches starting at the current cursor; on failure, it resets to the branch start and tries the next alternative.

## What breaks it (failure modes)
- Unscoped alternation — Confusing `cat|dog` with `(cat|dog)` if enclosing parenthesis boundaries are not parsed properly.
- Literal pipe — Escaped `\|` must match a literal pipe character, not trigger alternation.
- Nested or multi-way alternatives — Patterns with 3+ branches like `(red|blue|green)`.

## Tradeoffs
- Recursive descent AST parsing (`GroupNode` with alternatives) vs string expansion: Full AST parsing properly preserves token bounds and seamlessly generalizes to capture groups and backreferences in Stage 13.

## CLI / Protocol format
- Command: `./your_program.sh -E "(cat|dog)"`
- Stdin: Target input line.
- Exit code: `0` on match, `1` otherwise.

## Java specifics — lookup, don't memorize
- Recursive subpattern parsing:
  ```java
  while (pos < pattern.length() && pattern.charAt(pos) != ')') {
      alternatives.add(parseSequence(')'));
      if (pos < pattern.length() && pattern.charAt(pos) == '|') pos++;
  }
  ```
