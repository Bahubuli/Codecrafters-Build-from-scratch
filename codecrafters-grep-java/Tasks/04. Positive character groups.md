# Stage 04: Positive character groups

## In one line
Positive character groups `[...]` define ad-hoc character sets that match if the inspected character belongs to any element in the bracketed list.

## Self-test (cover the answers below and answer these first)
- How does the parsing of character groups differ from sequential literal tokens?
- Why is a hash set or bitset ideal for matching character groups?
- What happens if the bracket syntax is unclosed or malformed?

## The problem it solved
Predefined classes (`\d`, `\w`) only represent fixed categories of characters. Programmers frequently need custom subsets, such as matching only vowels `[aeiou]` or specific punctuation. Positive character groups provide user-defined character sets.

## Concepts (the transferable part)
- **Extensional Set Definition** — Specifying a set by explicitly enumerating its members rather than relying on an intentional rule.
- **Bracket Parser Delimitation** — Detecting open `[` and matching close `]` delimiters and extracting the inner characters as a set.
- **Set Membership Check** — Evaluating whether the target character $c \in S$ using $O(1)$ lookup.

## What breaks it (failure modes)
- Special characters inside brackets — Characters like `.` or `*` inside character classes behave as literals unless escaped or hyphenated.
- Empty bracket groups `[]` — Depending on specification, empty groups are either illegal syntax or represent a literal `]`.
- Bracket order and nested brackets — Unmatched or improperly ordered brackets disrupt tokenization boundaries.

## Tradeoffs
- `Set<Character>` vs `boolean[128]` / `BitSet`: `Set<Character>` handles arbitrary characters cleanly in high-level Java, while a `BitSet` or boolean table provides cache-friendly zero-allocation checks.

## CLI / Protocol format
- Command: `./your_program.sh -E "[abc]"`
- Stdin: Input line to evaluate.
- Exit code: `0` if any character in the group matches, `1` otherwise.

## Java specifics — lookup, don't memorize
- `java.util.HashSet` — Implements the `Set` interface, backed by a hash table with constant-time basic operations.
- `String.substring(int beginIndex, int endIndex)` — Extracts the bracket inner content excluding delimiters.
