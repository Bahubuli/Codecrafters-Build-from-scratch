# Stage 08: End of string anchor

## In one line
The `$` anchor asserts that the consumed pattern sequence must reach exactly the terminus of the input string (`textIdx == inputLine.length()`).

## Self-test (cover the answers below and answer these first)
- Why must `$` be checked when the token sequence completes rather than matching a physical character?
- How do `^` and `$` work together to enforce exact full-string matching?
- If a pattern ends with `$`, what happens when a valid token sequence matches an interior substring?

## The problem it solved
Without `$`, a pattern like `dog` matches prefixes and substrings (e.g. `dogs`, `doghouse`). When an application requires matching file extensions (`.txt$`) or ensuring exact suffix constraints, `$` prevents downstream characters from matching.

## Concepts (the transferable part)
- **Terminal Zero-Width Assertion** — `$` checks that the input cursor has exhausted the text (`textIdx == text.length()`) without consuming trailing characters.
- **Exact String Invariance** — Combining `^pattern$` guarantees that the input matches the pattern entirely from index 0 to index $N$, transforming substring search into strict full-string verification.
- **Backtracking Termination Predicate** — In a recursive matcher, the base case `tokenIdx == tokens.size()` evaluates `if (anchorEnd) return textIdx == text.length();`.

## What breaks it (failure modes)
- Accepting a match that has unconsumed trailing characters when `$` is specified.
- Trailing `\$` escaped literals — An escaped dollar sign `\$` must be parsed as a literal character, not an end anchor.
- Empty string matching — `^$` should successfully match an empty string, while `^cat$` must reject it.

## Tradeoffs
- Parameter flag `anchorEnd` in `matchesAt` vs a dedicated `EndAnchorToken`: Passing `boolean anchorEnd` directly to the recursive terminal condition avoids synthetic token handling at the end of the token stream.

## CLI / Protocol format
- Command: `./your_program.sh -E "cat$"`
- Stdin: Input line to evaluate.
- Exit code: `0` if pattern matches up to string end, `1` otherwise.

## Java specifics — lookup, don't memorize
- `String.endsWith("$")` — Detects terminal anchor symbol.
- `String.length()` — Compares `textIdx == inputLine.length()` to verify exact string exhaustion.
