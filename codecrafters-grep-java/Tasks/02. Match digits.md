# Stage 02: Match digits

## In one line
A character class represents a set of characters that can match a single position, introducing the digit class `\d` to match any numeric character 0 through 9.

## Self-test (cover the answers below and answer these first)
- What distinguishes a character class token like `\d` from a literal sequence `\d`?
- How does the time complexity of scanning for a character class compare to scanning for a literal character?
- Why is an interface-based or polymorphic token model superior to hardcoding string inspections as patterns grow in complexity?

## The problem it solved
Prior to this stage, grep could only match specific hardcoded literal characters. To find digits without character classes, a caller would have to execute multiple separate searches for `0`, `1`, ..., `9`. The `\d` metacharacter solves this by establishing an abstract predicate matching any decimal digit `[0-9]`.

## Concepts (the transferable part)
- **Character Classes / Sets** — A character class maps multiple discrete codepoints to a single generalized token evaluation.
- **Escape Sequences in Regex** — Backslashes (`\`) serve as an escape indicator changing literal characters into special syntactic operators (`\d` denotes digit rather than literal `d`).
- **Polymorphic Token Matching** — Defining a unified `Token` abstraction decoupling token-specific acceptance predicates (`matches(char c)`) from the outer scanning and cursor management algorithms.

## What breaks it (failure modes)
- Escaping differences in CLI shells — Depending on the shell or language string literals, `\d` may require double escaping (`\\d`) during argument handling.
- Non-digit characters adjacent to digits — Matchers must test individual characters across the input line rather than expecting whole-string digit conformity.
- Empty input line — Input with length 0 must cleanly report no match without out-of-bounds errors.

## Tradeoffs
- Polymorphic token object model vs direct `switch` / `if`: Polymorphic token objects add small allocation overhead per query, but establish a clean open-closed design easily extensible to compound patterns, groups, quantifiers, and alternation.

## CLI / Protocol format
- Command: `./your_program.sh -E "\d"`
- Stdin: Input line to evaluate.
- Exit code: `0` if at least one digit is present in the line, `1` otherwise.

## Java specifics — lookup, don't memorize
- `Character.isDigit(char ch)` — Determines whether the specified character is a digit according to Java's Unicode/ASCII definitions.
- `String.charAt(int index)` — Returns the `char` value at the specified index within the string.
