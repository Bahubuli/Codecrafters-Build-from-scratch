# Stage 51: Background Jobs - Reap multiple jobs

## In one line
Extend background job reaping to loop over all active jobs, display finished jobs as `Done` with current position markers (`+`, `-`, or space), and purge them so subsequent queries show shifted markers for remaining running jobs.

---

## Self-test
Can you answer these questions from memory?
1. If three background jobs were running (jobs 1, 2, 3 with markers ` `, `-`, `+`) and jobs 2 and 3 terminate, how does the first `jobs` invocation format them?
2. What marker does job 1 receive on the subsequent `jobs` query after jobs 2 and 3 have been removed?
3. Are job numbers preserved when other jobs are reaped?
4. How often does a completed job display `Done` in `jobs` output?

---

## Problem Solved
When several jobs terminate concurrently or between `jobs` commands, the shell must iterate through all tracked jobs, check process termination non-blockingly, format `Done` jobs without trailing `&`, and remove them from the job table. On subsequent queries, marker assignment (`+` for latest, `-` for second latest, ` ` for older) naturally recalibrates over the remaining alive jobs.

---

## Concepts
- **Batch Reaping**: Iterating through all jobs in launch order, identifying all terminated processes in a single pass.
- **Marker Re-assignment**:
  - During the query, markers correspond to relative index positions (`n - 1` gets `+`, `n - 2` gets `-`).
  - After completed jobs are removed, the next `jobs` command evaluates the remaining jobs list (e.g., if only 1 job remains, it now gets `+`).
- **Stable IDs**: Job identifiers (e.g. `[1]`, `[2]`, `[3]`) remain constant; only their marker symbols change dynamically.

---

## The Solution
In `codecrafters-shell-java/src/main/java/Main.java`:
```java
} else if (command.equals("jobs")) {
    int n = backgroundJobs.size();
    List<Job> remainingJobs = new ArrayList<>();
    for (int j = 0; j < n; j++) {
        Job job = backgroundJobs.get(j);
        String marker = " ";
        if (j == n - 1) {
            marker = "+";
        } else if (j == n - 2) {
            marker = "-";
        }
        boolean isAlive = job.process != null && job.process.isAlive();
        String status = isAlive ? "Running" : "Done";
        String trailing = isAlive ? " &" : "";
        out.printf("[%d]%s  %-24s%s%s\n", job.id, marker, status, job.command, trailing);
        if (isAlive) {
            remainingJobs.add(job);
        }
    }
    backgroundJobs.clear();
    backgroundJobs.addAll(remainingJobs);
}
```

---

## Failure Modes
- **Marker desync**: Computing markers against original launched count instead of current table count before/after pruning.
- **Modifying during iteration**: Directly removing elements from `backgroundJobs` inside the loop causes `IndexOutOfBoundsException` or `ConcurrentModificationException`. Collecting `remainingJobs` and updating `backgroundJobs` after iteration guarantees safety.
- **Missing exits**: Checking only the first exited job instead of checking every job in `backgroundJobs`.

---

## Tradeoffs
- Rebuilding the active job list via `clear()` and `addAll(remainingJobs)` is clean, deterministic, and avoids off-by-one indexing bugs when multiple jobs finish at once.

## CLI / Protocol format
```bash
$ sleep 500 &
[1] 1318
$ cat /tmp/strawberry &
[2] 1319
$ cat /tmp/pineapple &
[3] 1321
$ # job 2 finishes
$ jobs
[1]   Running                 sleep 500 &
[2]-  Done                    cat /tmp/strawberry
[3]+  Running                 cat /tmp/pineapple &
$ # job 3 finishes
$ jobs
[1]-  Running                 sleep 500 &
[3]+  Done                    cat /tmp/pineapple
$ jobs
[1]+  Running                 sleep 500 &
```

---

## Java specifics
- `List.clear()` followed by `List.addAll()` mutates in-place, compatible with `static final List<Job>`.
- `job.process.isAlive()` is thread-safe and non-blocking.

## Rebuild checklist
1. Maintain jobs in chronological order in `backgroundJobs`.
2. On `jobs`, retrieve size `n`.
3. Loop `0 <= j < n`:
   - If `j == n - 1`, `marker = "+"`.
   - Else if `j == n - 2`, `marker = "-"`.
   - Else `marker = " "`.
   - If `job.process.isAlive()`, `status = "Running"`, `trailing = " &"`, add to `remainingJobs`.
   - Else `status = "Done"`, `trailing = ""`.
   - Format: `[%d]%s  %-24s%s%s\n`.
4. Replace `backgroundJobs` with `remainingJobs`.
