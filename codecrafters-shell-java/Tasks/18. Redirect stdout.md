# Stage 18: Redirect stdout

---

## In one line
Intercept file redirection operators (`>` and `1>`) to redirect a command's standard output stream to a target file (creating or truncating it) while preserving standard error on the terminal.

---

## Self-test (cover the answers below and answer these first)
- What is the difference between `>` and `1>` in standard POSIX shell syntax?
- Why must standard error (`stderr`, fd 2) remain connected to the terminal when redirecting standard output (`stdout`, fd 1) with `>`?
- What happens to an existing target file when standard output is redirected to it using `>`?
- What should happen if the destination file or its parent directories do not yet exist?
- Why must redirection operators and their target paths be stripped from the argument list passed to the executed command or builtin?
- What happens if a command produces no standard output (or fails before writing stdout) when `>` is used (e.g. `cat nonexistent > out.txt`)?

---

## The problem it solved
Previously, all output from commands—both internal builtins (`echo`, `pwd`, `type`) and external binaries executed via `ProcessBuilder`—was streamed directly to the terminal's standard output. Shells require the capability to persist output into files for logging, pipeline composition, and data processing. Furthermore, when redirecting standard output, error diagnostics emitted to `stderr` must not contaminate the output file; they must remain visible on the terminal console so that failures can be diagnosed.

---

## Concepts (the transferable part)

- **[CONCEPT] File Descriptors & Standard Streams** — Every process starts with three default POSIX file descriptors: `0` (`stdin`), `1` (`stdout`), and `2` (`stderr`). The redirection operator `>` is syntactic shorthand for `1>`, meaning "redirect file descriptor 1 to the file path operand".
- **[CONCEPT] Stream Separation** — Standard output carries the program's normal operational data, while standard error carries diagnostic messages and errors. When `1>` or `>` is used, only file descriptor 1 is redirected; file descriptor 2 remains connected to the terminal device (`/dev/tty` or inherited stderr).
- **[CONCEPT] Shell-Level Stream Redirection vs Process Arguments** — Redirection operators (`>`, `1>`, `2>`, etc.) are directives consumed by the shell itself, not arguments intended for the program being invoked. The shell must inspect the parsed arguments, configure the child process or internal stream accordingly, and strip the operator and filename from the final argv passed to the command.
- **[CONCEPT] Truncation Semantics (`O_TRUNC | O_CREAT`)** — The `>` redirection operator mandates that if the target file exists, its contents are discarded (truncated to 0 bytes) prior to writing. If it does not exist, it is created along with any necessary parent directories. Even if the executing command produces zero bytes on stdout, the empty file must still be created.

## The Solution

```java
import java.io.File;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }

            // Scan for stdout redirection operator (> or 1>)
            List<String> cmdArgs = new ArrayList<>();
            String redirectOutFile = null;

            for (int i = 0; i < parsedArgs.size(); i++) {
                String arg = parsedArgs.get(i);
                if ((arg.equals(">") || arg.equals("1>")) && i + 1 < parsedArgs.size()) {
                    redirectOutFile = parsedArgs.get(i + 1);
                    Path p = resolvePath(redirectOutFile);
                    if (p.getParent() != null) {
                        Files.createDirectories(p.getParent());
                    }
                    Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
                    i++;
                } else if (arg.startsWith(">") && !arg.startsWith(">>") && arg.length() > 1) {
                    redirectOutFile = arg.substring(1);
                    Path p = resolvePath(redirectOutFile);
                    if (p.getParent() != null) {
                        Files.createDirectories(p.getParent());
                    }
                    Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
                } else if (arg.startsWith("1>") && !arg.startsWith("1>>") && arg.length() > 2) {
                    redirectOutFile = arg.substring(2);
                    Path p = resolvePath(redirectOutFile);
                    if (p.getParent() != null) {
                        Files.createDirectories(p.getParent());
                    }
                    Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
                } else {
                    cmdArgs.add(arg);
                }
            }

            if (cmdArgs.isEmpty()) {
                continue;
            }

            String command = cmdArgs.get(0);
            Path outPath = redirectOutFile != null ? resolvePath(redirectOutFile) : null;

            if (BUILTINS.contains(command)) {
                PrintStream out = System.out;
                boolean closeOut = false;
                if (outPath != null) {
                    out = new PrintStream(Files.newOutputStream(outPath,
                            StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE));
                    closeOut = true;
                }

                try {
                    if (command.equals("exit")) {
                        int exitCode = 0;
                        if (cmdArgs.size() > 1) {
                            try {
                                exitCode = Integer.parseInt(cmdArgs.get(1));
                            } catch (NumberFormatException ignored) {
                            }
                        }
                        if (closeOut) {
                            out.close();
                            closeOut = false;
                        }
                        System.exit(exitCode);
                    } else if (command.equals("echo")) {
                        String output = String.join(" ", cmdArgs.subList(1, cmdArgs.size()));
                        out.println(output);
                    } else if (command.equals("type")) {
                        if (cmdArgs.size() > 1) {
                            String target = cmdArgs.get(1);
                            if (BUILTINS.contains(target)) {
                                out.println(target + " is a shell builtin");
                            } else {
                                Path executable = findExecutable(target);
                                if (executable != null) {
                                    out.println(target + " is " + executable);
                                } else {
                                    out.println(target + ": not found");
                                }
                            }
                        }
                    } else if (command.equals("pwd")) {
                        out.println(currentDir);
                    } else if (command.equals("cd")) {
                        String home = System.getenv("HOME");
                        if (home == null || home.isEmpty()) {
                            home = System.getProperty("user.home");
                        }
                        String targetPath = cmdArgs.size() > 1 ? cmdArgs.get(1) : home;
                        if (targetPath.equals("~")) {
                            targetPath = home;
                        } else if (targetPath.startsWith("~/")) {
                            targetPath = home + targetPath.substring(1);
                        }

                        Path target = currentDir.resolve(targetPath).normalize();
                        if (Files.isDirectory(target)) {
                            currentDir = target;
                        } else {
                            System.out.println("cd: " + targetPath + ": No such file or directory");
                        }
                    }
                } finally {
                    if (closeOut) {
                        out.close();
                    }
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(cmdArgs);
                    pb.directory(currentDir.toFile());
                    if (outPath != null) {
                        pb.redirectOutput(outPath.toFile());
                    } else {
                        pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);
                    }
                    pb.redirectError(ProcessBuilder.Redirect.INHERIT);
                    pb.redirectInput(ProcessBuilder.Redirect.INHERIT);
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static Path resolvePath(String pathStr) {
        String home = System.getenv("HOME");
        if (home == null || home.isEmpty()) {
            home = System.getProperty("user.home");
        }
        if (pathStr.equals("~")) {
            pathStr = home;
        } else if (pathStr.startsWith("~/")) {
            pathStr = home + pathStr.substring(1);
        }
        return currentDir.resolve(pathStr).normalize();
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        char next = input.charAt(i + 1);
                        if (next == '\"' || next == '\\' || next == '$' || next == '`') {
                            i++;
                            current.append(next);
                        } else {
                            current.append(c);
                        }
                    } else {
                        current.append(c);
                    }
                } else if (c == '\"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '\"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Leaking Redirection Operator into Command Arguments** — Passing `>` and `/tmp/out.txt` as arguments to the child process (e.g. `ls /tmp/baz > /tmp/out.txt` passing 3 args to `ls`) causes commands like `ls` to report `ls: cannot access '>': No such file or directory`. Redirection tokens must be stripped before process dispatch.
- **Accidentally Redirecting Standard Error** — Using `pb.redirectErrorStream(true)` or merging streams causes errors (e.g., `cat: nonexistent: No such file or directory`) to be written into the target file instead of appearing on the user's terminal.
- **Missing Parent Directories** — Writing to `/tmp/foo/baz.md` when `/tmp/foo` does not exist throws a `NoSuchFileException` or `IOException`. Always ensure parent directories are created via `Files.createDirectories(path.getParent())`.
- **Holding File Handles Open Across External Execution** — Opening an output stream on the destination file in Java before launching an external process via `ProcessBuilder` can lock the file or lead to buffer clobbering upon flush/close. Builtin streams must only be opened during builtin execution.
- **Omitting 0-byte File Creation on Command Failure** — If `cat nonexistent > out.txt` is run, `out.txt` must still be created (and truncated if existing). Creating/truncating the file upfront during redirection parsing guarantees this invariant.

---

## Tradeoffs

- **Pre-Execution Truncation vs On-Demand Opening** — Creating/truncating destination files during the argument scanning phase accurately mimics POSIX shell semantics where file descriptors are established before command execution begins. This ensures empty files are created even if the executed binary fails or produces no stdout.
- **Targeted Builtin `PrintStream` vs `System.setOut`** — Reassigning JVM-wide `System.setOut` mutates global state, requiring careful resetting and introducing hazards in multithreaded environments. Passing a localized `PrintStream out` to builtins keeps stream redirection scoped and thread-safe.

---

## CLI / Protocol format

- **Standard output redirection (`>`)**:
  ```
  $ ls /tmp/baz > /tmp/foo/baz.md
  $ cat /tmp/foo/baz.md
  apple
  blueberry
  ```
- **Explicit file descriptor 1 redirection (`1>`)**:
  ```
  $ echo Hello James 1> /tmp/foo/foo.md
  $ cat /tmp/foo/foo.md
  Hello James
  ```
- **Standard error remains on terminal**:
  ```
  $ cat /tmp/baz/blueberry nonexistent 1> /tmp/foo/quz.md
  cat: nonexistent: No such file or directory
  $ cat /tmp/foo/quz.md
  blueberry
  ```

## Java specifics — lookup, don't memorize

- `ProcessBuilder.redirectOutput(File)` — Directs child process stdout to write directly to the specified file descriptor.
- `ProcessBuilder.Redirect.INHERIT` — Keeps child standard error connected to the parent shell's console stream.
- `Files.createDirectories(Path)` — Creates any missing ancestor directories along the target path without throwing if they already exist.
- `Files.newOutputStream(Path, StandardOpenOption...)` — Opens a file stream with explicit creation and truncation options.
- `StandardOpenOption.TRUNCATE_EXISTING` — Truncates file content to 0 bytes upon opening if it already exists.
