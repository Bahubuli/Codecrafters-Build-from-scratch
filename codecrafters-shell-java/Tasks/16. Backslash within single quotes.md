# Stage 16: Backslash within single quotes

---

## In one line
Preserve all characters—including backslashes and quotes—verbatim inside single quotes (`'...'`), preventing any escape evaluation or metacharacter interpretation.

---

## Self-test (cover the answers below and answer these first)
- Why do backslashes (`\`) have zero escape capability inside single quotes in POSIX shells?
- How does the single-quote state (`inSingleQuote`) prevent backslashes from escaping following characters, such as `\'` or `\\`?
- Can a single-quote character itself ever appear inside a single-quoted string (e.g., `'can\'t'`)? How do shells handle this?
- What happens when a single-quoted string containing backslashes is directly adjacent to an unquoted or double-quoted string (e.g., `/tmp/'one slash \2'`)?
- How does treating backslashes literally in single quotes contrast with backslash behavior inside double quotes or outside quotes?

## The problem it solved
Users and scripts frequently need to pass raw text—such as regex patterns, Windows file paths, code snippets, or escape sequences—without the shell modifying or stripping backslashes. Outside quotes, backslashes act as escape characters (`\n` -> `n`, `\ ` -> ` `). Inside single quotes, the shell enforces an absolute literal context where every character is appended verbatim to the token without any escaping mechanism or transformation, guaranteeing that `echo 'shell\\nscript'` outputs `shell\\nscript`.

---

## Concepts (the transferable part)

- **[CONCEPT] POSIX Single-Quote Verbatim Invariant** — In POSIX shell grammar, enclosing characters in single quotes preserves the literal value of each character within the quotes. A single quote cannot occur within single quotes, even when preceded by a backslash, because backslashes possess no special escape semantics.
- **[CONCEPT] Context-Dependent Escape Semantics** — Lexical analyzers must vary the syntactic meaning of characters based on parser state. While `\` acts as an active escape operator outside quotes (and partially inside double quotes), it degrades to a pure literal data character in the single-quote state machine.
- **[CONCEPT] Adjacent Word Coalescence** — Shell arguments are formed by concatenating adjacent quoted, escaped, and unquoted spans into a single word token until an unquoted whitespace boundary is encountered (e.g., `/tmp/'one slash \2'` coalesces into `/tmp/one slash \2`).

## The Solution

```java
import java.io.File;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }
            String command = parsedArgs.get(0);

            if (command.equals("exit")) {
                int exitCode = 0;
                if (parsedArgs.size() > 1) {
                    try {
                        exitCode = Integer.parseInt(parsedArgs.get(1));
                    } catch (NumberFormatException ignored) {
                    }
                }
                System.exit(exitCode);
            } else if (command.equals("echo")) {
                String output = String.join(" ", parsedArgs.subList(1, parsedArgs.size()));
                System.out.println(output);
            } else if (command.equals("type")) {
                if (parsedArgs.size() > 1) {
                    String target = parsedArgs.get(1);
                    if (BUILTINS.contains(target)) {
                        System.out.println(target + " is a shell builtin");
                    } else {
                        Path executable = findExecutable(target);
                        if (executable != null) {
                            System.out.println(target + " is " + executable);
                        } else {
                            System.out.println(target + ": not found");
                        }
                    }
                }
            } else if (command.equals("pwd")) {
                System.out.println(currentDir);
            } else if (command.equals("cd")) {
                String home = System.getenv("HOME");
                if (home == null || home.isEmpty()) {
                    home = System.getProperty("user.home");
                }
                String targetPath = parsedArgs.size() > 1 ? parsedArgs.get(1) : home;
                if (targetPath.equals("~")) {
                    targetPath = home;
                } else if (targetPath.startsWith("~/")) {
                    targetPath = home + targetPath.substring(1);
                }

                Path target = currentDir.resolve(targetPath).normalize();
                if (Files.isDirectory(target)) {
                    currentDir = target;
                } else {
                    System.out.println("cd: " + targetPath + ": No such file or directory");
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(parsedArgs);
                    pb.directory(currentDir.toFile());
                    pb.inheritIO();
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Leaking Escape Logic into Single Quotes** — If the lexer checks `if (c == '\\')` before checking `if (inSingleQuote)` or allows backslash lookahead inside single quotes, strings like `'shell\\nscript'` get corrupted to `shell\nscript` or `'test\'` attempts to escape the closing quote.
- **Attempting to Escape Single Quotes Inside Single Quotes** — Users often expect `'it\'s'` to work; in POSIX, the backslash inside single quotes is literal and does not escape the `'`. The lexer terminates the single quote at the second `'` and parses `s'` outside. To include a literal `'` in single-quoted shell words, one must exit and concatenate: `'it'\''s'`.
- **Premature Token Termination on Adjacent Quotes** — Treating the closing single quote as an argument delimiter rather than just exiting the quote mode would break concatenated arguments such as `/tmp/'path \1'`.
- **Misinterpreting Double Backslashes** — In languages like Java or C, `\\` in string literals represents a single escaped backslash. In a shell's single-quoted string, `\\` represents two literal backslashes. Lexers must not collapse pairs of backslashes inside single quotes.

---

## Tradeoffs

- **State Machine Branch Order vs Flag Modifiers** — Handling single quotes in a dedicated top-level state branch (`if (inSingleQuote)`) cleanly isolates single-quote rules from escape logic, ensuring escape characters cannot inadvertently trigger. An alternative of using a shared escape flag checked across all quote states introduces high cyclomatic complexity and risk of leaking escape behavior.
- **Strict POSIX Literalism vs Ergonomic Escaping** — Some non-standard shells attempt to allow `\'` within single quotes. Following strict POSIX standards ensures complete predictability and compatibility with standard shell scripts, requiring users to exit single quotes (`'foo'\''bar'`) if a literal single quote is needed.

## CLI / Protocol format

- **Echoing raw backslashes and escape sequences**:
  ```
  $ echo 'shell\\nscript'
  shell\\nscript
  ```
- **Echoing double quotes and backslashes inside single quotes**:
  ```
  $ echo 'example\"test'
  example\"test
  $ echo 'every\"thing_is\"literal'
  every\"thing_is\"literal
  ```
- **Multiple raw backslashes**:
  ```
  $ echo 'multiple\slashes'
  multiple\slashes
  ```
- **Concatenated path arguments with single quotes and backslashes**:
  ```
  $ cat /tmp/'no slash 1' /tmp/'one slash \2' /tmp/'two slashes \3\'
  content1 content2 content3
  ```

## Java specifics — lookup, don't memorize

- `StringBuilder.append(char c)` — Appends the literal primitive character to the active token buffer.
- `String.charAt(int index)` — Fetches the character at the specified index without allocating substrings.
- `ProcessBuilder(List<String> command)` — Passes the tokenized argument list directly to the OS process without performing another round of shell expansion.
