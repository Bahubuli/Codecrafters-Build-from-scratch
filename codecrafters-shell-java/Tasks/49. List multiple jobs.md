# Stage 49: Background Jobs - List multiple jobs

## In one line
Extend `jobs` output to format job entries with job markers (`+` for the most recent / current job, `-` for the second most recent / previous job, and a space for all older jobs).

---

## Self-test
Can you answer these questions from memory?
1. Which marker is assigned to the most recently launched background job?
2. Which marker is assigned to the second most recently launched background job?
3. What marker is assigned to all earlier background jobs?
4. In what order must jobs be displayed in `jobs` output?

---

## Problem Solved
When multiple background jobs run simultaneously, shells identify the "current" and "previous" jobs for job control targets (like `fg %` or `fg %-`). In this stage, we dynamically assign `+` to the latest background job (`j == n - 1`), `-` to the second latest (`j == n - 2`), and a single space `" "` to all other jobs.

---

## Concepts
- **Current Job (`+`)**: The job most recently started or brought to foreground/background.
- **Previous Job (`-`)**: The job started immediately prior to the current job.
- **Job Ordering**: Jobs are listed sequentially in ascending order of their job IDs.

---

## The Solution
In `codecrafters-shell-java/src/main/java/Main.java`:
```java
} else if (command.equals("jobs")) {
    int n = backgroundJobs.size();
    for (int j = 0; j < n; j++) {
        Job job = backgroundJobs.get(j);
        String marker = " ";
        if (j == n - 1) {
            marker = "+";
        } else if (j == n - 2) {
            marker = "-";
        }
        out.printf("[%d]%s  %-24s%s &\n", job.id, marker, "Running", job.command);
    }
}
```

---

## Failure Modes
- **Hardcoding `+`**: Hardcoding `+` for all jobs fails when multiple jobs exist, as earlier jobs must use `-` or space.
- **Wrong column spacing**: Omitting the space marker for older jobs shifts columns leftwards; `[%d]%s  ` preserves alignment when `marker = " "`.

---

## Tradeoffs
- Using positional indices `n - 1` and `n - 2` directly corresponds to the job launch order in append-only job lists prior to job deletion/reclamation.

---

## CLI / Protocol format
```bash
$ sleep 10 &
[1] 96643
$ sleep 20 &
[2] 96644
$ sleep 30 &
[3] 96645
$ jobs
[1]   Running                 sleep 10 &
[2]-  Running                 sleep 20 &
[3]+  Running                 sleep 30 &
```

---

## Java specifics
- `PrintStream.printf("[%d]%s  %-24s%s &\n", job.id, marker, "Running", job.command)` handles both character markers (`+`, `-`) and single-space markers (` `) with identical alignment.
