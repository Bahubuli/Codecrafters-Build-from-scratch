# Stage 36: Printing missing specifications (#oi7)

## In one line
Implements the `complete -p <command>` option to query completion specifications and reports missing specifications to standard error.

---

## Self-test
- **Prompt**: When invoking `complete -p git` when no completion specification is registered for `git`, what output is expected and on what stream?
- **Answer**: `complete: git: no completion specification` on standard error (or error stream when redirected).

---

## Problem Solved
When tools or users inspect command completion capabilities in shells (e.g. bash), `complete -p <cmd>` provides introspection into active completion rules. If no rule is registered for `<cmd>`, the shell must report `complete: <cmd>: no completion specification`.

---

## Key Concepts
1. **Introspection Flag `-p`**:
   - The `-p` flag queries existing completion rules.
   - For any unregistered command, it outputs `complete: <command>: no completion specification`.
2. **Error Stream Routing**:
   - Builtin execution now manages both `out` (`PrintStream` to standard out or file via `> / >>`) and `err` (`PrintStream` to standard err or file via `2> / 2>>`).
   - Reporting errors via `err.println(...)` ensures that stderr redirections (like `2>`) properly capture builtin diagnostic messages.

---

## The Solution
In `Main.java`:
```java
} else if (command.equals("complete")) {
    if (cmdArgs.size() >= 3 && cmdArgs.get(1).equals("-p")) {
        String target = cmdArgs.get(2);
        err.println("complete: " + target + ": no completion specification");
    }
}
```

---

## Failure Modes & Bugs Prevented
- **Hardcoding Standard Err**:
  - Routing via `err` rather than hardcoded `System.err` ensures consistency if redirection operators like `2>` or `2>>` are attached to `complete -p`.
- **Command Argument Safety**:
  - Bounds-checking `cmdArgs.size() >= 3` prevents `IndexOutOfBoundsException` when the user enters incomplete flags.

---

## CLI / Protocol Format
```bash
$ complete -p git
complete: git: no completion specification
```
