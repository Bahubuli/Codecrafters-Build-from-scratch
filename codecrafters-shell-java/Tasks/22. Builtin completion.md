## The problem it solved
Previously, our shell used standard line-buffered input (`Scanner.nextLine()`), which delegates line editing and input buffering to the operating system's terminal driver in canonical mode. In canonical mode, the terminal driver buffers input until the user presses Enter (`\n`), meaning individual keystrokes like `<TAB>` (ASCII 9) are never delivered in real time to the shell program. By switching the terminal to non-canonical, no-echo mode, the shell intercepts every raw keystroke as it happens, completes unique builtin prefixes like `ech` -> `echo `, and retains interactive editing control.

---

## Concepts (the transferable part)

- **[CONCEPT] Terminal Canonical vs Non-Canonical Mode (`icanon`)** — By default, POSIX terminal line disciplines operate in canonical (cooked) mode: lines are assembled by the OS kernel, line-editing (backspace/erase) is handled in-kernel, and keystrokes are only returned to `read()` when a delimiter (`\n`) is encountered. In non-canonical (raw/cbreak) mode (`-icanon`), keystrokes are delivered immediately to the reading process byte-by-byte without waiting for a newline.
- **[CONCEPT] Terminal Echoing (`echo` vs `-echo`)** — In default terminal mode, every character typed is immediately echoed back to the screen by the kernel tty driver. When disabling canonical mode, we must also disable kernel echo (`-echo`). The shell program becomes fully responsible for deciding what characters appear on screen (echoing regular characters, erasing on backspace, printing completions on tab).
- **[CONCEPT] The Controlling Terminal (`/dev/tty`)** — In Unix, `/dev/tty` is a special device file representing the controlling terminal of the process group, independent of standard stream redirections. Invoking `stty` on `/dev/tty` directly configures the hardware or pseudo-terminal (pty) driver.
- **[CONCEPT] Terminal State Restoration & Process Hygiene** — Terminal state is persistent on the tty device. If a shell process exits while `-icanon -echo` is active, the user's terminal remains broken (no echo, weird carriage returns). Registering a shutdown hook to invoke `stty sane` and temporarily restoring canonical mode before running child processes (via `ProcessBuilder`) guarantees terminal integrity.
- **[CONCEPT] Real-Time I/O Flushing** — In interactive character-at-a-time REPLs, output streams buffer bytes until a newline or buffer overflow occurs. When printing individual typed characters or completion strings without newlines, explicit buffer flushing (`System.out.flush()`) is required so that the user and testing harnesses receive output without delay.

## The Solution

```java
import java.io.File;
import java.io.IOException;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.ArrayList;
import java.util.List;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        enableRawMode();

        while (true) {
            System.out.print("$ ");
            System.out.flush();
            String input = readLineWithCompletion();
            if (input == null) {
                break;
            }
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }

            // Scan for redirection operators (>>, 1>>, >, 1>, 2>>, 2>)
            List<String> cmdArgs = new ArrayList<>();
            String redirectOutFile = null;
            String redirectErrFile = null;
            boolean appendOut = false;
            boolean appendErr = false;

            for (int i = 0; i < parsedArgs.size(); i++) {
                String arg = parsedArgs.get(i);
                if ((arg.equals(">>") || arg.equals("1>>")) && i + 1 < parsedArgs.size()) {
                    appendOut = true;
                    redirectOutFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectOutFile, true);
                    i++;
                } else if (arg.equals("2>>") && i + 1 < parsedArgs.size()) {
                    appendErr = true;
                    redirectErrFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectErrFile, true);
                    i++;
                } else if (arg.startsWith(">>") && arg.length() > 2) {
                    appendOut = true;
                    redirectOutFile = arg.substring(2);
                    prepareRedirectionFile(redirectOutFile, true);
                } else if (arg.startsWith("1>>") && arg.length() > 3) {
                    appendOut = true;
                    redirectOutFile = arg.substring(3);
                    prepareRedirectionFile(redirectOutFile, true);
                } else if (arg.startsWith("2>>") && arg.length() > 3) {
                    appendErr = true;
                    redirectErrFile = arg.substring(3);
                    prepareRedirectionFile(redirectErrFile, true);
                } else if ((arg.equals(">") || arg.equals("1>")) && i + 1 < parsedArgs.size()) {
                    appendOut = false;
                    redirectOutFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectOutFile, false);
                    i++;
                } else if (arg.equals("2>") && i + 1 < parsedArgs.size()) {
                    appendErr = false;
                    redirectErrFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectErrFile, false);
                    i++;
                } else if (arg.startsWith(">") && !arg.startsWith(">>") && arg.length() > 1) {
                    appendOut = false;
                    redirectOutFile = arg.substring(1);
                    prepareRedirectionFile(redirectOutFile, false);
                } else if (arg.startsWith("1>") && !arg.startsWith("1>>") && arg.length() > 2) {
                    appendOut = false;
                    redirectOutFile = arg.substring(2);
                    prepareRedirectionFile(redirectOutFile, false);
                } else if (arg.startsWith("2>") && !arg.startsWith("2>>") && arg.length() > 2) {
                    appendErr = false;
                    redirectErrFile = arg.substring(2);
                    prepareRedirectionFile(redirectErrFile, false);
                } else {
                    cmdArgs.add(arg);
                }
            }

            if (cmdArgs.isEmpty()) {
                continue;
            }

            String command = cmdArgs.get(0);
            Path outPath = redirectOutFile != null ? resolvePath(redirectOutFile) : null;
            Path errPath = redirectErrFile != null ? resolvePath(redirectErrFile) : null;

            if (BUILTINS.contains(command)) {
                PrintStream out = System.out;
                boolean closeOut = false;
                if (outPath != null) {
                    out = new PrintStream(Files.newOutputStream(outPath,
                            StandardOpenOption.CREATE,
                            appendOut ? StandardOpenOption.APPEND : StandardOpenOption.TRUNCATE_EXISTING,
                            StandardOpenOption.WRITE));
                    closeOut = true;
                }

                try {
                    if (command.equals("exit")) {
                        int exitCode = 0;
                        if (cmdArgs.size() > 1) {
                            try {
                                exitCode = Integer.parseInt(cmdArgs.get(1));
                            } catch (NumberFormatException ignored) {
                            }
                        }
                        if (closeOut) {
                            out.close();
                            closeOut = false;
                        }
                        setRawMode(false);
                        System.exit(exitCode);
                    } else if (command.equals("echo")) {
                        String output = String.join(" ", cmdArgs.subList(1, cmdArgs.size()));
                        out.println(output);
                    } else if (command.equals("type")) {
                        if (cmdArgs.size() > 1) {
                            String target = cmdArgs.get(1);
                            if (BUILTINS.contains(target)) {
                                out.println(target + " is a shell builtin");
                            } else {
                                Path executable = findExecutable(target);
                                if (executable != null) {
                                    out.println(target + " is " + executable);
                                } else {
                                    out.println(target + ": not found");
                                }
                            }
                        }
                    } else if (command.equals("pwd")) {
                        out.println(currentDir);
                    } else if (command.equals("cd")) {
                        String home = System.getenv("HOME");
                        if (home == null || home.isEmpty()) {
                            home = System.getProperty("user.home");
                        }
                        String targetPath = cmdArgs.size() > 1 ? cmdArgs.get(1) : home;
                        if (targetPath.equals("~")) {
                            targetPath = home;
                        } else if (targetPath.startsWith("~/")) {
                            targetPath = home + targetPath.substring(1);
                        }

                        Path target = currentDir.resolve(targetPath).normalize();
                        if (Files.isDirectory(target)) {
                            currentDir = target;
                        } else {
                            System.out.println("cd: " + targetPath + ": No such file or directory");
                        }
                    }
                } finally {
                    if (closeOut) {
                        out.close();
                    }
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    setRawMode(false);
                    try {
                        ProcessBuilder pb = new ProcessBuilder(cmdArgs);
                        pb.directory(currentDir.toFile());
                        if (outPath != null) {
                            pb.redirectOutput(appendOut ? ProcessBuilder.Redirect.appendTo(outPath.toFile()) : ProcessBuilder.Redirect.to(outPath.toFile()));
                        } else {
                            pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);
                        }
                        if (errPath != null) {
                            pb.redirectError(appendErr ? ProcessBuilder.Redirect.appendTo(errPath.toFile()) : ProcessBuilder.Redirect.to(errPath.toFile()));
                        } else {
                            pb.redirectError(ProcessBuilder.Redirect.INHERIT);
                        }
                        pb.redirectInput(ProcessBuilder.Redirect.INHERIT);
                        Process process = pb.start();
                        process.waitFor();
                    } finally {
                        setRawMode(true);
                    }
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static void setRawMode(boolean raw) {
        try {
            String cmd = raw ? "stty -icanon -echo </dev/tty" : "stty sane </dev/tty";
            new ProcessBuilder("/bin/sh", "-c", cmd).inheritIO().start().waitFor();
        } catch (Exception ignored) {}
    }

    private static void enableRawMode() {
        setRawMode(true);
        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            setRawMode(false);
        }));
    }

    private static String readLineWithCompletion() throws IOException {
        StringBuilder line = new StringBuilder();
        while (true) {
            int ch = System.in.read();
            if (ch == -1) {
                return line.length() > 0 ? line.toString() : null;
            }
            if (ch == '\n' || ch == '\r') {
                System.out.print("\n");
                System.out.flush();
                return line.toString();
            } else if (ch == '\t') {
                String current = line.toString();
                List<String> candidates = List.of("echo", "exit");
                List<String> matches = candidates.stream()
                        .filter(cmd -> cmd.startsWith(current))
                        .toList();
                if (matches.size() == 1) {
                    String match = matches.get(0);
                    String completion = match.substring(current.length()) + " ";
                    line.append(completion);
                    System.out.print(completion);
                    System.out.flush();
                } else {
                    System.out.print("\u0007");
                    System.out.flush();
                }
            } else if (ch == 127 || ch == '\b') {
                if (line.length() > 0) {
                    line.deleteCharAt(line.length() - 1);
                    System.out.print("\b \b");
                    System.out.flush();
                }
            } else if (ch >= 32) {
                line.append((char) ch);
                System.out.print((char) ch);
                System.out.flush();
            }
        }
    }

    private static void prepareRedirectionFile(String pathStr, boolean append) throws Exception {
        Path p = resolvePath(pathStr);
        if (p.getParent() != null) {
            Files.createDirectories(p.getParent());
        }
        if (append) {
            if (!Files.exists(p)) {
                Files.createFile(p);
            }
        } else {
            Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
        }
    }

    private static Path resolvePath(String pathStr) {
        String home = System.getenv("HOME");
        if (home == null || home.isEmpty()) {
            home = System.getProperty("user.home");
        }
        if (pathStr.equals("~")) {
            pathStr = home;
        } else if (pathStr.startsWith("~/")) {
            pathStr = home + pathStr.substring(1);
        }
        return currentDir.resolve(pathStr).normalize();
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        char next = input.charAt(i + 1);
                        if (next == '\"' || next == '\\' || next == '$' || next == '`') {
                            i++;
                            current.append(next);
                        } else {
                            current.append(c);
                        }
                    } else {
                        current.append(c);
                    }
                } else if (c == '\"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '\"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {}
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Leaving Terminal in Raw Mode on Shell Exit** — If the shell process crashes or terminates without restoring canonical mode (`stty sane </dev/tty`), the user's terminal environment becomes unusable (keystrokes do not echo, backspace fails, carriage returns do not advance lines). Adding a JVM shutdown hook (`Runtime.getRuntime().addShutdownHook(...)`) ensures terminal settings are restored even on abnormal termination or SIGINT.
- **Child Processes Inheriting Raw Mode** — If external commands (such as `cat`, `vi`, or interactive scripts) are spawned while raw mode is enabled, child input/output handling may break or behave inconsistently. Calling `setRawMode(false)` immediately before `process = pb.start()` and `setRawMode(true)` in a `finally` block after `process.waitFor()` protects subprocess isolation.
- **Missing `System.out.flush()` on Character I/O** — Since `System.out` buffers output until a newline appears, printing typed characters `(char) ch` or completion suffixes without flushing leaves the terminal display blank while waiting for Enter. Explicit `System.out.flush()` after each keystroke and completion string is required.
- **Handling Backspace in Raw Mode** — In raw mode without kernel line editing, pressing backspace sends ASCII 127 (`DEL`) or ASCII 8 (`\b`). The shell must manually erase the character from the internal buffer (`line.deleteCharAt(...)`) and visual screen (`System.out.print("\b \b")`).
- **Trailing Space on Autocomplete** — According to the specification, completing a command must append a trailing space (e.g. `ech` -> `echo `) so the user can immediately type parameters without hitting the spacebar.

---

## Tradeoffs

- **Shell-Level POSIX `stty` Command vs Native JNI/JNA Terminal Libraries (e.g., JLine)** — Calling `/bin/sh -c "stty ..."` requires spawning a process twice (at start and end), but requires zero external dependencies and works natively on any POSIX system supported by the JVM. Dedicated terminal libraries like JLine offer cross-platform terminal control and full line-editing bindings, but introduce significant JAR dependency overhead.
- **Manual Keystroke Dispatcher vs Readline State Machine** — Implementing a lightweight `readLineWithCompletion()` directly in Java gives full, readable control over printable characters, backspace, and tab autocompletion without needing a complex terminal capability matrix.

## CLI / Protocol format

- **Autocompleting `echo` builtin**:
  ```
  $ ech<TAB>
  $ echo 
  ```
- **Autocompleting `exit` builtin**:
  ```
  $ exi<TAB>
  $ exit 
  ```
- **Unambiguous vs Ambiguous Match**:
  - Exactly 1 match: Appends the remaining characters plus a trailing space (`" "`) and flushes to terminal.
  - 0 or >1 matches: Emits the terminal bell (`\u0007`) and leaves input unchanged.

## Java specifics — lookup, don't memorize

- `System.in.read()` — Reads a single byte from standard input; returns -1 on EOF.
- `ProcessBuilder("/bin/sh", "-c", "stty -icanon -echo </dev/tty")` — Executes the `stty` utility in a subshell targeting the controlling terminal.
- `Runtime.getRuntime().addShutdownHook(Thread)` — Registers an action to be executed when the JVM initiates its shutdown sequence.
- `\u0007` — The ASCII Bell character (BEL), commonly used in shells to signal completion failure or no-op.
- `\b \b` — Standard terminal sequence to move cursor backward, overwrite with space, and move backward again.
