# Stage 42: Multiple completer candidates (#ep2)

## In one line
Extends programmable completion to handle multiple returned candidates: rings bell on the first TAB and prints all candidates alphabetized and separated by two spaces on the second consecutive TAB before reprinting the prompt.

---

## Self-test
- **Prompt**: If a completer script prints `rebase`, `remote`, `reset`, what happens on the 1st and 2nd TAB?
- **Answer**:
  - 1st TAB: Shell rings bell (`\u0007`) because there is no single unambiguous completion.
  - 2nd TAB: Shell prints a newline, prints candidates joined with spaces (`rebase  remote  reset`), prints another newline, reprints the prompt line (`$ git re`), and flushes output.

---

## Problem Solved
Completer scripts often yield multiple choices for a given prefix. Rather than silently doing nothing or failing, standard shells alert the user via an audible/visual bell on the first TAB and display the available candidate list upon the second TAB.

---

## Key Concepts
1. **Candidate Set Sorting**:
   - `TreeSet<String>` automatically deduplicates and orders candidates alphabetically as required by CodeCrafters.
2. **Double-TAB State Tracking**:
   - Tracking `consecutiveTabs`:
     - 1st TAB with `matches.size() > 1`: Ring bell (`System.out.print("\u0007")`).
     - 2nd TAB with `matches.size() > 1`: Print options on next line and restore prompt buffer.
     - Any regular keystroke or backspace resets `consecutiveTabs = 0`.

    } else {
        consecutiveTabs++;
        if (consecutiveTabs == 1) {
            System.out.print("\u0007");
            System.out.flush();
        } else if (consecutiveTabs >= 2) {
            System.out.print("\n");
            System.out.print(String.join("  ", matches));
            System.out.print("\n");
            System.out.print("$ " + current);
            System.out.flush();
            consecutiveTabs = 0;
        }
    }
}

---

## Failure Modes & Edge Cases Handled
- **Consecutive TAB reset**:
  - Correctly resets `consecutiveTabs` on any non-TAB keystroke (printable characters, backspaces, enters).
- **Prompt restoration**:
  - Restores `$ <current>` exactly after listing candidates so the user's editing buffer remains intact.
