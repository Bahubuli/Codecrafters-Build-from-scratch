# Stage 13: Single quotes

---

## In one line
Implement a lexical command-line tokenizer that honors POSIX single-quote literals (`'...'`), preserves whitespace within quotes, and concatenates adjacent quoted and unquoted tokens.

---

- How does a shell lexer treat consecutive single quotes (`''`) when adjacent to another token versus when standalone?
- Why do single quotes in POSIX shells disable all escape sequences, such that even `\'` does not escape a single quote?

## The problem it solved
Previously, our shell parsed commands by splitting the entire input string on whitespace delimiters using `input.trim().split("\\s+")`. This naive approach collapsed all consecutive spaces into single delimiters and made it impossible to pass filenames, file paths, or arguments containing spaces (e.g. `cat '/tmp/my notes.txt'` was split into three distinct tokens `cat`, `'/tmp/my`, and `notes.txt'`). Single quotes allow users to pass literal strings containing arbitrary spaces and characters without premature word splitting.

---

## Concepts (the transferable part)

- **[CONCEPT] Lexical Analysis (Tokenization / Scanning)** — The phase of an interpreter or compiler where a stream of raw characters is converted into meaningful semantic tokens (words/arguments). Rather than treating delimiters uniformly, the lexer maintains state (e.g., inside quotes vs. unquoted) to decide whether a whitespace character is a delimiter or part of token data.
- **[CONCEPT] POSIX Single-Quote Literal Semantics** — In Unix shells, enclosing characters in single quotes preserves the literal value of each character within the quotes. No parameter expansion, command substitution, arithmetic expansion, or escape sequence processing occurs. A single quote cannot even occur between single quotes; it must be closed first.
- **[CONCEPT] Token Concatenation (Word Gluing)** — In shell grammar, quoted fragments and unquoted fragments immediately adjacent to each other without whitespace form a single composite word (e.g., `hello''world` and `'hello''world'` both evaluate to `helloworld`).
- **[CONCEPT] Argument Vectors (`argv`)** — The operating system's process invocation boundary (via `execve`) accepts an array of distinct string pointers (`argv[]`), not a raw string. The shell is responsible for tokenizing and quote-stripping the user's command line into this exact array before passing it to the OS.

## The Solution

```java
import java.io.File;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }
            String command = parsedArgs.get(0);

            if (command.equals("exit")) {
                int exitCode = 0;
                if (parsedArgs.size() > 1) {
                    try {
                        exitCode = Integer.parseInt(parsedArgs.get(1));
                    } catch (NumberFormatException ignored) {
                    }
                }
                System.exit(exitCode);
            } else if (command.equals("echo")) {
                String output = String.join(" ", parsedArgs.subList(1, parsedArgs.size()));
                System.out.println(output);
            } else if (command.equals("type")) {
                if (parsedArgs.size() > 1) {
                    String target = parsedArgs.get(1);
                    if (BUILTINS.contains(target)) {
                        System.out.println(target + " is a shell builtin");
                    } else {
                        Path executable = findExecutable(target);
                        if (executable != null) {
                            System.out.println(target + " is " + executable);
                        } else {
                            System.out.println(target + ": not found");
                        }
                    }
                }
            } else if (command.equals("pwd")) {
                System.out.println(currentDir);
            } else if (command.equals("cd")) {
                String home = System.getenv("HOME");
                if (home == null || home.isEmpty()) {
                    home = System.getProperty("user.home");
                }
                String targetPath = parsedArgs.size() > 1 ? parsedArgs.get(1) : home;
                if (targetPath.equals("~")) {
                    targetPath = home;
                } else if (targetPath.startsWith("~/")) {
                    targetPath = home + targetPath.substring(1);
                }

                Path target = currentDir.resolve(targetPath).normalize();
                if (Files.isDirectory(target)) {
                    currentDir = target;
                } else {
                    System.out.println("cd: " + targetPath + ": No such file or directory");
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(parsedArgs);
                    pb.directory(currentDir.toFile());
                    pb.inheritIO();
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Standalone empty quotes `''` vs whitespace** — If a command is `echo ''`, the second argument is an empty string `""`, not absent. Using a `StringBuilder.length() > 0` check alone would mistakenly drop empty quoted arguments. Maintaining an explicit `hasToken` flag ensures that encountering quotes marks an active argument even if its string content is length 0.
- **Multiple spaces outside vs inside quotes** — Outside quotes, consecutive spaces act as a single delimiter and must not emit empty tokens. Inside quotes, every whitespace character is appended verbatim to the token buffer.
- **Adjacent quote concatenation (`'hello''world'`)** — If the lexer emitted a token immediately upon seeing a closing quote, `'hello''world'` would be split into two tokens `["hello", "world"]`. The token must only be committed to the argument list when an unquoted whitespace character or end-of-line is reached.
- **Passing quoted paths to external processes** — If quotes are retained in the argument string (e.g. `['cat', "'/tmp/file'"]`), the OS `execve` call looks for a file whose name literally contains single quotes. The tokenizer must perform quote stripping, yielding `/tmp/file`.

---

## Tradeoffs

- **State-Machine Lexer vs Regular Expressions** — While regexes (like `matcher.find()`) can handle simple quote patterns, regexes quickly become unwieldy and unreadable when handling concatenations (`hello'world'`), mixed quotes, and escaped characters. A clean character-by-character state-machine lexer is $O(N)$, straightforward to debug, and easily extendable for double quotes (`"..."`) and backslash escapes (`\...`) in future stages.
- **`hasToken` boolean vs Nullable Token Reference** — Distinguishing between "no token in progress" and "an empty string token explicitly created by `''`" can be done with a boolean flag `hasToken` or an object wrapper. A simple boolean `hasToken` is zero-allocation and keeps state tracking crystal clear.

## CLI / Protocol format

- **Preserving whitespace in arguments**:
  ```
  $ echo 'hello    world'
  hello    world
  ```
- **Collapsing unquoted whitespace**:
  ```
  $ echo hello    world
  hello world
  ```
- **Adjacent quote concatenation**:
  ```
  $ echo 'hello''world'
  helloworld
  $ echo hello''world
  helloworld
  ```
- **External command with quoted filename argument**:
  ```
  $ cat '/tmp/file name' '/tmp/file name with spaces'
  content1 content2
  ```

## Java specifics — lookup, don't memorize

- `StringBuilder.setLength(0)` — Empties the `StringBuilder` buffer efficiently without allocating a new object.
- `Character.isWhitespace(char ch)` — Determines whether the specified character is white space according to Java (includes space `' '`, tab `'\t'`, newline, etc.).
- `List.subList(int fromIndex, int toIndex)` — Returns a view of the portion of this list between the specified indices.
- `String.join(CharSequence delimiter, Iterable elements)` — Concatenates the elements of an Iterable with the specified delimiter between each element.
