# Stage 43: Longest common prefix (#xz3)

## In one line
Completes the current token up to the Longest Common Prefix (LCP) when multiple completer candidates share a common prefix longer than the current input, without ringing the terminal bell or listing candidates.

---

## Self-test
- **Prompt**: If a completer script returns `checkout` and `cherry-pick` and the user types `git c<TAB>`, what should happen?
- **Answer**: The LCP between `checkout` and `cherry-pick` is `che`. Because `"che".length() > "c".length()`, the shell appends `"he"` to the buffer, prints `"he"` without a trailing space, flushes stdout, and resets `consecutiveTabs` to 0 without ringing any bell.

---

## Problem Solved
When multiple candidates share characters beyond what the user has currently typed, standard Unix tab completion expands the word up to the longest shared common prefix. Only when the input is already identical to the LCP does subsequent TAB usage trigger the bell and display candidates.

---

## Key Concepts
1. **Longest Common Prefix (LCP)**:
   - Given a collection of candidate strings `{"checkout", "cherry-pick"}`, find the longest string prefix present in all candidates (`"che"`).
2. **Partial vs Full Completion**:
   - If `matches.size() == 1`: append remaining characters + trailing space `' '`.
   - If `matches.size() > 1` and `lcp.length() > word.length()`: append `lcp.substring(word.length())` without a trailing space, reset `consecutiveTabs = 0`.
   - If `matches.size() > 1` and `lcp.length() <= word.length()`: ring bell on 1st TAB (`consecutiveTabs == 1`), print candidate list on 2nd TAB (`consecutiveTabs >= 2`).

---

## The Solution
In `Main.java`:
```java
} else if (matches.size() > 1) {
    String lcp = longestCommonPrefix(matches);
    if (lcp.length() > word.length()) {
        String completion = lcp.substring(word.length());
        line.append(completion);
        System.out.print(completion);
        System.out.flush();
        consecutiveTabs = 0;
    } else {
        consecutiveTabs++;
        if (consecutiveTabs == 1) {
            System.out.print("\u0007");
            System.out.flush();
        } else if (consecutiveTabs >= 2) {
            System.out.print("\n");
            System.out.print(String.join("  ", matches));
            System.out.print("\n");
            System.out.print("$ " + current);
            System.out.flush();
            consecutiveTabs = 0;
        }
    }
}
```

---

## Failure Modes & Edge Cases Handled
- **No common characters beyond input**:
  - Falls through to the `consecutiveTabs` bell / candidate list branch.
- **Single remaining candidate**:
  - Handled by `matches.size() == 1` branch, appending the full remaining word and a space delimiter.
- **Empty candidate set**:
  - Handled by `else` branch, ringing the terminal bell.
