# Stage 14: Double quotes

## In one line
Extend the lexical tokenizer with double-quote state tracking (`"..."`) so that spaces and single quotes are preserved literally within double quotes, and adjacent quoted/unquoted segments concatenate seamlessly into single arguments.

## The problem it solved
Single quotes enforce strict verbatim literals where no character inside can have special meaning (not even escape characters or variable expansions). However, real-world shell scripts and interactive commands frequently need quoting that preserves internal spaces and literal single quotes (e.g. `echo "shell's test"` or `cat "/tmp/file name"`), while setting the groundwork for variable substitution (`$VAR`) and backslash escapes (`\`). Implementing double-quote parsing solves the problem of passing arguments containing single quotes, internal whitespace, and concatenating double-quoted fragments with adjacent text.

---

## Concepts (the transferable part)

- **[CONCEPT] POSIX Double-Quote Semantics (Weak Quoting)** — In shell grammar, double quotes provide "weak" quoting: they suppress word splitting on whitespace and treat most punctuation literally (such as `'`), but preserve the meaning of a small set of special expansion characters (like `$`, `` ` ``, and `\` in full POSIX; introduced in later stages). Inside double quotes, a single quote is just an ordinary character.
- **[CONCEPT] Mutual Quote Invariance** — In a lexical analyzer, whichever quote type is opened first becomes the enclosing context until its matching closing quote is encountered. When in `inSingleQuote`, double quotes `"` are treated as ordinary payload characters. When in `inDoubleQuote`, single quotes `'` are treated as ordinary payload characters. Neither quote type can terminate or nest within the other without closing first.
- **[CONCEPT] Lexer State Machine Extension** — Extending a tokenizer to support multiple quoting styles does not require separate passes or complex regular expressions. By introducing orthogonal state flags (`inSingleQuote`, `inDoubleQuote`), the lexer evaluates incoming characters against the active quote context before falling back to default delimiter handling.
- **[CONCEPT] Word Boundary vs Token Content** — A token boundary is triggered solely by unquoted whitespace or EOF. Quoting mechanisms alter how characters are accumulated into the active buffer, but the decision of when a word starts or ends remains anchored to unquoted whitespace delimiters.

## The Solution

```java
import java.io.File;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }
            String command = parsedArgs.get(0);

            if (command.equals("exit")) {
                int exitCode = 0;
                if (parsedArgs.size() > 1) {
                    try {
                        exitCode = Integer.parseInt(parsedArgs.get(1));
                    } catch (NumberFormatException ignored) {
                    }
                }
                System.exit(exitCode);
            } else if (command.equals("echo")) {
                String output = String.join(" ", parsedArgs.subList(1, parsedArgs.size()));
                System.out.println(output);
            } else if (command.equals("type")) {
                if (parsedArgs.size() > 1) {
                    String target = parsedArgs.get(1);
                    if (BUILTINS.contains(target)) {
                        System.out.println(target + " is a shell builtin");
                    } else {
                        Path executable = findExecutable(target);
                        if (executable != null) {
                            System.out.println(target + " is " + executable);
                        } else {
                            System.out.println(target + ": not found");
                        }
                    }
                }
            } else if (command.equals("pwd")) {
                System.out.println(currentDir);
            } else if (command.equals("cd")) {
                String home = System.getenv("HOME");
                if (home == null || home.isEmpty()) {
                    home = System.getProperty("user.home");
                }
                String targetPath = parsedArgs.size() > 1 ? parsedArgs.get(1) : home;
                if (targetPath.equals("~")) {
                    targetPath = home;
                } else if (targetPath.startsWith("~/")) {
                    targetPath = home + targetPath.substring(1);
                }

                Path target = currentDir.resolve(targetPath).normalize();
                if (Files.isDirectory(target)) {
                    currentDir = target;
                } else {
                    System.out.println("cd: " + targetPath + ": No such file or directory");
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(parsedArgs);
                    pb.directory(currentDir.toFile());
                    pb.inheritIO();
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Premature Token Flush on Closing Quote** — If closing a quote immediately emitted the token to `args`, inputs like `"hello""world"` or `"hello"world` would produce two tokens (`["hello", "world"]`) rather than concatenating into one (`["helloworld"]`). Closing quotes must merely flip the quoting state boolean back to `false` without flushing the `StringBuilder`.
- **Single Quotes Inside Double Quotes** — For `echo "shell's test"`, if `'` was checked globally before checking `inDoubleQuote`, the lexer would enter single-quote mode inside double-quote mode, breaking quotation state. Checking `if (inDoubleQuote)` first ensures `'` is treated purely as a character literal.
- **Double Quotes Inside Single Quotes** — For `echo 'say "hello"'`, checking `if (inSingleQuote)` first ensures `"` is treated purely as a character literal.
- **Empty Quoted Arguments `""`** — For `echo ""`, `hasToken` is set to `true` when `"` is encountered. When the closing `"` is hit, `current` is still empty (`length == 0`). If the flush logic checked `!current.isEmpty()` instead of `hasToken`, the empty string argument would be silently dropped.
- **Preservation of Whitespace** — Inside `inDoubleQuote`, spaces and tabs must not trigger word flushing; they are appended directly to `current`.

---

## Tradeoffs

- **Orthogonal Boolean Flags vs Enum Parser State** — Tracking states with boolean flags (`inSingleQuote`, `inDoubleQuote`) is simple and legible when quotes do not nest. Alternatively, an explicit `enum State { NORMAL, IN_SINGLE_QUOTE, IN_DOUBLE_QUOTE }` could be used. Both yield equivalent $O(N)$ single-pass performance; the boolean approach keeps conditions concise.
- **Single-Pass Character Scanning vs Multi-Phase Tokenization** — Splitting into lexical token tokens (`QUOTE`, `WORD`, `WHITESPACE`) followed by a grammatical concatenation pass offers formal structure for full compilers, but incurs multiple object allocations per command line. A single-pass streaming builder directly emits clean `List<String>` argument vectors with zero intermediate AST or token allocations.

## CLI / Protocol format

- **Multiple spaces preserved in double quotes**:
  ```
  $ echo "hello    world"
  hello    world
  ```
- **Concatenation of adjacent quoted tokens**:
  ```
  $ echo "hello""world"
  helloworld
  $ echo "hello"world
  helloworld
  ```
- **Single quote literal inside double quotes**:
  ```
  $ echo "shell's test"
  shell's test
  ```
- **External command with double-quoted arguments**:
  ```
  $ cat "/tmp/file name" "/tmp/'file name' with spaces"
  content1 content2
  ```

## Java specifics — lookup, don't memorize

- `StringBuilder.append(char c)` — Appends the character to the existing buffer in amortized $O(1)$ time.
- `String.charAt(int index)` — Fetches the UTF-16 code unit at the given index in $O(1)$ time.
- `Character.isWhitespace(char c)` — Checks whether a character is whitespace (Unicode standard, covering space, tab, line breaks).
