# Stage 41: Passing environment variables (#nr7)

## In one line
Sets `COMP_LINE` (full line buffer before TAB) and `COMP_POINT` (zero-based byte index of cursor position) as environment variables on the completer subprocess via `ProcessBuilder.environment()`.

---

## Self-test
- **Prompt**: When `git ad<TAB>` is pressed, what values must be assigned to `COMP_LINE` and `COMP_POINT` for the completer script?
- **Answer**:
  - `COMP_LINE`: `"git ad"` (the raw text of the line at TAB press without a trailing newline).
  - `COMP_POINT`: `"6"` (string byte length in UTF-8, reflecting cursor position at the end of the line).

---

## Problem Solved
Advanced completer engines need access to the entire unprocessed command line and exact cursor byte offset to handle context beyond just immediate preceding arguments (such as flags before verbs, subcommands with arbitrary nesting, and cursor positioning within the middle of lines).

---

## Key Concepts
1. **`COMP_LINE`**:
   - Holds the exact line string currently held in the shell's line buffer (`line.toString()`).
2. **`COMP_POINT`**:
   - The zero-based byte index into `COMP_LINE`.
   - In Java: `String.valueOf(compLine.getBytes(StandardCharsets.UTF_8).length)`.
3. **Subprocess Isolation**:
   - Using `ProcessBuilder.environment().put(...)` modifies only the environment block passed to the child process without mutating or polluting the parent Java shell process's own environment.

---

## The Solution
In `Main.java`:
```java
private static List<String> runCompleterScript(String scriptPath, String command, String word, String prevWord, String compLine) {
    List<String> results = new ArrayList<>();
    try {
        ProcessBuilder pb = new ProcessBuilder(scriptPath, command, word, prevWord);
        pb.environment().put("COMP_LINE", compLine);
        pb.environment().put("COMP_POINT", String.valueOf(compLine.getBytes(StandardCharsets.UTF_8).length));
        pb.directory(currentDir.toFile());
        Process p = pb.start();
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(p.getInputStream()))) {
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (!line.isEmpty()) {
                    results.add(line);
                }
            }
        }
        p.waitFor();
    } catch (Exception ignored) {}
    return results;
}
```

Caller in `readLineWithCompletion()`:
```java
List<String> scriptOutput = runCompleterScript(script, firstWord, word, prevWord, current);
```

---

## Failure Modes & Edge Cases Handled
- **Multibyte Characters**:
  - `COMP_POINT` requires byte count rather than character count; computing `compLine.getBytes(StandardCharsets.UTF_8).length` correctly accounts for non-ASCII characters if present.
- **Environment Containment**:
  - Variables are set strictly on the `ProcessBuilder` instance, leaving the shell's own environment untouched.
