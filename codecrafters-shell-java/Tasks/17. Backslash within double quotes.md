# Stage 17: Backslash within double quotes

---

## In one line
Conditionally evaluate backslashes inside double quotes (`"..."`) so that only specific characters (`"`, `\`, `$`, `` ` ``, and `\n`) are escaped, while backslashes preceding any other character are preserved literally.

---

- Which characters does a backslash escape inside double quotes according to POSIX shell standards?

- How does the parser distinguish between an escaped quote (`\"`) that remains part of the string and an unescaped quote (`"`) that terminates the quoted token?
- What happens when a double-quoted token with escaped backslashes or quotes is directly concatenated with unquoted or single-quoted substrings (e.g., `/tmp/"doublequote \" 2"`)?

---

## The problem it solved
In shell scripts and command-line interfaces, double quotes are used for strings that require word-boundary preservation while still allowing variable expansion, command substitution, and selective character escaping. Previously, our double-quote parser treated every character except `"` literally. As a result, users could not embed literal double quotes (`\"`) or literal backslashes (`\\`) inside double quotes, and attempts to escape quotes caused premature termination of the quoted string. This stage implements selective backslash escaping inside double quotes per POSIX shell rules.

---

## Concepts (the transferable part)

- **[CONCEPT] Selective Escaping vs Complete Literalism** — Single quotes enforce total literalism (no escapes whatsoever), and unquoted text escapes any character immediately following `\`. Double quotes occupy a middle ground: `\` is an active escape character *only* when preceding special metacharacters (`"`, `\`, `$`, `` ` ``, and newline). For all other characters, `\` retains its literal character value.
- **[CONCEPT] One-Character Lookahead in Lexers** — When the lexer encounters an escape initiator (`\`) in double-quote mode, it must peek at `index + 1`. If the following character is an escapable metacharacter, both the backslash and the metacharacter are consumed, appending only the escaped character. If not, the backslash is retained as literal text, and parsing continues with the subsequent character.
- **[CONCEPT] Escaping the Quote Delimiter** — By allowing `\"` to emit a literal `"` without toggling the `inDoubleQuote` state flag, the shell enables nested quotes within a single contiguous token argument without breaking the state machine.

## The Solution

```java
import java.io.File;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }
            String command = parsedArgs.get(0);

            if (command.equals("exit")) {
                int exitCode = 0;
                if (parsedArgs.size() > 1) {
                    try {
                        exitCode = Integer.parseInt(parsedArgs.get(1));
                    } catch (NumberFormatException ignored) {
                    }
                }
                System.exit(exitCode);
            } else if (command.equals("echo")) {
                String output = String.join(" ", parsedArgs.subList(1, parsedArgs.size()));
                System.out.println(output);
            } else if (command.equals("type")) {
                if (parsedArgs.size() > 1) {
                    String target = parsedArgs.get(1);
                    if (BUILTINS.contains(target)) {
                        System.out.println(target + " is a shell builtin");
                    } else {
                        Path executable = findExecutable(target);
                        if (executable != null) {
                            System.out.println(target + " is " + executable);
                        } else {
                            System.out.println(target + ": not found");
                        }
                    }
                }
            } else if (command.equals("pwd")) {
                System.out.println(currentDir);
            } else if (command.equals("cd")) {
                String home = System.getenv("HOME");
                if (home == null || home.isEmpty()) {
                    home = System.getProperty("user.home");
                }
                String targetPath = parsedArgs.size() > 1 ? parsedArgs.get(1) : home;
                if (targetPath.equals("~")) {
                    targetPath = home;
                } else if (targetPath.startsWith("~/")) {
                    targetPath = home + targetPath.substring(1);
                }

                Path target = currentDir.resolve(targetPath).normalize();
                if (Files.isDirectory(target)) {
                    currentDir = target;
                } else {
                    System.out.println("cd: " + targetPath + ": No such file or directory");
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(parsedArgs);
                    pb.directory(currentDir.toFile());
                    pb.inheritIO();
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        char next = input.charAt(i + 1);
                        if (next == '\"' || next == '\\' || next == '$' || next == '`') {
                            i++;
                            current.append(next);
                        } else {
                            current.append(c);
                        }
                    } else {
                        current.append(c);
                    }
                } else if (c == '\"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '\"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Blindly Stripping All Backslashes** — In unquoted mode, `\a` becomes `a`. In double quotes, `\a` must remain `\a`! Only escapable characters (`"`, `\`, `$`, `` ` ``) lose their preceding backslash.
- **Premature Quote Termination** — If `\"` is not intercepted before checking `c == '\"'`, the backslash is appended and the quote state closes prematurely, corrupting the remainder of the command line.
- **Index Out of Bounds at String End** — If an unclosed double quote ends with a trailing backslash (e.g., `"test\`), lookahead without boundary checking (`i + 1 < input.length()`) throws `StringIndexOutOfBoundsException`.
- **Double Backslash Collapsing** — For `"\\n"`, the first backslash escapes the second backslash, yielding `\`. The subsequent `n` is literal, resulting in `\n`. If a parser naively interprets `\n` as a newline escape sequence or drops both backslashes, test cases like `echo "just'one'\\n'backslash"` fail.

---

## Tradeoffs

- **Lookahead Inspection vs Secondary Lexer State** — Peeking one character ahead (`input.charAt(i + 1)`) within `inDoubleQuote` is concise and directly matches POSIX rules without introducing extra state flags (like `escapeNext`). Since only single-character escapes exist in double quotes, lookahead avoids state transitions.
- **Hardcoding Escapable Set vs Configuration Set** — Checking `next == '\"' || next == '\\' || next == '$' || next == '`'` inline avoids object allocations or `Set.contains` lookup overhead inside a tight character-scanning loop.

## CLI / Protocol format

- **Escaping quotes inside double quotes**:
  ```
  $ echo "A \" inside double quotes"
  A " inside double quotes
  ```
- **Escaping backslashes inside double quotes**:
  ```
  $ echo "A \\ escapes itself"
  A \ escapes itself
  ```
- **Non-escapable characters preserving the backslash**:
  ```
  $ echo "just'one'\\n'backslash"
  just'one'\n'backslash
  ```
- **Mixed quotes and escapes in arguments**:
  ```
  $ echo "inside\"literal_quote."outside\"
  inside"literal_quote.outside"
  $ cat /tmp/"number 1" /tmp/"doublequote \" 2" /tmp/"backslash \\ 3"
  content1 content2 content3
  ```

## Java specifics — lookup, don't memorize

- `input.charAt(i + 1)` — Direct zero-allocation character peek at the subsequent position in the input string.
- `i++` — Incrementing the index within the lookahead branch skips the escaped character during the loop's next iteration.
