# Stage 15: Backslash outside quotes

---

## In one line
Enhance the lexical tokenizer with unquoted backslash escape handling (`\c`) so that special characters and literal characters have their syntactic meaning removed and are emitted literally without the escape backslash.

---

## The problem it solved
Prior to this stage, any space outside quotes acted as an unconditional argument delimiter, and quotes (`'` and `"`) unconditionally toggled quoting modes. Users could not pass filenames or arguments containing spaces without enclosing them in full quotes, nor could they pass literal quote characters or backslashes without surrounding quotes. Adding unquoted backslash escaping removes the syntactical significance of the immediately following character, emitting it literally into the token stream and discarding the escape backslash itself.

---

## Concepts (the transferable part)

- **[CONCEPT] POSIX Escape Character (Backslash Outside Quotes)** — In shell grammar, an unquoted backslash (`\`) preserves the literal value of the following character, stripping the backslash itself from the resulting word. This applies universally to whitespace, quotes, metacharacters, and ordinary characters alike.
- **[CONCEPT] Lookahead & Immediate Token Consumption** — In character-by-character lexical scanning, encountering an escape character triggers an immediate 1-character lookahead. Consuming the next character directly into the accumulator bypasses all grammar state checks (whitespace splitting, quote toggles) for that consumed character.
- **[CONCEPT] Whitespace Boundary Delimitation with Escaped Spaces** — An escaped space (`\ `) is marked as token payload rather than delimiter. Any subsequent unescaped spaces immediately re-engage the shell's delimiter logic, which collapses consecutive unquoted whitespace runs between tokens.
- **[CONCEPT] Literal Quote Emission vs Quote State Activation** — Escaping a quote character (`\'` or `\"`) outside quotes prevents the lexer from setting `inSingleQuote` or `inDoubleQuote`. The quote glyph is emitted as plain text, allowing literal quotes to be passed directly to programs.

## The Solution

```java
import java.io.File;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }
            String command = parsedArgs.get(0);

            if (command.equals("exit")) {
                int exitCode = 0;
                if (parsedArgs.size() > 1) {
                    try {
                        exitCode = Integer.parseInt(parsedArgs.get(1));
                    } catch (NumberFormatException ignored) {
                    }
                }
                System.exit(exitCode);
            } else if (command.equals("echo")) {
                String output = String.join(" ", parsedArgs.subList(1, parsedArgs.size()));
                System.out.println(output);
            } else if (command.equals("type")) {
                if (parsedArgs.size() > 1) {
                    String target = parsedArgs.get(1);
                    if (BUILTINS.contains(target)) {
                        System.out.println(target + " is a shell builtin");
                    } else {
                        Path executable = findExecutable(target);
                        if (executable != null) {
                            System.out.println(target + " is " + executable);
                        } else {
                            System.out.println(target + ": not found");
                        }
                    }
                }
            } else if (command.equals("pwd")) {
                System.out.println(currentDir);
            } else if (command.equals("cd")) {
                String home = System.getenv("HOME");
                if (home == null || home.isEmpty()) {
                    home = System.getProperty("user.home");
                }
                String targetPath = parsedArgs.size() > 1 ? parsedArgs.get(1) : home;
                if (targetPath.equals("~")) {
                    targetPath = home;
                } else if (targetPath.startsWith("~/")) {
                    targetPath = home + targetPath.substring(1);
                }

                Path target = currentDir.resolve(targetPath).normalize();
                if (Files.isDirectory(target)) {
                    currentDir = target;
                } else {
                    System.out.println("cd: " + targetPath + ": No such file or directory");
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(parsedArgs);
                    pb.directory(currentDir.toFile());
                    pb.inheritIO();
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Failing to Advance Loop Index (`i++`)** — If the lexer appends `input.charAt(i + 1)` but fails to increment `i`, the escaped character will be re-evaluated in the next iteration as an unescaped character, duplicating characters and triggering unwanted delimiter splitting or quote activations.
- **Trailing Backslash Index Out of Bounds** — When an input ends with a lone backslash (`\` at `i == input.length() - 1`), evaluating `input.charAt(i + 1)` without a boundary check throws `StringIndexOutOfBoundsException`. The lookahead check `i + 1 < input.length()` prevents this error.
- **Leaking Escapes Inside Quotes** — In POSIX shells, single quotes (`'...'`) treat backslashes as verbatim characters with zero escape semantics. Double quotes (`"..."`) only allow escaping a specific subset (`$`, `` ` ``, `"`, `\`, and newline). Applying unconditional outside-quote escape logic inside quotes breaks quoting invariants.
- **Discarding Escaped Whitespace Tokens** — If an argument consists solely of escaped spaces (e.g., `\ \ `), relying on `current.length() > 0` instead of `hasToken` could cause edge-case bugs. `hasToken = true` ensures the token is recorded even in edge cases.
- **Improper Delimiter Collapsing After Escaped Space** — For `echo before\     after`, the first space is escaped into `current` (`"before "`). The next character is an unescaped space, which must flush the token and trigger whitespace collapsing until the next non-whitespace character (`a`).

---

## Tradeoffs

- **Inline Loop Step (`i++`) vs Explicit `inEscape` State Flag** — Consuming the escaped character immediately by incrementing `i++` handles the 1-character lookahead in $O(1)$ time with zero additional state variables. An alternative approach uses a boolean flag `boolean inEscape = false`, which defers character appending to the next iteration. Inline consumption is cleaner and keeps all escape handling localized to a single branch.
- **Single-Pass Character Scanning vs Multi-Pass Preprocessing** — Attempting to resolve backslashes with string replacement (such as regex replacements) prior to tokenization corrupts quoted strings (e.g. replacing `\ ` inside single quotes where it should remain literal). Embedding escape handling inside the single-pass tokenizer respects contextual quote states naturally.

## CLI / Protocol format

- **Literal spaces within a single argument**:
  ```
  $ echo three\ \ \ spaces
  three   spaces
  ```
- **Escaped space followed by collapsed unescaped spaces**:
  ```
  $ echo before\     after
  before  after
  ```
- **Escaping non-special letters (removes backslash)**:
  ```
  $ echo test\nexample
  testnexample
  ```
- **Escaping a backslash itself**:
  ```
  $ echo hello\\world
  hello\world
  ```
- **Escaping quotes to produce literal quotes**:
  ```
  $ echo \'\"literal quotes\"\'
  '"literal quotes"'
  ```
- **Path arguments containing escaped characters**:
  ```
  $ cat /tmp/\_ignored_1 /tmp/ignore_\2 /tmp/just_one_\\_3
  content1 content2 content3
  ```

## Java specifics — lookup, don't memorize

- `String.charAt(int index)` — Retrieves the `char` value at the specified 0-based index in $O(1)$ time.
- `StringBuilder.append(char c)` — Appends the specified character to the sequence in amortized $O(1)$ time.
- `Character.isWhitespace(char c)` — Determines if the character is whitespace according to Unicode specifications.
