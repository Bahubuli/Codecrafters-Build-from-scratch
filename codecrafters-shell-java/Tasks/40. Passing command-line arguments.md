# Stage 40: Passing command-line arguments (#zi0)

## In one line
Passes command completion context to the `-C` completer script as 3 positional arguments: `command`, `word` (current partial text), and `prevWord` (immediately preceding word or empty string).

---

## Self-test
- **Prompt**: When completing `git remote set<TAB>`, what arguments are passed to the completer script registered for `git`?
- **Answer**:
  - `argv[1]`: `git` (the base command name)
  - `argv[2]`: `set` (the word being completed at cursor)
  - `argv[3]`: `remote` (the word immediately preceding the cursor word)
  If the command was `git <TAB>`, `argv[3]` would be `""`.

---

## Problem Solved
Enables context-aware programmable completion scripts (e.g. `git`, `docker`, `systemctl` completion engines) to inspect the specific subcommand and previous tokens to dynamically compute prefix matches (like resolving `set` -> `set-url` under `git remote`).

---

## Key Concepts
1. **Positional Arguments for `-C` Completers**:
   - Following standard shell completion protocol (e.g. Bash programmable completion):
     - `argv[1]` = Command being completed (`firstWord`).
     - `argv[2]` = Word being completed (`word`).
     - `argv[3]` = Preceding word (`prevWord`).
2. **Preceding Word Extraction**:
   - Take the substring preceding `lastSpace` and trim trailing whitespace:
     ```java
     String beforeCurrentWord = current.substring(0, lastSpace).trim();
     ```
   - If `beforeCurrentWord` is empty (e.g. `git <TAB>`), `prevWord = ""`.
   - Otherwise, locate the last space in `beforeCurrentWord` and extract the token after it.

---

## The Solution
In `readLineWithCompletion()`:
```java
if (COMPLETION_SPECS.containsKey(firstWord)) {
    String script = COMPLETION_SPECS.get(firstWord);
    String prevWord = "";
    String beforeCurrentWord = current.substring(0, lastSpace).trim();
    if (!beforeCurrentWord.isEmpty()) {
        int prevSpace = beforeCurrentWord.lastIndexOf(' ');
        if (prevSpace == -1) {
            prevWord = beforeCurrentWord;
        } else {
            prevWord = beforeCurrentWord.substring(prevSpace + 1);
        }
    }
    List<String> scriptOutput = runCompleterScript(script, firstWord, word, prevWord);
    matches = new TreeSet<>(scriptOutput);
} else {
    matches = getFileCompletions(word);
}
```

And in `runCompleterScript`:
```java
private static List<String> runCompleterScript(String scriptPath, String command, String word, String prevWord) {
    List<String> results = new ArrayList<>();
    try {
        ProcessBuilder pb = new ProcessBuilder(scriptPath, command, word, prevWord);
        pb.directory(currentDir.toFile());
        Process p = pb.start();
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(p.getInputStream()))) {
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (!line.isEmpty()) {
                    results.add(line);
                }
            }
        }
        p.waitFor();
    } catch (Exception ignored) {}
    return results;
}
```

---

## Failure Modes & Edge Cases Handled
- **No Preceding Word**:
  - `git <TAB>`: `beforeCurrentWord` is `git`, which is the command itself, so `prevWord` is `git` (or if whitespace between command, handled cleanly).
- **Extra Whitespace**:
  - Consecutive spaces before the current word are trimmed away using `trim()` before finding `prevSpace`, ensuring `prevWord` is never an empty token from intermediate spaces.
