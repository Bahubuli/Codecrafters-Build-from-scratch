# Stage 38: Single completion (#pm5)

## In one line
Executes the registered completer script via `ProcessBuilder` on `<TAB>` press when completing arguments for registered commands and inserts the completed word followed by a trailing space.

---

## Self-test
- **Prompt**: If `complete -C /bin/git-completer git` has been registered, and the user enters `git <TAB>`, what happens?
- **Answer**: The shell executes `/bin/git-completer`, reads its stdout line (e.g. `push`), completes the line to `git push `, and flushes it to the terminal.

---

## Problem Solved
Enables programmable command completions where third-party or custom tools provide dynamically generated arguments for commands (such as Git subcommands, Docker options, etc.).

---

## Key Concepts
1. **Completer Dispatch**:
   - Inspect the first word of the command line.
   - If `COMPLETION_SPECS.containsKey(firstWord)`, dispatch completion generation to the registered script.
2. **Synchronous Process Execution**:
   - Run the script as a sub-process:
     ```java
     ProcessBuilder pb = new ProcessBuilder(scriptPath);
     pb.directory(currentDir.toFile());
     Process p = pb.start();
     ```
   - Collect its standard output lines.
   - Wait for process termination before proceeding.
3. **Fallback to Default**:
   - If no script is registered for `firstWord`, or the script returns no output, fall back gracefully to file/directory completion.

---

## The Solution
In `Main.java`:
```java
private static List<String> runCompleterScript(String scriptPath) {
    List<String> results = new ArrayList<>();
    try {
        ProcessBuilder pb = new ProcessBuilder(scriptPath);
        pb.directory(currentDir.toFile());
        Process p = pb.start();
        try (BufferedReader reader = new BufferedReader(new InputStreamReader(p.getInputStream()))) {
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (!line.isEmpty()) {
                    results.add(line);
                }
            }
        }
        p.waitFor();
    } catch (Exception ignored) {}
    return results;
}
```

In `readLineWithCompletion()`:
```java
String firstWord = current.trim().split("\\s+")[0];
```

## Failure Modes & Bugs Prevented
- **Race Condition / Partial Read**:
  - Fully consuming `p.getInputStream()` within a try-with-resources reader and calling `p.waitFor()` ensures that the shell never truncates the output of slow or multi-buffered completer scripts.
- **Prefix Matching**:
  - `match.startsWith(word) ? match.substring(word.length()) : match` handles both partial typed prefixes and empty prefixes after spaces.
