# Stage 71: Storing shell variables

## In one line
Add support for declaring shell variables via `declare NAME=VALUE` and displaying existing variable definitions in normalized format (`declare -- NAME="VALUE"`) using `declare -p NAME`.

## The problem it solved
Shells maintain a symbol table of variables scoped to the session. Builtin commands like `declare` allow creating and updating variables (`declare foo=bar`) as well as inspecting their declared state and types (`declare -p foo`). Supporting storage and formatted inspection provides the foundation for subsequent parameter expansion (`$foo`).

## Concepts (the transferable part)
- **Variable Symbol Table** — A map (`Map<String, String> SHELL_VARIABLES`) retaining session variables across REPL interactions.
- **Key-Value Splitting** — Finding the first `=` (`arg.indexOf('=')`) to distinguish the variable name from its assigned value (which itself may contain further `=` characters).
- **Canonical Representation Format** — `declare -p` outputs the exact shell-reproducible declaration: `declare -- <name>="<value>"`.

## What breaks it (failure modes)
- Splitting by regex or all `=` — Using `split("=")` truncates values containing equal signs (e.g. `declare url=https://site?a=1`). Always split only at the first occurrence: `substring(0, eqIndex)` and `substring(eqIndex + 1)`.
- Overwriting in subshells — Subshell invocations should not mutate the parent shell's variable environment.
- Missing quotes in `-p` output — The specification requires `declare -- <name>="<value>"`. Omitting quotes around the value fails test assertions.

## Tradeoffs
- Simple `Map<String, String>` vs Typed Shell Attributes — Real shells track attributes (export, readonly, integer, array). For standard variable storage and `-p` inspection, a string-to-string mapping suffices until additional flags (like `-x` or `-r`) are introduced.

## CLI / Protocol format
```bash
$ declare foo=bar
$ declare -p foo
declare -- foo="bar"
$ declare -p missing_variable
declare: missing_variable: not found
$ declare foo=bar2
$ declare -p foo
declare -- foo="bar2"
```

## Java specifics — lookup, don't memorize
- Parsing assignment and querying:
  ```java
  // In declare builtin:
  if (cmdArgs.size() >= 2 && cmdArgs.get(1).equals("-p")) {
      int exitCode = 0;
      if (cmdArgs.size() > 2) {
          for (int i = 2; i < cmdArgs.size(); i++) {
              String varName = cmdArgs.get(i);
              if (SHELL_VARIABLES.containsKey(varName)) {
                  out.println("declare -- " + varName + "=\"" + SHELL_VARIABLES.get(varName) + "\"");
              } else {
                  err.println("declare: " + varName + ": not found");
                  exitCode = 1;
              }
          }
      }
      err.flush();
      out.flush();
      return exitCode;
  } else if (!inSubshell) {
      for (int i = 1; i < cmdArgs.size(); i++) {
          String arg = cmdArgs.get(i);
          int eqIndex = arg.indexOf('=');
          if (eqIndex != -1) {
              String name = arg.substring(0, eqIndex);
              String value = arg.substring(eqIndex + 1);
              SHELL_VARIABLES.put(name, value);
          }
      }
  }
  ```
