# Stage 37: Displaying registered specifications (#wl6)

## In one line
Implements the `-C <completer_path>` flag in the `complete` builtin to register command completion specifications, and updates `complete -p <command>` to display the registered completion specification in normalized format with single quotes.

---

## Self-test
- **Prompt**: When `complete   -C    /tmp/git-completer   git` is run followed by `complete -p git`, what is the output?
- **Answer**: `complete -C '/tmp/git-completer' git` (no extra whitespace, path wrapped in single quotes).

---

## Problem Solved
Shells like Bash allow users and scripts to register completion specification handlers via `complete -C <script> <command>`. Running `complete -p <command>` then reconstructs and outputs the specification in a canonical format:
`complete -C '<path>' <command>`.

---

## Key Concepts
1. **Completion Specification Map**:
   - Store mapping from command name (e.g. `git`, `docker`) to completer script path:
     `Map<String, String> COMPLETION_SPECS = new HashMap<>()`.
2. **Normalized Output Representation**:
   - Do not merely echo the raw registration string (which might contain arbitrary whitespace).
   - Reconstruct canonically:
     `"complete -C '" + scriptPath + "' " + target`
3. **Missing Specification Fallback**:
   - If no entry exists for `<command>`, retain missing specification diagnostic to standard error:
     `complete: <command>: no completion specification`.

---

## The Solution
In `Main.java`:
```java
private static final Map<String, String> COMPLETION_SPECS = new HashMap<>();
...
} else if (command.equals("complete")) {
    if (cmdArgs.size() >= 3 && cmdArgs.get(1).equals("-p")) {
        String target = cmdArgs.get(2);
        if (COMPLETION_SPECS.containsKey(target)) {
            out.println("complete -C '" + COMPLETION_SPECS.get(target) + "' " + target);
        } else {
            err.println("complete: " + target + ": no completion specification");
        }
    } else if (cmdArgs.size() >= 4 && cmdArgs.get(1).equals("-C")) {
        String scriptPath = cmdArgs.get(2);
        String target = cmdArgs.get(3);
        COMPLETION_SPECS.put(target, scriptPath);
    }
}
```

---

## Failure Modes & Bugs Prevented
- **Whitespace Bleed-through**:
  - Parsed token arguments ensure extra spaces between `-C`, script path, and command name are stripped.
- **Literal Quotes**:
  - Re-encapsulating `<scriptPath>` in single quotes ensures standard shell formatting compatibility.

## CLI / Protocol Format
```bash
$ complete -C /usr/local/bin/git_completer git
$ complete -p git
complete -C '/usr/local/bin/git_completer' git
```
