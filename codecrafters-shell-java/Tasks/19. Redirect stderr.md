# Stage 19: Redirect stderr

---

## In one line
Intercept the standard error redirection operator (`2>`) to redirect a command's error diagnostics to a destination file (creating or truncating it) while preserving standard output on the terminal.

---

## The problem it solved
Previously, all error messages emitted by child processes and commands printed directly to the terminal's standard error stream. In production environments, scripts, and automation pipelines, operators need to isolate diagnostics, logs, or error stack traces into dedicated error log files without mixing them into standard output or cluttering the terminal. Implementing `2>` allows routing file descriptor 2 to an arbitrary file path while leaving file descriptor 1 (stdout) attached to the terminal console.

---

## Concepts (the transferable part)

- **[CONCEPT] File Descriptor 2 (`stderr`)** — In the POSIX I/O model, every standard process is initialized with three stream descriptors: standard input (`0`), standard output (`1`), and standard error (`2`). The syntax `2>` explicitly binds file descriptor 2 to the specified target file while leaving descriptors 0 and 1 unmodified.
- **[CONCEPT] Independent Stream Routing** — Standard output and standard error are orthogonal streams. Redirecting one does not impact the routing or buffering of the other. For example, `cat valid_file missing_file 2> err.txt` streams the contents of `valid_file` to the terminal console (`stdout`) while capturing `cat: missing_file: No such file or directory` into `err.txt` (`stderr`).
- **[CONCEPT] Eager File Creation & Truncation Semantics** — In shell execution, file redirection targets are created and opened (with `O_CREAT | O_TRUNC`) before the child command is launched. Even if the command never writes to `stderr` (e.g. `echo hello 2> err.txt`), the target file must still exist and be truncated to 0 bytes.
- **[CONCEPT] Operator Parsing and Token Extraction** — Redirection tokens are shell instructions, not arguments for the executable. The shell's parser must detect both separated forms (`2> file.txt`) and concatenated forms (`2>file.txt`), extract the destination path, prepare the file, and remove both tokens from the command argument array.

## The Solution

```java
import java.io.File;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }

            // Scan for redirection operators (>, 1>, 2>)
            List<String> cmdArgs = new ArrayList<>();
            String redirectOutFile = null;
            String redirectErrFile = null;

            for (int i = 0; i < parsedArgs.size(); i++) {
                String arg = parsedArgs.get(i);
                if ((arg.equals(">") || arg.equals("1>")) && i + 1 < parsedArgs.size()) {
                    redirectOutFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectOutFile);
                    i++;
                } else if (arg.equals("2>") && i + 1 < parsedArgs.size()) {
                    redirectErrFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectErrFile);
                    i++;
                } else if (arg.startsWith(">") && !arg.startsWith(">>") && arg.length() > 1) {
                    redirectOutFile = arg.substring(1);
                    prepareRedirectionFile(redirectOutFile);
                } else if (arg.startsWith("1>") && !arg.startsWith("1>>") && arg.length() > 2) {
                    redirectOutFile = arg.substring(2);
                    prepareRedirectionFile(redirectOutFile);
                } else if (arg.startsWith("2>") && !arg.startsWith("2>>") && arg.length() > 2) {
                    redirectErrFile = arg.substring(2);
                    prepareRedirectionFile(redirectErrFile);
                } else {
                    cmdArgs.add(arg);
                }
            }

            if (cmdArgs.isEmpty()) {
                continue;
            }

            String command = cmdArgs.get(0);
            Path outPath = redirectOutFile != null ? resolvePath(redirectOutFile) : null;
            Path errPath = redirectErrFile != null ? resolvePath(redirectErrFile) : null;

            if (BUILTINS.contains(command)) {
                PrintStream out = System.out;
                boolean closeOut = false;
                if (outPath != null) {
                    out = new PrintStream(Files.newOutputStream(outPath,
                            StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE));
                    closeOut = true;
                }

                try {
                    if (command.equals("exit")) {
                        int exitCode = 0;
                        if (cmdArgs.size() > 1) {
                            try {
                                exitCode = Integer.parseInt(cmdArgs.get(1));
                            } catch (NumberFormatException ignored) {
                            }
                        }
                        if (closeOut) {
                            out.close();
                            closeOut = false;
                        }
                        System.exit(exitCode);
                    } else if (command.equals("echo")) {
                        String output = String.join(" ", cmdArgs.subList(1, cmdArgs.size()));
                        out.println(output);
                    } else if (command.equals("type")) {
                        if (cmdArgs.size() > 1) {
                            String target = cmdArgs.get(1);
                            if (BUILTINS.contains(target)) {
                                out.println(target + " is a shell builtin");
                            } else {
                                Path executable = findExecutable(target);
                                if (executable != null) {
                                    out.println(target + " is " + executable);
                                } else {
                                    out.println(target + ": not found");
                                }
                            }
                        }
                    } else if (command.equals("pwd")) {
                        out.println(currentDir);
                    } else if (command.equals("cd")) {
                        String home = System.getenv("HOME");
                        if (home == null || home.isEmpty()) {
                            home = System.getProperty("user.home");
                        }
                        String targetPath = cmdArgs.size() > 1 ? cmdArgs.get(1) : home;
                        if (targetPath.equals("~")) {
                            targetPath = home;
                        } else if (targetPath.startsWith("~/")) {
                            targetPath = home + targetPath.substring(1);
                        }

                        Path target = currentDir.resolve(targetPath).normalize();
                        if (Files.isDirectory(target)) {
                            currentDir = target;
                        } else {
                            System.out.println("cd: " + targetPath + ": No such file or directory");
                        }
                    }
                } finally {
                    if (closeOut) {
                        out.close();
                    }
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(cmdArgs);
                    pb.directory(currentDir.toFile());
                    if (outPath != null) {
                        pb.redirectOutput(outPath.toFile());
                    } else {
                        pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);
                    }
                    if (errPath != null) {
                        pb.redirectError(errPath.toFile());
                    } else {
                        pb.redirectError(ProcessBuilder.Redirect.INHERIT);
                    }
                    pb.redirectInput(ProcessBuilder.Redirect.INHERIT);
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static void prepareRedirectionFile(String pathStr) throws Exception {
        Path p = resolvePath(pathStr);
        if (p.getParent() != null) {
            Files.createDirectories(p.getParent());
        }
        Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
    }

    private static Path resolvePath(String pathStr) {
        String home = System.getenv("HOME");
        if (home == null || home.isEmpty()) {
            home = System.getProperty("user.home");
        }
        if (pathStr.equals("~")) {
            pathStr = home;
        } else if (pathStr.startsWith("~/")) {
            pathStr = home + pathStr.substring(1);
        }
        return currentDir.resolve(pathStr).normalize();
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        char next = input.charAt(i + 1);
                        if (next == '\"' || next == '\\' || next == '$' || next == '`') {
                            i++;
                            current.append(next);
                        } else {
                            current.append(c);
                        }
                    } else {
                        current.append(c);
                    }
                } else if (c == '\"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '\"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Accidental Stream Merging** — Using `pb.redirectErrorStream(true)` instead of `pb.redirectError(File)` routes stderr directly into stdout. If only `2>` is specified, stdout must remain connected to the terminal while stderr is isolated into the file.
- **Leaking `2>` into Binary Arguments** — Failing to remove `2>` and the target file from `cmdArgs` passes them to the child process (e.g. `ls nonexistent 2> err.txt` calling `ls` with 3 arguments instead of 1), causing `ls` to search for files named `2>` and `err.txt`.
- **Failing to Create Empty File on Zero Errors** — Running `echo hello 2> errors.txt` produces zero stderr output. If file creation is deferred until error data is written, `errors.txt` would never be created. Eagerly truncating and creating the file during redirection parsing ensures standard shell compliance.
- **Missing Parent Directories** — Attempting to write error logs to nested non-existent paths (e.g., `/tmp/quz/baz.md`) throws an `IOException` unless missing parent directories are created via `Files.createDirectories()`.
- **Mixing Up stdout (`1>`) and stderr (`2>`) Paths** — When both streams are redirected in the same command (e.g., `cmd 1> out.txt 2> err.txt`), each descriptor must independently point to its respective target file.

---

## Tradeoffs

- **Immediate Eager Truncation vs Lazy ProcessBuilder Redirection** — In Java, `ProcessBuilder.redirectError(File)` will create/truncate the target file when `start()` is invoked. However, calling `prepareRedirectionFile()` upfront during argument scanning guarantees that missing parent directories are created immediately and that builtins (such as `echo 2> err.txt`, which bypass `ProcessBuilder`) also reliably produce empty error files.
- **Independent File Descriptors vs Shared Stream Handles** — Keeping `redirectOutFile` and `redirectErrFile` as distinct optional states in the loop allows supporting any combination of stdout and stderr redirections in arbitrary order.

---

## CLI / Protocol format

- **Standard error redirection (`2>`)**:
  ```
  $ ls nonexistent 2> /tmp/quz/baz.md
  $ cat /tmp/quz/baz.md
  ls: nonexistent: No such file or directory
  ```
- **Standard output remains on terminal**:
  ```
  $ echo Maria file cannot be found 2> /tmp/quz/foo.md
  Maria file cannot be found
  $ cat /tmp/quz/foo.md
  $
  ```
- **Separation of stdout and stderr across multiple inputs**:
  ```
  $ cat /tmp/bar/pear nonexistent 2> /tmp/quz/quz.md
  pear
  $ cat /tmp/quz/quz.md
  cat: nonexistent: No such file or directory
  ```

## Java specifics — lookup, don't memorize

- `ProcessBuilder.redirectError(File)` — Configures the operating system file descriptor 2 of the child process to write directly to the given file.
- `ProcessBuilder.Redirect.INHERIT` — Configures the child process stream to inherit the current JVM process's standard stream (the console terminal).
- `Files.write(Path, byte[], StandardOpenOption...)` — Atomically writes a byte array to a path with options such as `CREATE` and `TRUNCATE_EXISTING`.
- `Files.createDirectories(Path)` — Recursively creates all non-existent parent directories without throwing errors if ancestors exist.
