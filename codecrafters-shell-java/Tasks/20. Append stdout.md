# Stage 20: Append stdout

---

## In one line
Support stdout appending using `>>` and `1>>` to write stream output to the end of a file while preserving existing file contents and creating missing files/directories.

---

## The problem it solved
Previously, standard output redirection only supported overwriting target files (`>` and `1>`), which unconditionally truncated existing file contents down to zero bytes before writing. In real-world shell usage and logging pipelines, users routinely need to accumulate logs, append command results, or build up files iteratively across multiple command invocations. Implementing `>>` and `1>>` allows appending standard output to the end of a target file while preserving existing data and ensuring non-existent files and parent directories are safely created.

---

## Concepts (the transferable part)

- **[CONCEPT] Append Mode (`O_APPEND`)** — When a file descriptor is opened in append mode, the operating system atomically repositions the file write offset to the current end of the file before every write operation. Existing data is never truncated or overwritten.
- **[CONCEPT] File Creation Semantics in Append Redirection** — In POSIX shells, append redirection (`>>`) does not require the target file to exist prior to invocation. If the file is absent, the shell creates it (equivalent to `O_CREAT | O_APPEND`). Missing parent directory structures must also be generated.
- **[CONCEPT] Descriptor Equivalence (`>>` vs `1>>`)** — In Unix shell syntax, omission of a file descriptor number before a redirection operator defaults to descriptor 1 (`stdout`). Therefore, `>>` and `1>>` are identical instructions binding standard output in append mode.
- **[CONCEPT] Redirection Operator Precedence in Lexical Analysis** — Longer multi-character operators (`>>`, `1>>`) must be matched before shorter single-character operators (`>`, `1>`) during argument parsing to prevent greedy prefix collisions (e.g. accidentally matching the first `>` of `>>` as a truncate operator).

## The Solution

```java
import java.io.File;
import java.io.PrintStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.nio.file.StandardOpenOption;
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;
import java.util.Set;
import java.util.regex.Pattern;

public class Main {
    private static final Set<String> BUILTINS = Set.of("echo", "exit", "type", "pwd", "cd");
    private static Path currentDir = Paths.get(System.getProperty("user.dir")).toAbsolutePath().normalize();

    public static void main(String[] args) throws Exception {
        Scanner scanner = new Scanner(System.in);

        while (true) {
            System.out.print("$ ");
            if (!scanner.hasNextLine()) {
                break;
            }
            String input = scanner.nextLine();
            List<String> parsedArgs = parseArguments(input);
            if (parsedArgs.isEmpty()) {
                continue;
            }

            // Scan for redirection operators (>>, 1>>, >, 1>, 2>)
            List<String> cmdArgs = new ArrayList<>();
            String redirectOutFile = null;
            String redirectErrFile = null;
            boolean appendOut = false;

            for (int i = 0; i < parsedArgs.size(); i++) {
                String arg = parsedArgs.get(i);
                if ((arg.equals(">>") || arg.equals("1>>")) && i + 1 < parsedArgs.size()) {
                    appendOut = true;
                    redirectOutFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectOutFile, true);
                    i++;
                } else if (arg.startsWith(">>") && arg.length() > 2) {
                    appendOut = true;
                    redirectOutFile = arg.substring(2);
                    prepareRedirectionFile(redirectOutFile, true);
                } else if (arg.startsWith("1>>") && arg.length() > 3) {
                    appendOut = true;
                    redirectOutFile = arg.substring(3);
                    prepareRedirectionFile(redirectOutFile, true);
                } else if ((arg.equals(">") || arg.equals("1>")) && i + 1 < parsedArgs.size()) {
                    appendOut = false;
                    redirectOutFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectOutFile, false);
                    i++;
                } else if (arg.equals("2>") && i + 1 < parsedArgs.size()) {
                    redirectErrFile = parsedArgs.get(i + 1);
                    prepareRedirectionFile(redirectErrFile, false);
                    i++;
                } else if (arg.startsWith(">") && !arg.startsWith(">>") && arg.length() > 1) {
                    appendOut = false;
                    redirectOutFile = arg.substring(1);
                    prepareRedirectionFile(redirectOutFile, false);
                } else if (arg.startsWith("1>") && !arg.startsWith("1>>") && arg.length() > 2) {
                    appendOut = false;
                    redirectOutFile = arg.substring(2);
                    prepareRedirectionFile(redirectOutFile, false);
                } else if (arg.startsWith("2>") && !arg.startsWith("2>>") && arg.length() > 2) {
                    redirectErrFile = arg.substring(2);
                    prepareRedirectionFile(redirectErrFile, false);
                } else {
                    cmdArgs.add(arg);
                }
            }

            if (cmdArgs.isEmpty()) {
                continue;
            }

            String command = cmdArgs.get(0);
            Path outPath = redirectOutFile != null ? resolvePath(redirectOutFile) : null;
            Path errPath = redirectErrFile != null ? resolvePath(redirectErrFile) : null;

            if (BUILTINS.contains(command)) {
                PrintStream out = System.out;
                boolean closeOut = false;
                if (outPath != null) {
                    out = new PrintStream(Files.newOutputStream(outPath,
                            StandardOpenOption.CREATE,
                            appendOut ? StandardOpenOption.APPEND : StandardOpenOption.TRUNCATE_EXISTING,
                            StandardOpenOption.WRITE));
                    closeOut = true;
                }

                try {
                    if (command.equals("exit")) {
                        int exitCode = 0;
                        if (cmdArgs.size() > 1) {
                            try {
                                exitCode = Integer.parseInt(cmdArgs.get(1));
                            } catch (NumberFormatException ignored) {
                            }
                        }
                        if (closeOut) {
                            out.close();
                            closeOut = false;
                        }
                        System.exit(exitCode);
                    } else if (command.equals("echo")) {
                        String output = String.join(" ", cmdArgs.subList(1, cmdArgs.size()));
                        out.println(output);
                    } else if (command.equals("type")) {
                        if (cmdArgs.size() > 1) {
                            String target = cmdArgs.get(1);
                            if (BUILTINS.contains(target)) {
                                out.println(target + " is a shell builtin");
                            } else {
                                Path executable = findExecutable(target);
                                if (executable != null) {
                                    out.println(target + " is " + executable);
                                } else {
                                    out.println(target + ": not found");
                                }
                            }
                        }
                    } else if (command.equals("pwd")) {
                        out.println(currentDir);
                    } else if (command.equals("cd")) {
                        String home = System.getenv("HOME");
                        if (home == null || home.isEmpty()) {
                            home = System.getProperty("user.home");
                        }
                        String targetPath = cmdArgs.size() > 1 ? cmdArgs.get(1) : home;
                        if (targetPath.equals("~")) {
                            targetPath = home;
                        } else if (targetPath.startsWith("~/")) {
                            targetPath = home + targetPath.substring(1);
                        }

                        Path target = currentDir.resolve(targetPath).normalize();
                        if (Files.isDirectory(target)) {
                            currentDir = target;
                        } else {
                            System.out.println("cd: " + targetPath + ": No such file or directory");
                        }
                    }
                } finally {
                    if (closeOut) {
                        out.close();
                    }
                }
            } else {
                Path executable = findExecutable(command);
                if (executable != null) {
                    ProcessBuilder pb = new ProcessBuilder(cmdArgs);
                    pb.directory(currentDir.toFile());
                    if (outPath != null) {
                        pb.redirectOutput(appendOut ? ProcessBuilder.Redirect.appendTo(outPath.toFile()) : ProcessBuilder.Redirect.to(outPath.toFile()));
                    } else {
                        pb.redirectOutput(ProcessBuilder.Redirect.INHERIT);
                    }
                    if (errPath != null) {
                        pb.redirectError(errPath.toFile());
                    } else {
                        pb.redirectError(ProcessBuilder.Redirect.INHERIT);
                    }
                    pb.redirectInput(ProcessBuilder.Redirect.INHERIT);
                    Process process = pb.start();
                    process.waitFor();
                } else {
                    System.out.println(command + ": command not found");
                }
            }
        }
    }

    private static void prepareRedirectionFile(String pathStr, boolean append) throws Exception {
        Path p = resolvePath(pathStr);
        if (p.getParent() != null) {
            Files.createDirectories(p.getParent());
        }
        if (append) {
            if (!Files.exists(p)) {
                Files.createFile(p);
            }
        } else {
            Files.write(p, new byte[0], StandardOpenOption.CREATE, StandardOpenOption.TRUNCATE_EXISTING, StandardOpenOption.WRITE);
        }
    }

    private static Path resolvePath(String pathStr) {
        String home = System.getenv("HOME");
        if (home == null || home.isEmpty()) {
            home = System.getProperty("user.home");
        }
        if (pathStr.equals("~")) {
            pathStr = home;
        } else if (pathStr.startsWith("~/")) {
            pathStr = home + pathStr.substring(1);
        }
        return currentDir.resolve(pathStr).normalize();
    }

    private static List<String> parseArguments(String input) {
        List<String> args = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inSingleQuote = false;
        boolean inDoubleQuote = false;
        boolean hasToken = false;

        for (int i = 0; i < input.length(); i++) {
            char c = input.charAt(i);
            if (inSingleQuote) {
                if (c == '\'') {
                    inSingleQuote = false;
                } else {
                    current.append(c);
                }
            } else if (inDoubleQuote) {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        char next = input.charAt(i + 1);
                        if (next == '\"' || next == '\\' || next == '$' || next == '`') {
                            i++;
                            current.append(next);
                        } else {
                            current.append(c);
                        }
                    } else {
                        current.append(c);
                    }
                } else if (c == '\"') {
                    inDoubleQuote = false;
                } else {
                    current.append(c);
                }
            } else {
                if (c == '\\') {
                    if (i + 1 < input.length()) {
                        i++;
                        current.append(input.charAt(i));
                        hasToken = true;
                    } else {
                        current.append(c);
                        hasToken = true;
                    }
                } else if (c == '\'') {
                    inSingleQuote = true;
                    hasToken = true;
                } else if (c == '\"') {
                    inDoubleQuote = true;
                    hasToken = true;
                } else if (Character.isWhitespace(c)) {
                    if (hasToken) {
                        args.add(current.toString());
                        current.setLength(0);
                        hasToken = false;
                    }
                } else {
                    current.append(c);
                    hasToken = true;
                }
            }
        }
        if (hasToken) {
            args.add(current.toString());
        }
        return args;
    }

    private static Path findExecutable(String command) {
        if (command.contains("/") || command.contains(File.separator)) {
            try {
                Path path = currentDir.resolve(command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
            return null;
        }
        return findExecutableInPath(command);
    }

    private static Path findExecutableInPath(String command) {
        String pathEnv = System.getenv("PATH");
        if (pathEnv == null || pathEnv.isEmpty()) {
            return null;
        }
        String[] dirs = pathEnv.split(Pattern.quote(File.pathSeparator));
        for (String dir : dirs) {
            if (dir.isEmpty()) {
                continue;
            }
            try {
                Path path = Paths.get(dir, command);
                if (Files.isRegularFile(path) && Files.isExecutable(path)) {
                    return path;
                }
            } catch (Exception ignored) {
            }
        }
        return null;
    }
}
```

## What breaks it (failure modes)

- **Accidental File Truncation During Append** — If `prepareRedirectionFile` unconditionally truncates files with `new byte[0]` or `StandardOpenOption.TRUNCATE_EXISTING`, any existing file contents will be lost when `>>` or `1>>` is executed. The method must check `if (append)`: only ensure missing parent directories and empty file creation (`Files.createFile`), leaving existing files unmodified.
- **Prefix Collision in Operator Matching** — `>>` and `1>>` start with `>` and `1>` respectively. If `startsWith(">")` is evaluated before `startsWith(">>")`, `>>output.txt` would match `>` and strip only the first `>`, incorrectly taking `>output.txt` as the file path and truncating rather than appending. Ordering `>>` / `1>>` before `>` / `1>` prevents this.
- **Using Overwrite Redirection for External Commands** — In Java `ProcessBuilder`, calling `pb.redirectOutput(outPath.toFile())` defaults to overwriting/truncating. External processes redirected with `>>` must explicitly use `ProcessBuilder.Redirect.appendTo(outPath.toFile())`.
- **Builtins Overwriting Existing Files** — When opening an `OutputStream` for builtins (e.g. `echo text >> file`), failing to conditionally switch between `StandardOpenOption.APPEND` and `StandardOpenOption.TRUNCATE_EXISTING` will overwrite previous file contents.
- **Missing Parent Directories** — Redirection targets located inside nested non-existent directories (e.g., `/tmp/bar/bar.md`) require recursive creation with `Files.createDirectories(p.getParent())` before attempting to create or open the file.

---

## Tradeoffs

- **Flag-Based State vs Full AST / Polymorphic Redirection Model** — For the current scope of redirection features (`>`, `1>`, `2>`, `>>`, `1>>`), storing `redirectOutFile`, `redirectErrFile`, and `boolean appendOut` is concise, performs no extra heap allocations, and directly maps to `ProcessBuilder` and `OutputStream` options. If the shell later requires arbitrary descriptor duping (e.g. `2>&1`), a list of structured Redirection action objects would be preferable.
- **Immediate File Creation vs Process-Delegated File Creation** — `ProcessBuilder.Redirect.appendTo()` automatically creates files when starting a child process, but builtins bypass `ProcessBuilder`. Calling `prepareRedirectionFile()` eagerly ensures uniform behavior for both builtins and external commands while handling parent directory creation upfront.

## CLI / Protocol format

- **Standard output append redirection (`>>`)**:
  ```
  $ echo first >> output.txt
  $ echo second >> output.txt
  $ cat output.txt
  first
  second
  ```
- **Explicit descriptor 1 append redirection (`1>>`)**:
  ```
  $ echo Hello Emily 1>> /tmp/bar/baz.md
  $ echo Hello Maria 1>> /tmp/bar/baz.md
  $ cat /tmp/bar/baz.md
  Hello Emily
  Hello Maria
  ```
- **Combining overwrite and append across commands**:
  ```
  $ echo List of files: > /tmp/bar/qux.md
  $ ls /tmp/baz >> /tmp/bar/qux.md
  $ cat /tmp/bar/qux.md
  List of files:
  apple
  banana
  blueberry
  ```

## Java specifics — lookup, don't memorize

- `ProcessBuilder.Redirect.appendTo(File)` — Configures a process builder to append stdout or stderr to a file descriptor rather than overwriting it.
- `StandardOpenOption.APPEND` — Opens a file for writing, setting the file offset to the end of the file prior to each write.
- `Files.exists(Path)` — Checks if the specified path points to an existing file system object.
- `Files.createFile(Path)` — Creates a new empty file at the path, throwing `FileAlreadyExistsException` if the file already exists.
