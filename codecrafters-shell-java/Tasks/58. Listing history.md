# Stage 58: Listing history

## In one line
Display command history entries numbered with 1-based indexing right-aligned in 5 characters including the `history` command invocation itself.

## Self-test (cover the answers below and answer these first)
- Why must `history` include the `history` command itself in its listing?
- How is the command index formatted and aligned in standard shell history output?
- Should invalid or failed commands also be recorded in the shell's command history?

## The problem it solved
Users interacting with a command line shell require visibility into previous commands entered in the session for auditing, repeating, or recalling workflows. Listing history allows users to inspect the exact sequence of typed commands with consistent numbered formatting.

## Concepts (the transferable part)
- **Session History Accounting** — Shells record raw command lines prior to tokenization or execution so that even failed commands, invalid commands, or commands that error out are preserved in historical order.
- **Self-inclusion in History** — The command that triggers history inspection is itself part of the user input stream and gets added to the history buffer before evaluation.
- **Fixed-width Index Formatting** — Text-based tabular output uses width specifiers (`%5d`) to ensure alignment across small and large entry counts.

## What breaks it (failure modes)
- Adding commands only after successful execution — Fails to record invalid commands or commands that exited with non-zero exit codes.
- Omitting the `history` command itself — If the command is executed before being added to history, the count and listing will be off by one.
- 0-based indexing — Shell conventions use 1-based numbering for human readability.

## Tradeoffs
- Recording raw input vs parsed input — Recording raw input preserves exact flags, spacing, and quotes as entered by the user.

## CLI / Protocol format
- Command: `history`
- Expected output per entry: `out.printf("%5d  %s\n", index, command)`
  - 5 characters right-aligned index
  - 2 spaces
  - Raw command string
  - Newline

## Java specifics — lookup, don't memorize
- `String.format("%5d  %s\n", i + 1, commandHistory.get(i))` or `out.printf("%5d  %s\n", i + 1, commandHistory.get(i))` — Formats integer right-aligned to width 5 followed by two spaces and command string.
